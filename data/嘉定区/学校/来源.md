## 字段口径说明

### 名额到校最低分数线

- 原始口径：原文标题为「上海市高中学校"名额分配到校"招生录取最低分数线（嘉定区）」。
- 本项目口径：见 `.trellis/spec/data/field-conventions.md` → 「名额到校最低分数线」。
- 整理目标文件：`名额到校最低分数线-嘉定区-<年份>.csv`
  （字段 `year` / `district` / `junior_high_school` / `senior_high_school` /
  `min_score` / `score_full_mark` / `source_doc` / `source_page`）

### 跨年版式差异（影响字段提取，逐项以渲染原文首页核对）

| 年份 | 标题用词 | 是否有「是否同分优待」列 | 是否有「综合素质评价」列 |
|------|----------|--------------------------|--------------------------|
| 2023 | 录取最低分（含学业考总成绩和**综合考查**成绩） | ✓ 有 | ✗ 无 |
| 2024 | 录取最低分（含学业考总成绩和**综合素质评价**成绩） | ✓ 有 | ✗ 无 |
| 2025 | 录取最低分（含学业考总成绩和综合素质评价成绩） | ✓ 有 | ✓ 有 |
| 2026 | 录取最低分（含学业考总成绩和综合素质评价成绩） | ✓ 有 | ✓ 有 |

### 两条口径纪律

> 1. 「名额到校」是**中考招生录取**口径，与小学/初中**对口划片**是两套口径，
>    不得互相替代，也不得用它直接推断**小学**学区房价格。
> 2. 「名额数（计划）」与「最低分数线」是**两套口径**，不得合并成一个「初中好坏」的单一指标；
>    最低分数线与当年试卷难度强相关，**跨年不可直接比较分数**。
>    跨年比较前须先确认「综合考查成绩 / 综合素质评价成绩」的满分与计入口径是否一致。
