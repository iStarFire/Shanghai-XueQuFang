# 名额到校 PDF 提取工具

零依赖（仅 Python 标准库 `re` / `zlib`）的 PDF 内容流解码器，用于把
`data/徐汇区/学校/` 下的名额到校 PDF 精确转成结构化数据，**不依赖读图**。

| 文件 | 作用 |
|------|------|
| `pdftext.py` | 对象扫描、流解压、ToUnicode CMap 解析、矩阵乘法 |
| `ex3.py` | PDF 内容流解释器：跟踪 CTM/Tm、字体、文字显示算子；**递归进入 Form XObject**；自动跳过带 `/OC` 的水印层；字体解码按 `/ToUnicode` → 标准 CMap（`GBK-EUC-H` / `UniGB-UCS2-H`）→ `WinAnsi` 逐级回退 |
| `scores.py` | 分数线表 → 长表。按列带归并，初中列用 ±11 容差吸收单元格内换行；各年列带按**字符起点 x** 标定 |
| `build_csv.py` | 修复被矢量化的校名（唯一前缀匹配）并按**字段名**对齐写出统一 schema 的 CSV |
| `plan.py` | 计划表 → 长表。**自适应**：自动找表头 6 位高中编号行、按编号中心就近归位；左三列（序号/学校编号/学校名称）按间隙切分；初中列 ±11 容差吸收换行 |
| `build_plan_csv.py` | 计划表长表落盘（按表头**实际**编号顺序，不硬编码） |
| `table.py` / `extract.py` | 早期版本与按 y/x 分组的辅助函数（保留参考） |

用法：

```bash
python3 ex3.py  <pdf>        # 打印每页片段数
python3 scores.py <年> <pdf> # 提取分数线长表并打印统计
```

## 已确认的 PDF 生成方式（决定可用手段）

| 文件 | 生成者 | 文本层 | 可用手段 |
|------|--------|--------|----------|
| 计划 2022 | WPS | ✅ SimSun + Identity-H + ToUnicode | 精确解码 |
| 计划 2023 | — | ✅ | 精确解码 |
| 计划 2024 | Aspose.PDF（`/Rotate 90`，Resources 为间接引用） | ✅ 字体 TT3/TT5/TT6 各带 ToUnicode | 精确解码 |
| **计划 2025 / 2026** | **Quark（扫描件）** | ❌ 整页是 `DCTDecode` JPEG（2171×1536） | **只能读图** |
| 分数线 2022 | — | ✅ 但**逐字**显示（每字一个 Tj） | 精确解码，列带需按字符坐标定 |
| 分数线 2023 | iText（`UniGB-UCS2-H` / `GBK-EUC-H`，无 ToUnicode） | ✅ | 编码回退解码 |
| 分数线 2024–2026 | iText | ✅ | 精确解码 |

## 列带标定要点

- 报出的 x 是**文本起点**（`Tm` 的 e 值），不是居中位置。
- **分数线 2022 逐字显示**（每字一个 `Tj`，CJK 间距 ≈9.75、数字 ≈4.95），
  列带必须按字符起点标定：`[210, 365, 435, 480, 505, 540]`。
  最初按「合并单元格末字 x」标定导致 2022 的招生学校列错分（25 种取值）。
- 分数线 2023–2026 整串显示，列带按起点即可。

## 已解决 / 仍存在

| 问题 | 状态 |
|------|------|
| 2022 列带错分（高中数列 25 种） | ✅ 已修，现为 9 种 |
| 单元格内换行导致校名截断 | ✅ 已修（初中列 ±11 容差 + 按 x 拼接） |
| 水印「上海市教育考试院」混入 | ✅ 已修（跳过带 `/OC` 的 Form XObject） |
| **2024 超长校名尾部被矢量化** | ⚠️ **无法用解码器修复**。文本层物理上只有部分字（如「华东」）。已用唯一前缀匹配回填并登记；**必须靠回源复核兜底** |
| **计划表 2025 / 2026** | ⚠️ 扫描件（`DCTDecode` JPEG），无文本层，**只能人工读图 + 二次核对** |

## 旋转页处理（重要）

`/Rotate 90` 的页（2024 计划表）在**内容空间里表格是转置的**：高中编号竖排、序号横排。
`ex3.page_texts` 现在检测 `/Rotate 90|270` 并**交换 x/y**，还原为行列表结构；
不做这一步，2024 计划表一行都提不出来。

## 典型坑速查

| 现象 | 原因 | 处置 |
|------|------|------|
| 校名只剩前半截 | 尾部被矢量化（Aspose） | 唯一前缀匹配回填 + 回源复核 |
| 校名被拆成两行数据 | 单元格内换行（y 差 9–13） | 初中列 ±11 容差按 x 拼接 |
| 高中数列出现 25 种取值 | 列带按「末字 x」标定（应为首字 x） | 按文本起点 x 标定 |
| 一行都提不出来 | 页面 `/Rotate 90`，表格转置 | 交换 x/y |
| 无名额处忽 0 忽空 | 源文件各年写法不同 | 统一记为 `0`，登记差异 |
