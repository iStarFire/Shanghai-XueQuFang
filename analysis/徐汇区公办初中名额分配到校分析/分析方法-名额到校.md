# 分析方法：用「名额分配到校」数据衡量初中水平（可复用）

> 本文件是**方法说明**，不承载结论。结论见 `分析报告.md`。
> 方法可复用到其他行政区（但**尺度与阈值不可照搬**，见 §8）。

---

## 1. 为什么「名额到校」可以同时衡量规模和水平——以及它的边界

「名额分配到校」数据里有**两个独立维度**，必须分开使用：

| 维度 | 含义 | 能回答 | 不能回答 |
|---|---|---|---|
| **计划名额数** | 分到该校的名额个数 | 该校**规模**（报名人数占比） | 该校水平 |
| **最低录取分数线** | 该校最后一名被录取考生的分数 | 该校学生**内部竞争的激烈程度** | 该校整体质量 |

**名额数为什么是规模的代理**：计划表表头备注原文写明，区属市重的名额分配
「原则上以符合填报『名额分配到校』志愿资格的**中招报名人数**占我区该类学校
中招报名总人数的**比例为测算依据**」。所以名额数 ≈ 该校毕业班人数的线性代理。

**分数线为什么只能叫「竞争强度」而不是「质量」**：
- 它是**末位**录取分，衡量的是「该校学生在这个通道里的相对位次」，不是平均学业水平；
- 各校只能在校内竞争，**同一所高中在不同初中给出的分数线互不可比**；
- 受志愿填报博弈影响，存在明显的「大小年」。

⇒ **硬约束**：不得把「计划数」与「分数线」加权合成单一「初中强弱分」；
不得把最低分数线直接表述为「初中质量」。

## 2. 必须固定的三件事（否则结论不可比）

### 2.1 参与高中集合逐年变化 ⇒ 固定基线

区属市重集合逐年扩张：2022 年 4 所 → 2023 年新增复附徐汇（5 所）→ 2026 年新增
市二梅陇（6 所）。**直接取「当年全部区属高中的算术平均」会让跨年比较失真**——
某校某年恰好多对口一所高分高中，均分就被抬高。

**解法**：定义**固定基线 `BASE4`** = 5 年全部存在的 4 所
（市二中学、南洋模范、位育中学、南洋中学），主口径只用这 4 所的分数线求平均。

- 主口径 `mean_score_base4`：`BASE4` 均分，**跨年可比**
- 辅口径 `mean_score_all`：当年全部区属高中的均分，**仅当年内参考**
- 两者必须分别报告，并做稳健性对照（见 §5.2）

> 注意 `042002`「上海市第二中学（梅陇校区）」是**市二中学的校区**，
> 不是独立高中实体。2026 年的辅口径会同时包含市二与市二梅陇，
> 属**轻度重复计数**，这也是主口径必须固定 `BASE4` 的理由之一。

### 2.2 分母用「有效对数」，不用名额数

```
mean_score_base4(c,y) = Σ_{h∈E4(c,y)} S(c,h,y) / |E4(c,y)|
E4(c,y) = { h ∈ BASE4 : 该校在 h 有分数线 }
```

**不能**按名额数加权。原因：某校在某高中名额多（如 10 个），另一些只有 1 个，
按名额加权会让「名额分布」混进「分数线水平」，而名额分布本身就是规模变量，
两个维度会互相污染。**也**不能让缺分的高中记 0 分——缺分意味着
「录不满或无人填报」，不是「0 分」。

### 2.3 跨年汇总只用共同子集

2022 的 26 所公办与 2026 的 25 所公办**不是同一批**（有进出、有改名、有新增）。
把「某年才出现的学校」和「五年都在的学校」混在一起求平均，会产生无法解释的漂移。

**解法**：定义 `CORE` = 5 年都被收录**且**5 年都有 `mean_score_base4` 的公办初中，
跨年汇总（均值 / 中位数 / 方差 / 时间加权）**只在 `CORE` 内计算**。
非 `CORE` 学校保留逐年数据在宽表中，但不参与跨年排序。

当年内排名则用**当年全样本**（口径不同，必须分别声明）。

## 3. 跨年不能用原始分数 ⇒ 一律用名次

每年中考满分虽都是 800，但**试卷难度逐年不同**，2022 年的 730 分与 2026 年的 730 分
不是同一个水平。**跨年一律用「当年内名次」作为可比的序数变量**，
原始分数只用于同年内展示。

这就带来一个副作用：**名次本身不携带「分差」信息**。
两所学校名次相邻，可能分数差 10 分，也可能差 0.5 分。
所以结论里凡是用名次的地方，都要配合 §5.3 的「分差视角」一起看。

## 4. 排名与汇总统计量

### 4.1 平均名次法（处理并列）

```
rank(c,y) = 1 + #{ c' ≠ c : 均分(c') > 均分(c) }
             + ( #{ c' ≠ c : 均分(c') = 均分(c) } ) / 2
```

并列取平均名次，避免因并列挤位导致的名次抖动。

### 4.2 三个统计量各回答一个问题

| 统计量 | 回答 | 陷阱 |
|---|---|---|
| **均值** | 长期平均处于什么位置 | 对单年异常值极其敏感 |
| **中位数** | 典型年份处于什么位置 | 5 个数据点，中位数对极端年不敏感是优点也是缺点 |
| **方差** | 稳定程度 | **5 年样本的方差本身噪声很大**，不要在小数点上做文章 |

> **均值与中位数出现大幅背离时，必须优先怀疑「单年异常」，而不是宣布该校「不稳定」。**
> 典型例子：梅园中学均名 8.70、中位 4.50，差 4.2 名——它的 2026 年排到 23 名，
> 单这一年就把均值拉垮（见 `分析报告.md` A1）。
> **5 个点的方差只能用来分「稳定 / 中等 / 很不稳定」三档，不能用来排序。**
> 本报告因此对高方差学校逐一回看逐年名次，而不是只看方差数字。

## 5. 补充方法（本课题新增，是结论可靠性的主要来源）

### 5.1 时间加权：三方案并列，看偏移量而不是看谁对

越近年份越能反映「当前水平」，但「多近算近」没有客观答案。
**做法**：同时算三种权重，把差异当**不确定性区间**报告：

| 方案 | 权重 `w_y`（2022→2026） | 含义 |
|---|---|---|
| 等权 | 1, 1, 1, 1, 1 | 五年同等重要 |
| 线性 | 1, 2, 3, 4, 5 | 每年前进一名权重 |
| 指数 | 0.24, 0.34, 0.49, 0.70, 1.00 | 近期权重压倒性 |

```
rank_w(c) = Σ_y w_y · rank(c,y) / Σ_y w_y
```

**判读规则**：若三方案下的名次偏移中位数 < 1 名，说明**结论对权重不敏感**，
可以直接用等权结论；若某校偏移 > 2 名，说明它的近期表现与历史平均明显背离，
**必须单独说明**，不能只给等权数字。

### 5.2 分档分析：为什么必须做

名额多的学校与名额少的学校，**志愿填报逻辑不一样**：

- **大规模校**（年均区属名额 40+）：名额多、对口高中多，
  校内排名靠前的学生有充分选择空间，**填报博弈更充分，分数线更接近真实位次**；
- **小规模校**（年均区属名额 < 17）：某些高中只有 1 个名额，
  **一个学生的选择就能决定该年的分数线**，波动天然更大。

⇒ 把大小规模学校放在一起排名，**小规模校的高方差会被误读为「水平不稳」**，
而它其实只是「样本量小」。**做法**：按 `quota_zone_avg` 三分位切档，
写死阈值，**档内排名**与全样本排名并列展示，看是否翻转。

> 阈值必须在分析前固定并写入产物，**事后不得调整**。

### 5.3 「南模线」分歧校分析

取 `BASE4` 中的南洋模范中学单独看，作为**头部学生水平**的粗代理，
与 `mean_score_base4`（整体水平）**各自排名**，比较两者之差：

- 差 ≈ 0：头部与整体一致，学校内部层级均匀
- 差 > +2（整体排名优于头部排名）：**整体强、头部不突出**，中段学生厚实
- 差 < −2（头部排名优于整体排名）：**头部强、整体偏弱**，校内分层明显

这个差值本身**不能证明**「学校好不好」，但能揭示**校内结构**，
是志愿填报策略的输入（头部学生 vs 中段学生选校逻辑不同）。

### 5.4 反向证据：必须主动找

一个只报告「谁排前面」的分析是不可信的。**必做的三项反查**：

1. **口径翻转检查**：用辅口径（当年全量区属）重算 Top/Bottom，
   与主口径逐条对照，列出不一致的年份与学校；
2. **权重翻转检查**：换权重方案重算，列出偏移最大的学校；
3. **直觉冲突检查**：主动列出「排名与常识/口碑冲突」的学校，并给出可能原因
   （不强行解释，允许写成「原因未知，需外部证据」）。

### 5.5 口径变更检查（跨年可比性的前提）

逐年确认四件事，**变化年份不得连成趋势**：

| 检查项 | 徐汇区的实测结果 |
|---|---|
| 参与高中范围 | 2023 新增复附徐汇；2026 新增市二梅陇 ⇒ 用 `BASE4` 固定 |
| 初中参与资格 | **2024 起民办初中开始纳入** ⇒ 公可用名额池被分流（口径断裂） |
| 名额分配规则 | 区属按比例、委属抽签，五年一致 |
| 中考满分 | 五年均 800，一致 |

> **本课题最容易被误读的一点**：公办区属总计划 2023 年 740 → 2024 年 607，
> 看似「名额大幅缩减」，实为 **2024 年民办首次参与、209 个名额被分走**所致。
> **这是口径变更，不是趋势。**

## 6. 本方法的局限（结论使用的边界）

1. **分数线受当年试卷难度影响** ⇒ 跨年只用名次。
2. **「最低分」是末位录取分**，受志愿博弈影响，存在「大小年」。
3. **委属已排除** ⇒ 顶尖学生去向信息不完整；
   「南模线」只是**代理**，不等于「头部水平」。
4. **公办/民办划分来自 2026 年公示** ⇒ 2022–2023 的性质判定属**跨年外推**。
5. **区属高中集合逐年变化** ⇒ 主口径固定 `BASE4`。
6. **样本逐年进出** ⇒ 跨年汇总只用 `CORE`。
7. **计划数 ≠ 实际录取数**（官方未公布实际录取数）。
8. **`CORE` 只有 23 所、时间只有 5 年** ⇒ 统计量（尤其方差）精度有限。
9. 分析只覆盖**徐汇区**，结论**不得外推到其他区**。
10. **满分构成恒等式有 10/755 行越界 1–4 分**（推测含政策性加分），
    该恒等式未被用作任何指标，不影响排名。

## 8. 趋势分析（上升 / 下降）

### 8.1 为什么不能直接用名次

名次是相对当年全体的序数，一所学校里外挪一名牵动全表。
实测（23 所）：**去掉最新一年后，名次口径 20/22 所方向翻转**，分差口径仅 5/22。
⇒ 名次口径的趋势结论几乎完全由最新一年决定，**不可用**。

### 8.2 主口径：相对当年中位分差

```
rel(c,y) = mean_score_base4(c,y) − median_{c' ∈ CORE}( mean_score_base4(c',y) )
```

- 单位「分」，正 = 高于当年中位；**基准用固定集合 CORE** 以消除样本进出
- 保留原始分量级，不被名次的整数化吃掉
- 局限：假定「难度差异对全体近似平移」；若高/低分段受影响不同（天花板效应），
  需与名次口径并列互校

### 8.3 四个统计量

| 量 | 定义 | 作用 |
|---|---|---|
| `sen` | Theil–Sen 斜率（10 个点对斜率的中位数） | 主趋势，对单期异常稳健 |
| `spearman` | 年份与 `rel` 的秩相关 | 单调性 |
| `sen_drop26` | 去掉最新一年的 Sen | 去尾敏感性 |
| 留一法 | 删任意一年重算 Sen（5 次） | **单年驱动检测** |

### 8.4 严格三重判定

① Sen 与 Spearman 同号且 `|sen| ≥ 1.0 分/年`
② 去掉最新一年后不翻转
③ 留一法 5 个斜率符号全部一致

**幅度阈值必须事前写定**（本项目取 1.0 分/年）。未通过者**必须逐条写明卡在哪一条**——
否则读者无法分辨「真的没趋势」与「门槛太苛刻」。

### 8.5 ⚠️ 必须做的收敛诊断（本项目的关键发现）

**症状**：通过判定的学校里，历史前列的全在「下降」、历史靠后的全在「上升」。
这不是多个独立故事，可能是一个现象。

**做法**：对 `Δrel(首→末)` 与 `rel(首)` 做回归，量化「起点高低」能解释多少：

```
Δrel = a + b × rel_首        b < 0 ⇒ 整体在收敛
残差 = 实际变化 − 收敛预测    |残差| ≥ 1σ ⇒ 位移超出收敛可解释范围
```

本项目实测：`b = −0.653`，**R² = 0.565**，IQR 从 19 分降到 5 分。
11 所通过严格判定的学校里，**9 所的位移完全可由收敛解释**（|z| ≤ 0.99），
真正超出收敛的只有 2 所。

> **不做的后果**：会把「全区在收敛」误报成「11 所学校各自在变好/变差」，
> 且前几名会被无端描述成「在退步」。
> **建议**：把收敛诊断作为趋势分析的**固定第二步**，与主判定并列呈现；
> 并明确标注它是事后诊断还是事前门槛。

### 8.6 另两个必查项

- **换窗**：用近 3 年重算，方向相反的学校必须单独说明（本项目 1/11）
- **构成一致性**：`mean_score_base4` 的分母是有效对数，
  若某校某年对数不齐（如缺一个高中），其均值与相邻年**不可比**，
  必须单独标注（本项目 1 所：某校末年缺其历年最低分那所高中）

### 8.7 局限

1. **时点少（5 个）时检验力有限**：「未检出趋势」≠「水平未变」
2. 收敛回归若只用首末两端，中间路径未参与拟合
3. **趋势方向 ≠ 学校变好/变差**——指标始终是「通道的相对竞争强度」

## 9. 复用到其他区时的调整点

- **`BASE4` 必须重算**：各区的区属市重名单不同，固定基线要取该区五年都在的区属高中交集。
- **三分位阈值必须重算**：徐汇区阈值（16.8 / 34.2）只适用于徐汇区的规模分布。
- **民办纳入年份要单独确认**：各区民办的参与节奏一致（2024 起），
  但**具体民办名单与名额分流量**必须逐区采集。
- **公办/民办名录要找该区自己的公示**，并同样标注「跨年外推」限制。
