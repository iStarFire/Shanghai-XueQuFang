⬇ 分析报告（Markdown）
用 5 年「名额分配到校」公开数据（区考试中心公示），分析普陀区不选择生源初中
在名额到校通道上的真实竞争梯队、稳定性与趋势。
- 数据来源：上海市教育考试院（分数线 2023–2026）+ 普陀区教育考试中心（分数线 2022、
计划 2022–2026），逐文件登记见 data/普陀区/学校/来源.md
- 口径：市实验性示范性高中「名额分配到校」招生录取最低分数线（含综合素质评价成绩）；
当年到校均分 = 计划名额加权平均（v3，等权版保留为对照列）；
主排序 = 综合口径 P综合 = (P全身 + P头部 + P尾部)/3（三组等权）；
单口径 P / Z / ZR 与时间权重口径全部并列披露（第 2 章总表）
- 基线高中：区属 4 所——华二普陀 / 曹杨二中 / 晋元 / 宜川（五年全勤无断点）；
委属 5 所不参与排名口径，其名额仅计入「年均计划」列的说明
- 方法：逐年名次 → 分位 P 主口径；Z/ZR 辅；Sen 斜率 + 收敛回归
- 排名样本过滤（必读）：所有 P / Z / rank 列对全部 44 所都有值，
主表一律先按 years_included ≥ 4 过滤（31 所五年全勤 + 1 所 4 年），见局限声明第 9 条
- 指标的有效边界：名额到校的切点只落在全校前约 2%–5% 段（占考生 83% 的中段不可见），
逐线量化见 3.4；本榜不可用于判断学校整体好坏

核心结论（基于名额加权主口径，先读这里）

口径变更声明（v3，显式记录）：本报告主口径的当年到校均分已由「4 条线最低分的算术平均（等权）」
改为「计划名额加权平均」：Σ(最低分 × 该线名额) / Σ(名额)（只取当年该校有分数的线）。
等权版全部保留为对照列，正文同时给出两者名次与位次差。三组结构口径（全身 / 头部 / 尾部）
与综合口径 P综合 = (P全身 + P头部 + P尾部)/3 的合成规则不变，仅底层均分改为加权。
语义局限（必读）：名额按在籍人数比例分配，权重差异反映的是招生规模结构，而非学校水平；
因此加权版与等权版的差异应作为口径不确定性理解，而不是「加权更准」。
两者一致性：Spearman = 0.9842，最大位移 北海中学 -5 位。

A. 排名（名额加权综合口径，32 所）

  1. 第一梯队（加权综合前 4）：晋元高级中学附属学校（0.827）、江宁学校（0.795）、曹杨第二中学附属学校（0.765）、中远实验学校（0.751）。等权口径下的前 4 为 江宁学校、晋元高级中学附属学校、真北中学、中远实验学校 ——换加权口径使晋元附校升至第 1、江宁退到第 2。
  2. 第二梯队（加权综合 5–8）：真北中学、梅陇中学、华东师范大学附属外国语实验学校、华东师范大学第四附属中学。
  3. 加权与等权的位次差异是有限的：32 所中 8 所不变、12 所变动 1 位、 10 所变动 2 位，仅 北海中学 变动 5 位；Spearman = 0.9842。
  4. 梅陇中学（全区规模最大）：加权综合第 6、全身第 6、 头部第 2、尾部第 9（等权综合第 7）。它的强度集中在门槛最高的线上（华二普陀线均分全区第 1、曹杨二中线第 2），弱项在门槛较低的两条线—— 只报一个名次会看错它。注意精度：在全身口径下它与真北（0.7116）、华东师大附属外国语（0.7100）实质并列（三者极差仅 0.0015 分位），第 6 名须给区间引用（见 3.4）。

B. 头部口径与尾部口径分别说明什么

  1. 头部口径 = 尖子层位置（只看门槛最高的两条线：华二普陀、曹杨二中）：前 5 为曹杨第二中学附属学校、梅陇中学、华东师范大学第四附属中学、华东师范大学附属外国语实验学校、真北中学。
  2. 尾部口径 = 中后段位置（只看门槛较低的两条线：晋元、宜川）：前 5 为 晋元高级中学附属学校、江宁学校、上海师范大学附属第二实验学校、中远实验学校、上海外国语大学尚阳外国语学校。
  3. 两个口径的分歧是真实信息：头部与尾部口径 Spearman 仅 0.635 （全身–头部 0.895、全身–尾部 0.862）。极差最大的学校：洛川学校（全身20 / 头部28 / 尾部10，极差 18）、北海中学（全身21 / 头部13 / 尾部28，极差 15）、普陀区教育学院附属学校（全身22 / 头部26 / 尾部11，极差 15）。
  4. 两组的共同局限：头部组与尾部组各只用 2 条线，每条线每校每年只有 1–5 个名额，属小样本极值；综合口径压随机噪声，但不消除口径偏置。

C. 结构与规模

  1. 名额规模不解释位次：31 所五年全勤中 Spearman(区属年均计划, 加权均名) = -0.483、 (…, P综合) = 0.49——中等强度、方向为名额越多位次略好，与「大校被压低」的直觉相反；控制线难度后的同线内检验 ρ = −0.170（n=742，逐线口径）。梅陇（年均 62.4 个名额）在晋元/宜川线上的切点分位 与江宁几乎相同——「人数多导致排名下滑」在本数据中不成立。
  2. 单线视角与全身口径同向但会漂移：位次平均漂移 3.5–6.3 位（最大 19 位），四条区属线的第一名各不相同——单线视角适合看趋势与个案，不得替代综合口径做排名。

D. 趋势与收敛（加权口径重算）

  1. 全区在系统性收敛：校际 IQR 从 2022 年的 13.3 分降到 2026 年的 5.2 分（−61%）；收敛回归 b=−0.861、R²=0.745——约 75% 的五年变化量可由「起点高低」解释。
  2. 超出收敛解释的个案 10 所（|残差 z|≥1）：下降超出——沙田学校、桃浦中学、普陀区教育学院附属学校、新杨中学、文达学校、晋元高级中学附属学校南校；上升超出——上海理工大学附属普陀实验学校、中远实验学校、同济大学第二附属中学、延河中学。
  3. 名额总额的低谷在 2023（611）而非 2024：660 → 611 → 666 → 671 → 736。

E. 个案与口径

  1. 真北中学是最容易被口径误导的学校：加权综合第 5、全身第 5，但近 3 年权重下位次明显下沉 （逐年 rel +9.45 → -0.32， Sen -2.57、ρ -0.90）——高开低走。
  2. 沙田学校 / 桃浦中学 / 教育学院附属学校 / 新杨中学 / 文达学校 / 晋元附校南校为「下降超出收敛」名单； 上理工附属普陀实验 / 中远实验 / 同济二附中 / 延河中学为「上升超出收敛」名单。
  3. 时间权重不改变第一梯队但会重排中后段：线性/指数/近 3 年与等权榜 Spearman 0.936/0.821/0.882，变动 ≥3 位的分别为 12/17/18 所（详见附录 A）。 加权 = 当前水平、等权 = 长期画像，加权不等于更准。
  4. P / Z / ZR 三种单指标一致：Spearman(P加权, P等权) = 0.9655、 (P加权, Z加权) = 0.9718、(P综合, Z综合) = 0.9758、 (P综合, ZR综合) = 0.9897——第一梯队成员一致，「谁是第一」对口径敏感。

F. 使用边界（防止误读）

  1. 不能用本数据衡量「初中好坏」：它衡量的是「名额到校通道的竞争强度」，不含统一招生批次、自主招生与整体教学质量；本报告只做普陀区内排名； 13 所不足 4 年的学校未入榜（5 所民办 + 4 所公办新校/新参与校 + 4 所已停办或数据不足）。 量化边界见 3.4：切点只测到全校前约 2%–5% 段，占考生 83% 的中段完全不可见；要判整体水平需补毕业生规模、统招批次均分与市重点录取率。

局限声明（使用本报告前必读）

  1. 口径只覆盖名额到校通道，不含统一招生/自主招生，不能衡量学校绝对好坏。
  2. 分数线跨年不可直接比较原值：本报告跨年只用「当年名次/分位」，以及「相对当年中位的分差 rel」。
  3. 最低分是小样本极值：单条线上的名额可能只有 1 个，单年单校噪声大；本报告的主要结论建立在多年聚合上。
  4. 结构断点：初中集合逐年变化（34→33→40→41→41），2024 年新增民办与新课；主表（第 2 章）含 31 所五年全勤 + 1 所 4 年（曹杨二中附属实验中学：P 为年内标准化故可入榜，已在表中标注年数，精度低一年）；其余不足 4 年的学校仅列明细，不参与跨年排名。

1.2 口径定义：P / Z / ZR 到底是什么

三者都是「把当年分数差换算成相对位置」的方法，区别在使用什么信息与用什么尺度。

P（分位，主口径）——只用名次信息：

``
先算该校当年基线均分 x_it
→ 在当年全部有数据初中里排名次 rank_it（平均名次法，并列取平均）
→ P_it = 1 − (rank_it − 1)/(n_t − 1) （0–1，越大越强）
→ P_i = mean_t( P_it ) （跨年等权，只对有数据的年份）
``

Z（z-score）——保留分数间距，尺度用均值/标准差：

``
μ_t = 当年全部初中的均分均值；σ_t = 当年全部初中的总体标准差（pstdev）
z_it = (x_it − μ_t) / σ_t
Z_i = mean_t( z_it )
``

ZR（稳健 z）——同样保留间距，但尺度用抗极值的中位数/四分位距：

``
zr_it = (x_it − 中位_t) / (IQR_t / 1.349)
ZR_i = mean_t( zr_it )
``

1.349 是正态分布下 IQR 与标准差的换算系数（IQR ≈ 1.349σ），除它使 ZR 与 Z 量纲一致。

为什么要两个尺度：普陀 2024 年的 σ = 13.92，但 IQR/1.349 只有 8.15（被个别极低线拉大了 σ）；
2025 年 IQR/1.349 = 4.36 而 σ = 9.01。Z 在离散度大的年份压缩差异、在离散度小的年份放大差异，
等于隐式地给各年份不同权重；ZR 用稳健尺度缓解这一点。

三者的分工与一致性：

口径使用的信息特点
P（主）仅名次（序数）有界、抗尺度、抗极值；丢掉"分差有多大"
Z分数间距 + μ/σ保留间距；受极值与年度离散度影响
ZR分数间距 + 中位/IQR保留间距且抗极值，是 Z 的稳健版

两两一致性：Spearman(P加权, P等权) = 0.9655、Spearman(P加权, Z加权) = 0.9718，第一梯队成员一致。
差异集中在中段与趋势型学校：Z 口径把真北中学排到第 1，而 ZR 口径下它是第 3
（江宁 ZR 第 1）——原因见上文的尺度差异。

1.3 三个结构口径与综合口径

本报告在「基线高中」维度上再切三组，用于区分尖子层与中后段：

口径基线高中含义
全身 all华二普陀 / 曹杨二中 / 晋元 / 宜川（4 所区属）全部区属通道的整体位置（= 原主口径 P）
头部 head华二普陀 / 曹杨二中（门槛最高的 2 条线）尖子层的相对位置
尾部 tail晋元 / 宜川（门槛较低的 2 条线）中后段的相对位置
综合 comb—P综合 = (P全身 + P头部 + P尾部)/3（等权）
  • 三组的逐年排名池：34 / 33 / 40 / 41 / 41 所（含民办）；尾部组 2025–2026 少 2 所（无该线数据）。
  • 必须知道的样本局限：每条线每校每年只有 1–5 个名额，「最低分」是小样本极值；头部/尾部组各只用 2 条线，噪声更大。综合口径是三种噪声的等权平均，不消除口径偏置。
  • 合成规则的性质：三组等权 = 宣称「尖子层与中后段同等重要」。这是分析者的价值判断（已在文首登记），替代方案（头部加权、按名次平均）的差异见第 2 章注。三组之间 Spearman：全身–头部 0.897、全身–尾部 0.857、头部–尾部 0.628—— 头尾分歧是真实信息，不是噪声。

3.2.2 单线口径有多稳？——与全身口径同向，但名次会漂移 3–6 位

  • Spearman(曹杨二中单线均名, base4 均名) = +0.845； Spearman(华二普陀单线均名, base4 均名) = +0.843——方向一致。
  • 但位次漂移可观：与 base4 均名名次相比，平均绝对变动——华二普陀 4.4 位（最大 11）、曹杨二中 3.5 位（最大 19）、晋元 4.9 位（最大 14）、宜川 6.3 位（最大 18）。
  • 机理：每条线每校每年只有 1–5 个名额，「最低分」= 极小样本极值。同一所学校四条线的名次落差可达十余位——梅陇 13.5（华二普陀 9.3 / 曹二 8.8 / 晋元 12.2 / 宜川 22.3），安生 15.7、进华 15.2、洛川 14.4。
  • 推断：单线视角适合「看趋势、看个例」，不适合替代主口径做综合排名；它对梅陇这类「顶线强、底线弱」的学校尤其敏感。

3.4 指标的有效边界：切点只测到「全校前 2%–5%」这一段

本节回答一个前置问题：这个排名到底在测什么、没测什么。 结论 18 已声明「不能衡量学校好坏」，
此处给出可量化的边界。
  • 事实（覆盖缺口）：名额到校只覆盖考生的一部分。区内 4 条区属线名额合计每年 598–721 个 （5 年合计 3273 个），按普陀中考规模估算约相当于考生的 17%（估算值，仓库无普陀考生数）。再结合上表的名额占比，切点约落在全校前 1.9%（华二普陀）到前 5.1%（其余三线）—— 即本指标只观测到每个学校最前面 2%–5% 的那批学生， 占考生 83% 的「5%–50%」这一整段完全不可见。
  • 事实（实质并列）：在全身口径下，前 5 名里存在三所实质并列—— 真北中学 0.7116、梅陇中学 0.7102、华东师范大学附属外国语实验学校 0.7100，极差仅 0.0015 分位；到综合口径（含头/尾分组）才拉开为 0.7260 / 0.7193 / 0.6940。 引用「第几名」时须给区间或同时给出三位数值，否则会把噪声当序差。
  • 推断（为什么会有「公认最好」与本榜不一致）：公众认知里的「最好」主要来自 整体中考均分、市重点录取率、整体均分排名——这些覆盖全体学生；本指标测的是名额到校通道的入围门槛。两者测的不是同一件事，可以同时成立、 不可互相替代。特别地，顶端厚、5%–2% 段薄的学校（本区典型：梅陇头部第 2、尾部第 9）在任何平均型综合分里都会吃亏。
  • 要回答「哪所学校整体更好」，本数据集缺少的三类数据： ① 各校毕业生规模（可将名额占比换成真实切点分位）； ② 统一招生批次的校均分/最高分； ③ 名额到校落榜学生在统招批次的出口结果。在补齐之前，任何「梅陇是不是最好」的判断都不能由本报告的数据得出。
