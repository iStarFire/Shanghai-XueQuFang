⬇ 分析报告（Markdown）
用 5 年「名额分配到校」公开数据（区考试中心公示），分析普陀区不选择生源初中
在名额到校通道上的真实竞争梯队、稳定性与趋势。
- 数据来源：上海市教育考试院（分数线 2023–2026）+ 普陀区教育考试中心（分数线 2022、
计划 2022–2026），逐文件登记见 data/普陀区/学校/来源.md
- 口径：市实验性示范性高中「名额分配到校」招生录取最低分数线（含综合素质评价成绩）；
主排序 = 综合口径 P综合 = (P全身 + P头部 + P尾部)/3（三组等权，规则已登记）；
单口径 P / Z / ZR 与时间权重口径（线性/指数/近 3 年）全部并列披露（第 2 章总表）
- 基线高中：区属 4 所——华二普陀 / 曹杨二中 / 晋元 / 宜川（五年全勤无断点）；
委属 5 所（华二 / 上中 / 复附 / 交附 / 上师大）不参与排名口径，其计划名额仅计入总表
- 方法：逐年名次 → 分位 P 主口径；Z/ZR 辅；Sen 斜率 + 收敛回归

核心结论（基于综合多口径，先读这里）

排序口径说明：本章排序以综合口径 P综合 = (P全身 + P头部 + P尾部)/3 为主
——全身（4 所区属：华二普陀 / 曹杨二中 / 晋元 / 宜川）、头部（门槛最高的 2 条线：
华二普陀 + 曹杨二中）、尾部（门槛较低的 2 条线：晋元 + 宜川）三组等权。
合成规则是分析者选定的价值判断（含义：尖子层与中后段同等重要），不是数据给定的唯一答案；
三组名次与各单口径名次全部并列披露于第 2 章总表。引用任何名次请连同口径一起引用。

A. 排名（综合多口径，32 所）

  1. 第一梯队（综合前 4）：江宁学校（综合 0.818）、晋元高级中学附属学校（0.802）、真北中学（0.766）、中远实验学校（0.753）。四所在四种时间权重、以及 P/Z/ZR 三种单指标下 均在前 12，是口径无关的头部。
  2. 第二梯队（综合 5–8）：曹杨第二中学附属学校（0.732）、华东师范大学第四附属中学（0.730）、 梅陇中学（0.721）、华东师范大学附属外国语实验学校（0.721）。
  3. 梅陇中学是「偏科」典型，只用一个口径会看错：综合第 7、全身第 8、头部第 2、尾部第 10。它的强度集中在门槛最高的线上——华二普陀线均分 757.0（全区第 1）、曹杨二中线均名第 2；弱项在门槛较低的两条线。「中游第 8」的印象来自单一口径，已被综合口径修正。

B. 头部口径与尾部口径分别说明什么（本报告的两组结构口径）

  1. 头部口径 = 尖子层位置：只看门槛最高的两条线（华二普陀、曹杨二中），衡量该校最拔尖的那部分学生在全区尖子中的相对位置。 头部第 1 是华东师范大学第四附属中学（0.855），其后为梅陇（0.829）、真北（0.827）、华东师大附属外国语（0.810）；而综合/全身第 1 的江宁在头部只排第 5（0.792）。
  2. 尾部口径 = 中后段位置：只看门槛较低的两条线（晋元、宜川），衡量该校中后段入围者的相对位置。尾部第 1 是晋元高级中学附属学校（0.906，明显领先），其后为江宁（0.820）、中远实验（0.736）、上师大附属第二实验（0.728）。晋元附校因此成为「尾部强、头部一般」（头部第 9）的类型。
  3. 两个口径的分歧是真实信息，不是噪声：头部与尾部口径的 Spearman 仅 0.628 （全身–头部 0.897、全身–尾部 0.857）。三个名次极差最大的学校： 洛川学校（头部 28 / 尾部 9，极差 19）、教育学院附属学校（27/13）、长征中学（头部 6 / 尾部 19）、北海中学（14/27）、曹杨中学（20/32）。 → 「头部强」与「尾部强」是两件不完全重合的事；只报一个名次会掩盖这一点，因此本报告始终并列披露三组名次。
  4. 两组的共同前提与局限：头部组与尾部组各只用 2 条线，而每条线每校每年只有 1–5 个名额，「最低分」属小样本极值——两组口径的噪声都明显大于全身口径。综合口径是三种噪声的等权平均，它压随机噪声，但不消除口径偏置。

C. 结构与规模

  1. 名额规模不解释位次：全区 31 所五年全勤中，Spearman(区属年均计划, P综合) = +0.511、 (…, P全身) = +0.553、(…, P头部) = +0.569——中等强度、方向为名额越多位次略好，与「大校被压低」的直觉相反；控制线难度后的同线内检验 ρ = −0.170（n=742）。梅陇（年均 62.4 个名额）在晋元/宜川线上的切点分位（名额占该校总名额比例 0.293）与江宁（0.295）几乎相同——「人数多导致排名下滑」在本数据中不成立。
  2. 单线视角与主口径同向但会漂移：单线均名与全身口径 Spearman ≈ 0.84，但位次平均漂移 3.5–6.3 位（最大 19 位）；四条区属线的第一名各不相同 （华二普陀→华东师大四附中、曹杨二中→曹杨二中附属学校、晋元→晋元附校、宜川→晋元附校）。 → 单线视角适合看趋势与个案，不得替代主口径做综合排名。

D. 趋势与收敛

  1. 全区在系统性收敛：校际 IQR 从 2022 年的 13.4 分降到 2026 年的 5.5 分（−59%），中位 ±5 分内的学校占比从 55% 升到 81%；收敛回归 b=−0.820、R²=0.759 ——约 76% 的五年变化量可由「起点高低」解释。
  2. 真正超出收敛解释的个案 5 所（|残差 z|≥1）：下降超出——教育学院附属学校（z=−2.35）、沙田学校（z=−2.29，但近 3 年 Sen 已回升 +4.25）、文达学校（z=−1.68）；上升超出——上理工附属普陀实验（z=+1.67）、万里城实验（z=+1.60）。
  3. 名额总额的低谷在 2023（611）而非 2024：660 → 611 → 666 → 671 → 736。

E. 个案与口径

  1. 真北中学是最容易被口径误导的学校：全身第 4、Z 口径第 1、头部第 3，但近 3 年权重下掉到第 12——它的优势集中在早年（逐年 P 1.00→0.97→0.59→0.71→0.66，高开低走）。
  2. 文达学校 / 教育学院附属学校是反向典型：五年大幅下滑（文达 P 0.94→0.18），近 3 年权重下分别降至第 32、第 31——加权口径会放大它们已发生的下滑。
  3. 时间权重不改变第一梯队但会重排中后段：线性/指数/近 3 年加权与等权榜 Spearman 0.871–0.952，中后段最多 19/32 所位移 ≥3 位（详见附录 A）。 加权 = 当前水平、等权 = 长期画像，差异即「时间口径不确定性」，加权不等于更准。
  4. P / Z / ZR 三种单指标高度一致：Spearman(P, 均名)=0.993、Spearman(P, Z)=0.979，前 8 名完全同序；但 Z 口径把真北中学排到第 1、ZR 口径把它降到第 3—— 差异源于「用普通 σ 还是抗极值的中位/IQR 当尺度」。

F. 使用边界（防止误读）

  1. 不能用本数据衡量「初中好坏」：它衡量的是「名额到校通道的竞争强度」，不含统一招生批次、自主招生与整体教学质量。
  2. 本报告只做普陀区内的排名，不做跨区比较； 13 所不足 4 年的学校（民办系与新课）未入榜，其水平无法用本口径的 5 年窗口评估。

局限声明（使用本报告前必读）

  1. 口径只覆盖名额到校通道，不含统一招生/自主招生，不能衡量学校绝对好坏。
  2. 分数线跨年不可直接比较原值：本报告跨年只用「当年名次/分位」，以及「相对当年中位的分差 rel」。
  3. 最低分是小样本极值：单条线上的名额可能只有 1 个，单年单校噪声大；本报告的主要结论建立在多年聚合上。
  4. 结构断点：初中集合逐年变化（34→33→40→41→41），2024 年新增民办与新课；主表（第 2 章）含 31 所五年全勤 + 1 所 4 年（曹杨二中附属实验中学：P 为年内标准化故可入榜，已在表中标注年数，精度低一年）；其余不足 4 年的学校仅列明细，不参与跨年排名。
  5. 2023 年计划表为图片版人工转录（34 行）：已通过逐行总计自洽与分数线交叉校验（五年越界 0），但引用 2023 名额数时须知悉人工转录来源。
  6. 名录 ownership（公办/民办）为初判，待公开名录来源核实；不影响排名（样本 = 计划公示覆盖的全部不选择生源校）。
  7. 五年窗口：所有「趋势」判断的检验力有限；「未检出趋势」≠「没有变化」。
  8. 部分「有计划名额但无录取线」的对（逐年 9/5/4/4/4 对）按「无人达线」理解，待官方说明核对，未做填补。

1.1 样本与基础事实

  • 样本：45 个曾出现在名额到校计划或分数线中的初中名（含 3 所已停办：光新/兴陇/武宁）；其中 31 所五年全勤（2022–2026 每年都有区属基线上的录取线），进入跨年排名； 1 所 4 年（曹杨二中附属实验中学，2022 年未参与；P 主口径下已入榜并标注年数）； 13 所不足 4 年（民办系与新课）。
  • 基线高中：区属 4 所——华东师范大学第二附属中学（普陀校区）、上海市曹杨第二中学、上海市晋元高级中学、上海市宜川中学。五所委属（华二、上中、复附、交附、上师大） 不参与排名口径，其计划名额仅计入第 2 章总表的「年均计划（委属 5 所）」列。
  • 计划名额逐年总额：660 / 611 / 666 / 671 / 736（2022→2026）。全区峰值校梅陇中学 2026 年 69 个名额（五年均 63.4 个）。
  • 数据链路：区考试中心/市考试院 PDF → 长表（809 行分数线 + 1719 行计划）→ 宽表 → 本报告。 2.2 七维度校验通过（[校验记录](../../.trellis/tasks/10-01-putuo-junior-high/validation/data-validation.md)）。

1.2 口径定义：P / Z / ZR 到底是什么

三者都是「把当年分数差换算成相对位置」的方法，区别在使用什么信息与用什么尺度。

P（分位，主口径）——只用名次信息：

``
先算该校当年基线均分 x_it
→ 在当年全部有数据初中里排名次 rank_it（平均名次法，并列取平均）
→ P_it = 1 − (rank_it − 1)/(n_t − 1) （0–1，越大越强）
→ P_i = mean_t( P_it ) （跨年等权，只对有数据的年份）
``

Z（z-score）——保留分数间距，尺度用均值/标准差：

``
μ_t = 当年全部初中的均分均值；σ_t = 当年全部初中的总体标准差（pstdev）
z_it = (x_it − μ_t) / σ_t
Z_i = mean_t( z_it )
``

ZR（稳健 z）——同样保留间距，但尺度用抗极值的中位数/四分位距：

``
zr_it = (x_it − 中位_t) / (IQR_t / 1.349)
ZR_i = mean_t( zr_it )
``

1.349 是正态分布下 IQR 与标准差的换算系数（IQR ≈ 1.349σ），除它使 ZR 与 Z 量纲一致。

为什么要两个尺度：普陀 2024 年的 σ = 13.92，但 IQR/1.349 只有 8.15（被个别极低线拉大了 σ）；
2025 年 IQR/1.349 = 4.36 而 σ = 9.01。Z 在离散度大的年份压缩差异、在离散度小的年份放大差异，
等于隐式地给各年份不同权重；ZR 用稳健尺度缓解这一点。

三者的分工与一致性：

口径使用的信息特点
P（主）仅名次（序数）有界、抗尺度、抗极值；丢掉"分差有多大"
Z分数间距 + μ/σ保留间距；受极值与年度离散度影响
ZR分数间距 + 中位/IQR保留间距且抗极值，是 Z 的稳健版

两两一致性：Spearman(P, 均名) = 0.993、Spearman(P, Z) = 0.979，前 8 名完全同序。
差异集中在中段与趋势型学校：Z 口径把真北中学排到第 1，而 ZR 口径下它是第 3
（江宁 ZR 第 1）——原因见上文的尺度差异。

1.3 三个结构口径与综合口径

本报告在「基线高中」维度上再切三组，用于区分尖子层与中后段：

口径基线高中含义
全身 all华二普陀 / 曹杨二中 / 晋元 / 宜川（4 所区属）全部区属通道的整体位置（= 原主口径 P）
头部 head华二普陀 / 曹杨二中（门槛最高的 2 条线）尖子层的相对位置
尾部 tail晋元 / 宜川（门槛较低的 2 条线）中后段的相对位置
综合 comb—P综合 = (P全身 + P头部 + P尾部)/3（等权）
  • 三组的逐年排名池：34 / 33 / 40 / 41 / 41 所（含民办）；尾部组 2025–2026 少 2 所（无该线数据）。
  • 必须知道的样本局限：每条线每校每年只有 1–5 个名额，「最低分」是小样本极值；头部/尾部组各只用 2 条线，噪声更大。综合口径是三种噪声的等权平均，不消除口径偏置。
  • 合成规则的性质：三组等权 = 宣称「尖子层与中后段同等重要」。这是分析者的价值判断（已在文首登记），替代方案（头部加权、按名次平均）的差异见第 2 章注。三组之间 Spearman：全身–头部 0.897、全身–尾部 0.857、头部–尾部 0.628—— 头尾分歧是真实信息，不是噪声。

3.2.2 单线口径有多稳？——与主口径同向，但名次会漂移 3–6 位

  • Spearman(曹杨二中单线均名, base4 均名) = +0.845； Spearman(华二普陀单线均名, base4 均名) = +0.843——方向一致。

5 逐校个案

5.1 江宁学校（综合第 1）——最稳的头部

  • 事实：均名 6.80、中位 8.0、方差 10.96（稳定档）；rel 从 +2.9 到 +3.3，五年几乎无漂移（Sen +0.05、ρ=0.21）；收敛残差 z=+0.76。
  • 推断：唯一「高且稳」的头部校。
  • 引用注意：其区属年均名额 20.8，属中规模档。

5.2 晋元高级中学附属学校（综合第 2）——大体量头部

  • 事实：均名 7.10、方差 7.54；区属年均名额 44.6（全区第二）；rel +2.8→+3.1（Sen −0.20）。
  • 推断：规模与水平不矛盾的例外——大体量下仍稳定在头部，可作为「规模不解释水平」的反例。

5.3 真北中学（综合第 3 / Z 口径第 1）——均值-中位背离的反向典型

  • 事实：均名 9.40 但中位 12.5（均值优于典型年份）；方差 43.74； rel +9.0→+1.4（Sen −2.06、ρ −0.70——五年下行同向）；收敛残差 z=−0.04（被收敛解释）。
  • 推断：「高开低走，恰好落在收敛轨道上」——其下行与全区收敛一致，不构成自身退步证据；但 Z 口径把它排第 1，说明其早年高分年份给 z 聚合贡献大。它是最容易被口径误导的学校。

5.4 中远实验学校（综合第 4）——均值靠峰值，需看中位

  • 事实：均名 8.10 但中位仅 4.5（全区最典型的均值-中位背离）；方差 42.84； rel +6.3→+5.3（Sen −0.25）；收敛残差 z=+1.14。
  • 推断：典型年份位于前 5，均值被个别弱年拉低。引用其名次应同时给中位（4.5）。
  • 引用注意：Z 口径第 4、ZR 第 4——四种口径都在前列，属真头部。

5.5 梅陇中学（综合第 7 / 全身第 8 / 头部第 2 / 尾部第 10）——全区最大规模

  • 事实：区属年均名额 62.4（2026 年 69 个），为第二名 1.4 倍；均名 10.90（P 第 8）、中位 10.0、方差 7.24（稳定档）；rel +3.0→+3.1（Sen +0.02）——五年位次稳定在第 8–14 区间。
  • 事实（逐线）：华二普陀线均分 757.0（全区第 1）均名 9.3｜曹杨二中线均名 8.8（第 2）｜晋元线均名 12.2｜宜川线均名 22.3；四条线名次落差 13.5 位（梅陇以此进入「单线落差最大」前 5）。
  • 推断：「体量大、位置稳、顶线强、底线弱」。头部口径下它居第 2（门槛最高的两条线表现强），说明其尖子层强于整体位次。任何单口径引用都会失真，必须注明口径。
  • 不要归因于规模：全区层面名额与名次为负相关（−0.546，3.1/3.3），大校位次略好；梅陇在晋元/宜川线上的相对弱势中，有多少来自名额深度（其名额为江宁约 3 倍）、多少来自真实水平，本数据无法分离（3.3）。

5.6 普陀区教育学院附属学校（z=−2.35）——全区最强的「超收敛下降」

  • 事实：rel +3.25 → −8.25（Δ −11.5）；Sen −2.50、ρ=−1.00（五年单调下行）；残差 z=−2.35、近 3 年 Sen −2.13；均名 25.90、方差 115.44。
  • 推断：全表唯一「下降超出收敛且近端仍在走低」的个案——结构性下滑的嫌疑最高。局限：其区属年均名额仅 5.0，小样本极值噪声大，2027 年数据是验证关键。

5.7 沙田学校（z=−2.29）——下降超出但近端回升

  • 事实：rel 0.00 → −8.63（Δ −8.6）；残差 z=−2.29；近 3 年 Sen +4.25（回升）。
  • 推断：呈「长窗下行、近端反转」的形态， 不应简单表述为「下滑校」，应按「典型期处于中位、末期曾下探、近端回升」表述。

5.8 上理工附属普陀实验（z=+1.67）与万里城实验（z=+1.60）——上升超出收敛

  • 事实：前者 rel −7.6→+4.8（Δ +12.4，Sen +2.64、近 3 年 +4.00），区属年均名额仅 4.8；后者 rel −10.4→+4.0（Δ +14.4，Sen +2.98、ρ=0.80、近 3 年 +2.38）。
  • 推断：两校是全区最明确的上升个案（均超出收敛、近端延续）。上理工附属普陀规模极小（年均 4.8），单点噪声大；万里城证据更厚（名额 19.0、ρ=0.80）。
