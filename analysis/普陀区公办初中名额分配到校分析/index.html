核心结论（基于名额加权主口径，先读这里）

口径变更声明（v3，显式记录）：本报告主口径的当年到校均分已由「4 条线最低分的算术平均（等权）」
改为「计划名额加权平均」：Σ(最低分 × 该线名额) / Σ(名额)（只取当年该校有分数的线）。
等权版全部保留为对照列，正文同时给出两者名次与位次差。三组结构口径（全身 / 头部 / 尾部）
与综合口径 P综合 = (P全身 + P头部 + P尾部)/3 的合成规则不变，仅底层均分改为加权。
语义局限（必读）：名额与在籍人数规模相关（证据级别：弱旁证，见 1.0 —— 跨校占比相差 19 倍，
但占比跨年 CV 中位 18.6%，不足以断言「就是」规模），因此
权重差异主要反映招生规模结构，而非学校水平；
加权版与等权版的差异应作为口径不确定性理解，而不是「加权更准」。
两者一致性：Spearman = 0.9850，最大位移 北海中学 −5 位。

A. 排名（名额加权综合口径，32 所）

  1. 第一梯队（加权综合前 4）：晋元高级中学附属学校（0.827）、江宁学校（0.795）、曹杨第二中学附属学校（0.765）、中远实验学校（0.751）。等权口径下的前 4 为 江宁学校、晋元高级中学附属学校、真北中学、中远实验学校 ——换加权口径使晋元附校升至第 1、江宁退到第 2。
  2. 第二梯队（加权综合 5–8）：真北中学、梅陇中学、华东师范大学附属外国语实验学校、华东师范大学第四附属中学。
  3. 加权与等权的位次差异是有限的：32 所中 9 所不变、12 所变动 1 位、9 所变动 2 位，仅 2 所变动 ≥3 位（北海中学 −5、曹杨中学附属学校 +3）；Spearman = 0.9850。
  4. 梅陇中学（全区规模最大）：加权综合第 6、全身第 6、 头部第 2、尾部第 9（等权综合第 7）。它的强度集中在门槛最高的线上（华二普陀线均分全区第 1、曹杨二中线第 2），弱项在门槛较低的两条线—— 只报一个名次会看错它。注意精度：在全身口径下它与真北（0.7116） 实质并列（两者极差仅 0.0014 分位，第 5–6 名），须给区间引用（见 3.4）。

B. 头部口径与尾部口径分别说明什么

  1. 头部口径 = 尖子层位置（只看门槛最高的两条线：华二普陀、曹杨二中）：前 5 为曹杨第二中学附属学校、梅陇中学、华东师范大学第四附属中学、华东师范大学附属外国语实验学校、真北中学。
  2. 尾部口径 = 中后段位置（只看门槛较低的两条线：晋元、宜川）：前 5 为 晋元高级中学附属学校、江宁学校、上海师范大学附属第二实验学校、中远实验学校、上海外国语大学尚阳外国语学校。
  3. 两个口径的分歧是真实信息：头部与尾部口径 Spearman 仅 0.635 （全身–头部 0.899、全身–尾部 0.861）。极差最大的学校：洛川学校（全身20 / 头部28 / 尾部10，极差 18）、北海中学（全身21 / 头部13 / 尾部28，极差 15）、普陀区教育学院附属学校（全身22 / 头部26 / 尾部11，极差 15）。
  4. 两组的共同局限：头部组与尾部组各只用 2 条线，每条线每校每年只有 1–5 个名额，属小样本极值；综合口径压随机噪声，但不消除口径偏置。

C. 结构与规模

  1. 名额规模不解释位次：32 所五年全勤中 Spearman(区属年均计划, 加权均名) = -0.469、 (…, P综合) = 0.468——中等强度、方向为名额越多位次略好，与「大校被压低」的直觉相反；控制线难度后的同线内检验 ρ = −0.170（n=742，逐线口径）。梅陇（年均 62.4 个名额）在晋元/宜川线上的切点分位 与江宁几乎相同——「人数多导致排名下滑」在本数据中不成立。
  2. 单线视角与全身口径同向但会漂移：位次平均漂移 3.5–6.3 位（最大 19 位），四条区属线的第一名各不相同——单线视角适合看趋势与个案，不得替代综合口径做排名。

D. 趋势与收敛（加权口径重算）

  1. 全区在系统性收敛：校际 IQR 从 2022 年的 13.3 分降到 2026 年的 5.2 分（−61%）；收敛回归 b=−0.887、R²=0.749——约 75% 的五年变化量可由「起点高低」解释。
  2. 超出收敛解释的个案 10 所（|残差 z|≥1）：下降超出——沙田学校、桃浦中学、普陀区教育学院附属学校、新杨中学、文达学校、晋元高级中学附属学校南校；上升超出——上海理工大学附属普陀实验学校、中远实验学校、同济大学第二附属中学、延河中学。
  3. 名额总额的低谷在 2023（611）而非 2024：660 → 611 → 666 → 671 → 736。

E. 个案与口径

  1. 真北中学是最容易被口径误导的学校：加权综合第 5、全身第 5，但近 3 年权重下位次明显下沉 （逐年 rel +9.45 → -0.32， Sen -2.57、ρ -0.90）——高开低走。
  2. 沙田学校 / 桃浦中学 / 教育学院附属学校 / 新杨中学 / 文达学校 / 晋元附校南校为「下降超出收敛」名单； 上理工附属普陀实验 / 中远实验 / 同济二附中 / 延河中学为「上升超出收敛」名单。
  3. 时间权重不改变第一梯队但会重排中后段：线性/指数/近 3 年与等权榜 Spearman 0.936/0.821/0.882，变动 ≥3 位的分别为 12/17/18 所（详见附录 A）。 加权 = 当前水平、等权 = 长期画像，加权不等于更准。
  4. P / Z / ZR 三种单指标一致：Spearman(P加权, P等权) = 0.9655、 (P加权, Z加权) = 0.9718、(P综合, Z综合) = 0.9758、 (P综合, ZR综合) = 0.9897——第一梯队成员一致，「谁是第一」对口径敏感。

F. 使用边界（防止误读）

  1. 不能用本数据衡量「初中好坏」：它衡量的是「名额到校通道的竞争强度」，不含统一招生批次、自主招生与整体教学质量；本报告只做普陀区内排名； 未入榜的 11 所按 row_type 四类披露（见 1.1）： 5 所民办（excluded_private，2024 起参与，排除是口径选择而非数据不足）+ 4 所短样本公办（short_sample：梅陇实验、甘泉外国语各 2 年；金鼎、上音安师各 3 年）+ 2 所退出校（exited：光新暂停招生、武宁并入同济二附中，依据见附录 C）。 量化边界见 3.4：切点只测到全校前约 2%–5% 段（该百分比为外部估算，见 3.4 警示），中段完全不可见；要判整体水平需补毕业生规模、统招批次均分与市重点录取率。

局限声明（使用本报告前必读）

  1. 口径只覆盖名额到校通道，不含统一招生/自主招生，不能衡量学校绝对好坏。
  2. 分数线跨年不可直接比较原值：本报告跨年只用「当年名次/分位」，以及「相对当年中位的分差 rel」。
  3. 最低分是小样本极值：单条线上的名额可能只有 1 个，单年单校噪声大；本报告的主要结论建立在多年聚合上。
  4. 结构断点与两个池：初中集合逐年变化 —— P/Z/ZR 池（含民办）34→33→40→41→41， 公办非退出池（rel 与第 4 章收敛）32→32→34→36→36。两个池不可混用（见 1.2）。 2024 年新增民办与新课；主表（第 2 章）含 32 所五年全勤（四年制 0 所——曹杨二中附属实验中学已并入兴陇数据成为五年制；P 为年内标准化故可入榜，已在表中标注年数，精度低一年）；其余不足 4 年的学校仅列明细，不参与跨年排名。

1.0 口径结论的证据级别（先读，决定后面所有结论能信到什么程度）

普陀 5 个年度的名额到校计划文件全部是纯数据表（标题为「…分配结果公示」），
没有「以…为测算依据」的规则说明文字。因此本报告不给出「区级名额按某规则分配」式的断言——
普陀没有可引用的本地原文。能引用的依据只有三类：

级别依据可写程度
一级上海市统一政策《上海市高中阶段学校招生录取改革实施办法》（沪教委规〔2021〕2 号）可写「按市级政策，名额分配与考生规模挂钩」
旁证其他区公开计划文件中的同规则明文须注明非普陀本地原文
数据旁证普陀自有数据：各校名额占本线总额比例的跨校差异与跨年稳定性本节实测，见下

数据旁证的实测结果（工具/quota_proxy_evidence_pt.py 可复现）

判据是两条分别检验的：「各校名额占比跨年稳定且跨校差异大 ⇒ 与『按人数占比分配』一致」。
实测只满足一条：

条件实测判定
跨校差异大4 条区属基线线上，某校占比 0.51% ~ 9.83%，相差 19.2 倍✅ 满足
占比跨年稳定132 条校线观测的占比 CV 中位 18.6%；即使只看规模校（4 线年均 ≥3 个名额）仍有 15.7%❌ 不满足
因此「名额 ≈ 学校规模代理」只能作为弱旁证使用。
可以说：「名额的校际分布与学校规模高度相关（占比相差 19 倍）」。
不能说：「名额就是学校规模」—— 占比跨年 CV 达 15.7%–18.6%，已排除这一强说法。
更不能给出「名额按人数占比分配」式的断言 —— 本地无规则原文。
本报告其余章节凡引用「名额是规模代理」处，均为弱旁证，不作为推理前提。
⚠️ 与 3.3「名额基数过小」是同一问题的两副面孔：132 条校线观测中有 20 条的
4 线年均名额 <1.5（多为 1 个），其占比 CV 中位 23.9% —— 一个名额的增减
就让占比接近翻倍。加权均分在这种样本上等同于单条线的分数。

1.2 口径定义：P / Z / ZR 到底是什么

三者都是「把当年分数差换算成相对位置」的方法，区别在使用什么信息与用什么尺度。

P（分位，主口径）——只用名次信息：

``
先算该校当年基线均分 x_it
→ 在当年全部有数据初中里排名次 rank_it（平均名次法，并列取平均）
→ P_it = 1 − (rank_it − 1)/(n_t − 1) （0–1，越大越强）
→ P_i = mean_t( P_it ) （跨年等权，只对有数据的年份）
``

Z（z-score）——保留分数间距，尺度用均值/标准差：

``
μ_t = 当年全部初中的均分均值；σ_t = 当年全部初中的总体标准差（pstdev）
z_it = (x_it − μ_t) / σ_t
Z_i = mean_t( z_it )
``

ZR（稳健 z）——同样保留间距，但尺度用抗极值的中位数/四分位距：

``
zr_it = (x_it − 中位_t) / (IQR_t / 1.349)
ZR_i = mean_t( zr_it )
``

1.349 是正态分布下 IQR 与标准差的换算系数（IQR ≈ 1.349σ），除它使 ZR 与 Z 量纲一致。

为什么要两个尺度：σ 与稳健尺度之比逐年为 0.86 / 0.92 / 1.29 / 1.61 / 2.28（2022→2026）。
比值越大说明当年分布越被极值撑大。2024 年 σ = 11.17 而 IQR/1.349 仅 8.65；
2026 年 σ = 9.03 而 IQR/1.349 只有 3.95。Z 在离散度大的年份压缩中间段的差异、
在离散度小的年份放大差异，等于隐式地给各年份不同权重；ZR 用稳健尺度缓解这一点。

三者的分工与一致性：

口径使用的信息特点
P（主）仅名次（序数）有界、抗尺度、抗极值；丢掉"分差有多大"
Z分数间距 + μ/σ保留间距；受极值与年度离散度影响
ZR分数间距 + 中位/IQR保留间距且抗极值，是 Z 的稳健版

两两一致性（Spearman，主口径 vs 对照口径，平均秩处理并列）：
P等权 0.9655、Z加权 0.9666、ZR加权 0.9795 —— 三者高度一致。
但第 1 名会换人：P 口径下第 1 是晋元高级中学附属学校，Z 口径下仍是它，
而 ZR 口径下第 3 名从中远实验学校换成真北中学 —— 原因见上文的尺度差异。

⚠️ 两个百分位池子不同，勿混读：
- P / Z / ZR 的池 = 当年「全部有数据初中」，含民办：34 / 33 / 40 / 41 / 41（2022→2026）
- rel 与第 4 章收敛指标的池 = 当年「公办非退出」：32 / 32 / 34 / 36 / 36
两者相差 2–6 所（民办与两所退出校）。因此 P=0.80 表示「在含民办的全池中排前 20%」，
而 rel=+5 表示「比公办池中位高 5 分」，分母不同，不可互相换算。

对应研究问题 2：差距是在缩小还是扩大？ 校际离散度逐年变化，以及名额规模与位次的关系。

本章回答三个结构性问题：名额规模会不会影响位次（3.1）、只看单条线会看到什么（3.2）、「名额切得更深」有没有机械效应（3.3）。

依据（上海市统一机制，非普陀特有）：名额分配到校招生计划以各不选择生源初中学校

名额多 ⇒ 学生多，与「生源强 / 教学好」是两件事。
因此 ρ(区属年均名额, 加权综合名次) = −0.468 的正确读法是：
规模较大的学校在这条通道上位置略靠前，而不是「名额多的学校更强」。
两种读法在方向上恰好相反 —— 前者可由上述规则直接解释，后者没有依据，
且会与「本指标没有系统性压低大校」的事实矛盾。
本区无各校在校生数，故规则本身只能引用市级文件、无法用本区数据验证；
上面的 ρ 只能证明「规模与位次相关」，不能反推规模效应的大小。

3.4 指标的有效边界：切点只测到「全校前 2%–5%」这一段

本节回答一个前置问题：这个排名到底在测什么、没测什么。 结论 18 已声明「不能衡量学校好坏」，
此处给出可量化的边界。
  • 事实（覆盖缺口）：名额到校只覆盖考生的一部分。区内 4 条区属线名额合计每年 598–721 个 （5 年合计 3225 个，已按 1.1 的 merged_into 校正、剔除西校重复的 49 个），按普陀中考规模估算约相当于考生的 17%。

> ⚠️ 此处的 17% 与下文 1.9%–5.1% 均为「外部估算值」，证据级别低于本报告其余结论：
> 仓库内没有普陀考生数 / 各校毕业生规模，分母是外部引入的。
> 因此「前 2%–5%」应读作量级示意，不是可复算的测量值。
> 要把它变成测量值，必须补齐各校毕业生规模（见本节末尾第 ① 项）。

> 另需注意：区属线名额中民办初中占 88–92 个/年（2024 起，2026 年合计 91 个），
> 而本报告排名口径排除民办。故上列 598–721 含民办，而第 4 章的固定样本不含民办 ——
> 两个数字不可混用。

即本指标只观测到每个学校最前面 2%–5% 的那批学生，
占考生 83% 的「5%–50%」这一整段完全不可见。

  • 事实（实质并列）：在全身口径下，第 5–6 名是真北中学 0.7116 与梅陇中学 0.7102，极差仅 0.0014 分位 —— 远小于任何有意义的差异，应视作并列。到综合口径（含头/尾分组）才拉开为 0.7260 / 0.7193。另需注意第 3–4 名（中远 0.7852 / 曹二附属 0.7687，极差 0.0166）差距明显大于第 5–6 名。 引用「第几名」时须给区间或同时给出四位小数值，否则会把噪声当序差。

  • 要回答「哪所学校整体更好」，本数据集缺少的三类数据： ① 各校毕业生规模（可将名额占比换成真实切点分位）； ② 统一招生批次的校均分/最高分； ③ 名额到校落榜学生在统招批次的出口结果。在补齐之前，任何「梅陇是不是最好」的判断都不能由本报告的数据得出。
