# 普陀区公办初中名额分配到校分析（2022–2026）

> 用 5 年「名额分配到校」公开数据（区考试中心公示），分析普陀区**不选择生源初中**
> 在名额到校通道上的真实竞争梯队、稳定性与趋势。
>
> - 数据来源：上海市教育考试院（分数线 2023–2026）+ 普陀区教育考试中心（分数线 2022、
>   计划 2022–2026），逐文件登记见 `data/普陀区/学校/来源.md`
> - 口径：市实验性示范性高中「名额分配到校」招生录取最低分数线（含综合素质评价成绩）；
>   **主排序 = 综合口径** `P综合 = (P全身 + P头部 + P尾部)/3`（三组等权，规则已登记）；
>   单口径 **P / Z / ZR** 与时间权重口径（线性/指数/近 3 年）**全部并列披露**（第 2 章总表）
> - 基线高中：**区属 4 所**——华二普陀 / 曹杨二中 / 晋元 / 宜川（五年全勤无断点）；
>   委属 5 所（华二 / 上中 / 复附 / 交附 / 上师大）**不参与排名口径**，其计划名额仅计入总表
> - 方法：逐年名次 → 分位 P 主口径；Z/ZR 辅；Sen 斜率 + 收敛回归

## 核心结论（基于综合多口径，先读这里）

> **排序口径说明**：本章排序以**综合口径 `P综合 = (P全身 + P头部 + P尾部)/3`** 为主
> ——**全身**（4 所区属：华二普陀 / 曹杨二中 / 晋元 / 宜川）、**头部**（门槛最高的 2 条线：
> 华二普陀 + 曹杨二中）、**尾部**（门槛较低的 2 条线：晋元 + 宜川）**三组等权**。
> 合成规则是**分析者选定的价值判断**（含义：尖子层与中后段同等重要），不是数据给定的唯一答案；
> 三组名次与各单口径名次全部并列披露于**第 2 章总表**。引用任何名次请连同口径一起引用。

**A. 排名（综合多口径，32 所）**

1. **第一梯队（综合前 4）**：江宁学校（综合 0.818）、晋元高级中学附属学校（0.802）、
   真北中学（0.766）、中远实验学校（0.753）。四所在四种时间权重、以及 P/Z/ZR 三种单指标下
   **均在前 12**，是口径无关的头部。
2. **第二梯队（综合 5–8）**：曹杨第二中学附属学校（0.732）、华东师范大学第四附属中学（0.730）、
   **梅陇中学（0.721）**、华东师范大学附属外国语实验学校（0.721）。
3. **梅陇中学是「偏科」典型，只用一个口径会看错**：综合第 7、全身第 8、**头部第 2**、尾部第 10。
   它的强度集中在**门槛最高**的线上——华二普陀线均分 757.0（**全区第 1**）、曹杨二中线均名第 2；
   弱项在门槛较低的两条线。**「中游第 8」的印象来自单一口径，已被综合口径修正。**

**B. 头部口径与尾部口径分别说明什么（本报告的两组结构口径）**

4. **头部口径 = 尖子层位置**：只看门槛最高的两条线（华二普陀、曹杨二中），
   衡量该校**最拔尖的那部分学生**在全区尖子中的相对位置。
   **头部第 1 是华东师范大学第四附属中学（0.855）**，其后为梅陇（0.829）、真北（0.827）、
   华东师大附属外国语（0.810）；而综合/全身第 1 的**江宁在头部只排第 5**（0.792）。
5. **尾部口径 = 中后段位置**：只看门槛较低的两条线（晋元、宜川），
   衡量该校**中后段入围者**的相对位置。**尾部第 1 是晋元高级中学附属学校（0.906，明显领先）**，
   其后为江宁（0.820）、中远实验（0.736）、上师大附属第二实验（0.728）。
   晋元附校因此成为「尾部强、头部一般」（头部第 9）的类型。
6. **两个口径的分歧是真实信息，不是噪声**：头部与尾部口径的 Spearman 仅 **0.628**
   （全身–头部 0.897、全身–尾部 0.857）。三个名次极差最大的学校：
   **洛川学校**（头部 28 / 尾部 9，极差 **19**）、教育学院附属学校（27/13）、
   长征中学（头部 6 / 尾部 19）、北海中学（14/27）、曹杨中学（20/32）。
   → **「头部强」与「尾部强」是两件不完全重合的事**；只报一个名次会掩盖这一点，
   因此本报告始终并列披露三组名次。
7. **两组的共同前提与局限**：头部组与尾部组**各只用 2 条线**，而每条线每校每年只有
   **1–5 个名额**，「最低分」属**小样本极值**——两组口径的噪声都明显大于全身口径。
   综合口径是三种噪声的等权平均，**它压随机噪声，但不消除口径偏置**。

**C. 结构与规模**

8. **名额规模不解释位次**：全区 31 所五年全勤中，`Spearman(区属年均计划, P综合) = +0.511`、
   `(…, P全身) = +0.553`、`(…, P头部) = +0.569`——中等强度、方向为**名额越多位次略好**，
   与「大校被压低」的直觉相反；控制线难度后的同线内检验 ρ = **−0.170**（n=742）。
   梅陇（年均 62.4 个名额）在晋元/宜川线上的**切点分位**（名额占该校总名额比例 0.293）
   与江宁（0.295）几乎相同——**「人数多导致排名下滑」在本数据中不成立**。
9. **单线视角与主口径同向但会漂移**：单线均名与全身口径 Spearman ≈ 0.84，
   但位次平均漂移 **3.5–6.3 位**（最大 19 位）；四条区属线的**第一名各不相同**
   （华二普陀→华东师大四附中、曹杨二中→曹杨二中附属学校、晋元→晋元附校、宜川→晋元附校）。
   → 单线视角适合看趋势与个案，**不得替代主口径做综合排名**。

**D. 趋势与收敛**

10. **全区在系统性收敛**：校际 IQR 从 2022 年的 13.4 分降到 2026 年的 5.5 分（−59%），
    中位 ±5 分内的学校占比从 55% 升到 81%；收敛回归 **b=−0.820、R²=0.759**
    ——约 76% 的五年变化量可由「起点高低」解释。
11. **真正超出收敛解释的个案 5 所**（|残差 z|≥1）：下降超出——教育学院附属学校（z=−2.35）、
    沙田学校（z=−2.29，但近 3 年 Sen 已回升 +4.25）、文达学校（z=−1.68）；
    上升超出——上理工附属普陀实验（z=+1.67）、万里城实验（z=+1.60）。
12. **名额总额的低谷在 2023（611）而非 2024**：660 → 611 → 666 → 671 → 736。

**E. 个案与口径**

13. **真北中学是最容易被口径误导的学校**：全身第 4、**Z 口径第 1**、头部第 3，
    但近 3 年权重下掉到**第 12**——它的优势集中在早年（逐年 P 1.00→0.97→0.59→0.71→0.66，高开低走）。
14. **文达学校 / 教育学院附属学校**是反向典型：五年大幅下滑（文达 P 0.94→0.18），
    近 3 年权重下分别降至第 32、第 31——**加权口径会放大它们已发生的下滑**。
15. **时间权重不改变第一梯队但会重排中后段**：线性/指数/近 3 年加权与等权榜 Spearman
    0.871–0.952，中后段最多 19/32 所位移 ≥3 位（详见附录 A）。
    **加权 = 当前水平、等权 = 长期画像**，差异即「时间口径不确定性」，**加权不等于更准**。
16. **P / Z / ZR 三种单指标高度一致**：Spearman(P, 均名)=0.993、Spearman(P, Z)=0.979，
    前 8 名完全同序；但 **Z 口径把真北中学排到第 1、ZR 口径把它降到第 3**——
    差异源于「用普通 σ 还是抗极值的中位/IQR 当尺度」。

**F. 使用边界（防止误读）**

17. **不能用本数据衡量「初中好坏」**：它衡量的是「名额到校通道的竞争强度」，
    不含统一招生批次、自主招生与整体教学质量。
18. **本报告只做普陀区内的排名，不做跨区比较**；
    **13 所不足 4 年的学校（民办系与新课）未入榜**，其水平无法用本口径的 5 年窗口评估。

### 1.2 口径定义：P / Z / ZR 到底是什么

三者都是「把当年分数差换算成相对位置」的方法，区别在**使用什么信息**与**用什么尺度**。

**P（分位，主口径）**——只用**名次**信息：

```
先算该校当年基线均分 x_it
→ 在当年全部有数据初中里排名次 rank_it（平均名次法，并列取平均）
→ P_it = 1 − (rank_it − 1)/(n_t − 1)        （0–1，越大越强）
→ P_i  = mean_t( P_it )                     （跨年等权，只对有数据的年份）
```

**Z（z-score）**——保留**分数间距**，尺度用均值/标准差：

```
μ_t = 当年全部初中的均分均值；σ_t = 当年全部初中的总体标准差（pstdev）
z_it = (x_it − μ_t) / σ_t
Z_i  = mean_t( z_it )
```

**ZR（稳健 z）**——同样保留间距，但尺度用**抗极值**的中位数/四分位距：

```
zr_it = (x_it − 中位_t) / (IQR_t / 1.349)
ZR_i  = mean_t( zr_it )
```

`1.349` 是正态分布下 IQR 与标准差的换算系数（IQR ≈ 1.349σ），除它使 ZR 与 Z 量纲一致。

**为什么要两个尺度**：普陀 2024 年的 σ = 13.92，但 IQR/1.349 只有 8.15（被个别极低线拉大了 σ）；
2025 年 IQR/1.349 = 4.36 而 σ = 9.01。**Z 在离散度大的年份压缩差异、在离散度小的年份放大差异**，
等于隐式地给各年份不同权重；ZR 用稳健尺度缓解这一点。

**三者的分工与一致性**：

| 口径 | 使用的信息 | 特点 |
|------|-----------|------|
| **P（主）** | 仅名次（序数） | 有界、抗尺度、抗极值；丢掉"分差有多大" |
| **Z** | 分数间距 + μ/σ | 保留间距；受极值与年度离散度影响 |
| **ZR** | 分数间距 + 中位/IQR | 保留间距且抗极值，是 Z 的稳健版 |

两两一致性：Spearman(P, 均名) = **0.993**、Spearman(P, Z) = **0.979**，前 8 名完全同序。
差异集中在中段与趋势型学校：**Z 口径把真北中学排到第 1**，而 ZR 口径下它是第 3
（江宁 ZR 第 1）——原因见上文的尺度差异。

### 1.3 三个结构口径与综合口径

本报告在「基线高中」维度上再切三组，用于区分**尖子层**与**中后段**：

| 口径 | 基线高中 | 含义 |
|------|----------|------|
| 全身 `all` | 华二普陀 / 曹杨二中 / 晋元 / 宜川（4 所区属） | 全部区属通道的整体位置（= 原主口径 P） |
| 头部 `head` | 华二普陀 / 曹杨二中（门槛最高的 2 条线） | **尖子层**的相对位置 |
| 尾部 `tail` | 晋元 / 宜川（门槛较低的 2 条线） | **中后段**的相对位置 |
| **综合** `comb` | — | `P综合 = (P全身 + P头部 + P尾部)/3`（等权） |

- 三组的逐年排名池：34 / 33 / 40 / 41 / 41 所（含民办）；尾部组 2025–2026 少 2 所（无该线数据）。
- **必须知道的样本局限**：每条线每校每年只有 **1–5 个名额**，「最低分」是小样本极值；
  头部/尾部组各只用 2 条线，噪声更大。**综合口径是三种噪声的等权平均，不消除口径偏置。**
- **合成规则的性质**：三组等权 = 宣称「尖子层与中后段同等重要」。
  这是**分析者的价值判断**（已在文首登记），替代方案（头部加权、按名次平均）的差异见第 2 章注。
  三组之间 Spearman：全身–头部 **0.897**、全身–尾部 **0.857**、**头部–尾部 0.628**——
  头尾分歧是真实信息，不是噪声。

## 3 结构与异质性

本章回答四个「结构性问题」——它们决定了排名该如何被解释：

- **3.1 名额规模**会不会系统性影响位次？（关联有多强、方向是哪边）
- **3.2 只看单一条录取线**会看到什么？（以及为什么它不能替代主口径）
- **3.3 「名额切得更深」到底有没有机械效应？**（两种检验的分歧与结论）

> 统一提醒：**最低分是小样本极值**（每条线每校每年 1–5 个名额），
> 本章所有"线级"结论都建立在这一前提之上。
### 3.1 规模与竞争强度（区属年均名额三分位）

| 档 | 数量 | 全样本名次区间 |
|----|------|------|
| 大规模（年均 >20.4） | 10 所 | 第 1–29 名 |
| 中规模（11.2–20.4） | 10 所 | 第 3–27 名 |
| 小规模（≤11.2） | 11 所 | 第 4–31 名 |

- **事实**：三档的全样本名次区间**大面积重叠**——大规模档里既有全区第 1（江宁），
  也有第 29（曹杨中学）；中规模档里有第 3（中远实验）；小规模档里有第 4（真北）。
- **事实（符号与显著性，2026-10 更正）**：区属年均名额与均名的 Spearman = **−0.546**
  （n=31，p≈0.0015），与 P 的 Spearman = **+0.553**——为**中等强度、方向明确**的关联：
  **名额越多的校，位次反而略好**（均名更小 / P 更大）。
  本节旧版本只报绝对值并称「无系统关联」，**属误读，已更正**；同线内纯净检验见 3.3。
- **推断**：规模**不是**决定名次的因素——档内离散（如大规模档第 1 与第 29 同档）
  远大于档间差异；但规模**也不是无关变量**，方向为「略偏大校」。
  **本指标没有系统性压低大校**，梅陇的第 8 不能归因于其规模（见 3.3）。

#### 3.2.2 单线口径有多稳？——与主口径同向，但名次会漂移 3–6 位

  它对梅陇这类「顶线强、底线弱」的学校尤其敏感。

### 3.3 名额深度效应：两种检验的分歧与结论

| 检验 | n | Spearman | 方向解读 |
|------|---|----------|----------|
| 跨样本：区属年均名额 vs 均名 | 31 | **−0.546** | 名额越多，名次越**好** |
| 跨样本：区属年均名额 vs P | 31 | **+0.553** | 同上（P 越大越好，互为镜像） |
| 同线内：该校该线名额 vs 该线名次 | 742 | **−0.170** | 控制线难度后，仍略偏大校 |
|  ├ 华二普陀线 | 185 | −0.130 | |
|  ├ 曹杨二中线 | 188 | −0.306 | |
|  ├ 晋元线 | 186 | −0.218 | |
|  └ 宜川线 | 183 | −0.090 | |

**事实**：两种检验的符号**一致为负**——名额越多的校，位次反而**略好**（n=31 时 p≈0.0015，
属中等强度关联）。这与「名额多→切得深→线更低」的机械直觉**相反**。
**推断（机理）**：名额按在籍人数比例分配，切点在各校内的相对分位大致恒定，
机械深度效应被抵消；残留的负号来自「大规模校整体生源更强」的选择效应。
**因此：本指标并未系统性压低大校**——梅陇的第 8 不能归因于它的规模。
（注意：这不等于「规模决定水平」——三档名次区间仍大面积交织，见 3.1。）

## 5 逐校个案

### 5.1 江宁学校（综合第 1）——最稳的头部

- **事实**：均名 6.80、中位 8.0、方差 10.96（稳定档）；rel 从 +2.9 到 +3.3，
  五年几乎无漂移（Sen +0.05、ρ=0.21）；收敛残差 z=+0.76。
- **推断**：**唯一「高且稳」的头部校**。
- **引用注意**：其区属年均名额 20.8，属中规模档。

### 5.2 晋元高级中学附属学校（综合第 2）——大体量头部

- **事实**：均名 7.10、方差 7.54；区属年均名额 44.6（全区第二）；rel +2.8→+3.1（Sen −0.20）。
- **推断**：**规模与水平不矛盾的例外**——大体量下仍稳定在头部，可作为「规模不解释水平」的反例。

### 5.3 真北中学（综合第 3 / Z 口径第 1）——均值-中位背离的反向典型

- **事实**：均名 9.40 但**中位 12.5**（均值优于典型年份）；方差 43.74；
  rel +9.0→+1.4（**Sen −2.06、ρ −0.70**——五年下行同向）；收敛残差 z=−0.04（**被收敛解释**）。
- **推断**：**「高开低走，恰好落在收敛轨道上」**——其下行与全区收敛一致，不构成自身退步证据；
  但 Z 口径把它排第 1，说明其早年高分年份给 z 聚合贡献大。**它是最容易被口径误导的学校**。

### 5.4 中远实验学校（综合第 4）——均值靠峰值，需看中位

- **事实**：均名 8.10 但**中位仅 4.5**（全区最典型的均值-中位背离）；方差 42.84；
  rel +6.3→+5.3（Sen −0.25）；收敛残差 z=+1.14。
- **推断**：**典型年份位于前 5**，均值被个别弱年拉低。引用其名次应同时给中位（4.5）。
- **引用注意**：Z 口径第 4、ZR 第 4——四种口径都在前列，属真头部。

### 5.5 梅陇中学（综合第 7 / 全身第 8 / 头部第 2 / 尾部第 10）——全区最大规模

- **事实**：区属年均名额 **62.4**（2026 年 69 个），为第二名 1.4 倍；均名 10.90（P 第 8）、中位 10.0、
  方差 7.24（稳定档）；rel +3.0→+3.1（Sen +0.02）——**五年位次稳定在第 8–14 区间**。
- **事实（逐线）**：华二普陀线均分 757.0（**全区第 1**）均名 9.3｜曹杨二中线均名 **8.8（第 2）**｜
  晋元线均名 12.2｜宜川线均名 **22.3**；四条线名次落差 13.5 位（梅陇以此进入「单线落差最大」前 5）。
- **推断**：**「体量大、位置稳、顶线强、底线弱」**。头部口径下它居第 2（门槛最高的两条线表现强），
  说明其**尖子层强于整体位次**。任何单口径引用都会失真，必须注明口径。
- **不要归因于规模**：全区层面名额与名次为**负相关**（−0.546，3.1/3.3），
  大校位次略好；梅陇在晋元/宜川线上的相对弱势中，有多少来自名额深度（其名额为江宁约 3 倍）、
  多少来自真实水平，**本数据无法分离**（3.3）。

- **局限**：本区**没有**各校毕业生规模、整体中考均分、最高分/中位分数据，

  这也是「梅陇是不是最好」在本数据下**既不能证实也不能证伪**的原因。

- **事实**：rel +3.25 → −8.25（Δ −11.5）；Sen −2.50、ρ=−1.00（**五年单调下行**）；
  残差 z=−2.35、近 3 年 Sen −2.13；均名 25.90、方差 115.44。
- **推断**：**全表唯一「下降超出收敛且近端仍在走低」的个案**——结构性下滑的嫌疑最高。
  局限：其区属年均名额仅 5.0，小样本极值噪声大，2027 年数据是验证关键。

### 5.7 沙田学校（z=−2.29）——下降超出但近端回升

- **事实**：rel 0.00 → −8.63（Δ −8.6）；残差 z=−2.29；**近 3 年 Sen +4.25（回升）**。
- **推断**：呈「长窗下行、近端反转」的形态，
  **不应简单表述为「下滑校」**，应按「典型期处于中位、末期曾下探、近端回升」表述。

### 5.8 上理工附属普陀实验（z=+1.67）与万里城实验（z=+1.60）——上升超出收敛

- **事实**：前者 rel −7.6→+4.8（Δ +12.4，Sen +2.64、近 3 年 +4.00），
  区属年均名额仅 4.8；后者 rel −10.4→+4.0（Δ +14.4，Sen +2.98、ρ=0.80、近 3 年 +2.38）。
- **推断**：两校是全区**最明确的上升个案**（均超出收敛、近端延续）。
  上理工附属普陀规模极小（年均 4.8），单点噪声大；万里城证据更厚（名额 19.0、ρ=0.80）。
