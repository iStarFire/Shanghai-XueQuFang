# 字段与口径约定

> 新增字段前先读本文件。**同一概念在全项目只能有一个字段名与一种口径。**

---

## 通用规则

1. 字段名使用**英文小写下划线**：`school_name`、`unit_price`。
2. 枚举值使用**中文**，取值集合在下方显式列出，不使用自由文本。
3. 数值字段只写数字，**不带单位**；单位在字段名或本文件中约定。
   - 错误：`单价 = 12.5万元/㎡`
   - 正确：`unit_price_cny_per_sqm = 125000`（元/㎡）
4. 缺失值统一留空（CSV 中为空字段），并在 `待核实` 列或 `来源.md` 中标注。
   **禁止**用 `0`、`-1`、`未知`、`无` 等占位值混入数值字段。
5. 每条记录必须能定位到时点：要么文件级时点（文件名中的年月），要么行级字段
   （如 `price_month`）。政策类数据必须行级带 `effective_from`。
6. 金额单位统一为**元**（人民币），面积统一为**平方米**，单价统一为**元/㎡**。
7. 日期统一 `YYYY-MM-DD`；年月统一 `YYYY-MM`。

## 学校（`data/<行政区>/学校/`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `school_name` | 文本 | 学校全称，与官方公布名称一致 |
| `school_type` | 枚举 | `小学` / `初中` / `九年一贯制` / `完全中学` |
| `ownership` | 枚举 | `公办` / `民办` / `民办转公办` |
| `district` | 文本 | 行政区，与目录名一致 |
| `address` | 文本 | 官方地址；缺失留空 |
| `district_scope` | 文本 | 对口划片范围原文（可含多个小区/居委名） |
| `enrollment_plan` | 整数 | 招生计划人数，单位「人」 |
| `education_group` | 文本 | 所属教育集团/学区，无则留空 |
| `effective_from` | 日期 | 该划片/招生信息的生效时点（学年或政策发布日期） |

**口径陷阱**：

- 「对口划片」可能按**居委**、按**小区名**或按**道路门牌**划定，三种不可互相推导。
  必须在 `district_scope` 中保留原文，不要自行改写成小区名。
- 一所学校可能同时有多个校区，且**不同校区对口范围不同**。遇到时拆成多行，
  在 `school_name` 后加校区后缀，不要合并。
- 九年一贯制的「初中部」通常直升，不参与初中对口划片，不要与普通初中混算。

## 名额到校（`data/<行政区>/学校/`）

上海中考「名额分配到校」：市实验性示范性高中将部分招生计划分配到
**每一所不选择生源的初中学校**。它衡量的是**初中学校的升学通道质量**，
与小学对口划片是两套完全不同的口径，不可混用。原始文件目前为 PDF。

| 字段 | 类型 | 说明 |
|------|------|------|
| `year` | 整数 | 中考年份（4 位），必填 |
| `district` | 文本 | 行政区，与目录名一致 |
| `junior_high_school` | 文本 | 初中学校全称（名额的接收方） |
| `senior_high_school` | 文本 | 市重点高中全称（名额的给出方） |
| `quota_plan` | 整数 | 计划名额数，单位「人」 |
| `quota_actual` | 整数 | 实际录取数，无数据留空 |
| `school_code` | 文本 | 官方学校代码，无则留空 |
| `source_doc` | 文本 | 对应原始文件名 |
| `source_page` | 文本 | PDF 页码或表格编号，便于回源核对 |

**口径陷阱**：

- **「名额到校」≠「对口入学」**：前者是中考招生计划分配，后者是小学/初中划片。
  用名额到校数据推断**小学**学区房价格，是口径错误。
- **逐年政策会变**：名额分配比例、参与高中范围、初中资格条件都可能调整。
  `year` 是必填字段，跨年比较前先确认口径是否变过。
- **计划数 ≠ 实际录取数**：两者可能不等，且只有一个时不得推测另一个。
- **同一初中的名额来自多所高中**：是一对多关系。做「初中强弱」排序时，
  必须声明聚合口径（总名额数？还是加权？按什么加权？）。
- **学校改名/合并**：同一实体在不同年份可能名称不同，需要别名映射后统一。
- **PDF 提取易错**：表格跨页、上下标、全角数字、合并单元格都会导致错位。
  从 PDF 提取后必须按 `.trellis/spec/quality/` 做一次逐行回源抽查
  （至少抽查首、中、尾各若干行）。

## 名额到校最低分数线（`data/<行政区>/学校/`）

同一批原始文件里可能同时存在「计划名额」与「最低录取分数线」两类表。
**它们是两套独立口径，必须分表存放、分表登记。**

| 字段 | 类型 | 说明 |
|------|------|------|
| `year` | 整数 | 中考年份（4 位），必填 |
| `district` | 文本 | 行政区，与目录名一致 |
| `junior_high_school` | 文本 | 初中学校全称 |
| `senior_high_school` | 文本 | 市重点高中全称 |
| `min_score` | 整数 | 最低录取分数线（按当年满分口径） |
| `score_full_mark` | 整数 | 当年中考满分，用于消除跨年难度差异 |
| `score_rate` | 小数 | 衍生指标 `min_score / score_full_mark`，跨年比较**只用它** |
| `source_doc` | 文本 | 对应原始文件名 |
| `source_page` | 文本 | PDF 页码或表格编号 |

**口径陷阱**：

- **分数线不可跨年直接比较**：每年试卷难度与满分可能不同。
  跨年比较必须换算成 `score_rate`，并说明这是近似手段。
- **满分口径要确认**：是否含体育/实验/加分，不同年份可能调整。
- **分数线 ≠ 学校质量**：它同时受当年考生分数分布、志愿填报博弈影响，
  且同一初中对应多所高中时分数各不相同。**禁止**把「最低分数线高」简单等同于
  「初中更好」。
- **不要与「名额数」合成单一指标**：名额数衡量通道容量，分数线衡量竞争强度，
  两个维度的口径不可加权合并成一个「初中强弱分」。
- **年份错位是常态**：原始文件常见「某年计划 + 另一年分数线」，
  对比前先确认年份是否对齐，未对齐时禁止直接并列展示。

## 小区（`data/<行政区>/小区/`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `community_name` | 文本 | 小区名，与房产平台/物业名称一致 |
| `district` | 文本 | 行政区 |
| `address` | 文本 | 地址 |
| `built_year` | 整数 | 建成年份（4 位） |
| `building_count` | 整数 | 楼栋数 |
| `household_count` | 整数 | 户数 |
| `property_type` | 枚举 | `住宅` / `公寓` / `商住` / `别墅` / `其他` |
| `developer` | 文本 | 开发商 |
| `property_company` | 文本 | 物业公司 |
| `price_type` | 枚举 | `挂牌价` / `成交价` / `评估价` |
| `unit_price_cny_per_sqm` | 整数 | 单价，元/㎡ |
| `price_month` | 年月 | 价格对应时点 `YYYY-MM` |
| `source_tier` | 枚举 | `官方` / `平台` / `中介` / `非官方` |

**口径陷阱**：

- **挂牌价 ≠ 成交价**。两者绝不可混在同一列。混用时必须在 `来源.md` 说明并单列 `price_type`。
- 单价可能按**建筑面积**或**使用面积**计算，差异可达 20%+。本项目的默认口径是
  **建筑面积单价**，若来源是使用面积必须换算并登记。
- 商住/公寓不能享受学区政策，`property_type` 为 `商住`/`公寓` 的记录
  不得进入学区溢价分析，除非分析目标就是对比。
- 同一小区在不同平台上名称可能不同（含「苑」「园」「小区」差异），
  建立别名映射后统一，不要按字符串直接当两个小区统计。

## 规划（`data/<行政区>/规划/`）

目前实际数据为**单元规划**（控制性详细规划，PDF，体量大）。
单元规划是法定图则，规划期长、覆盖全行政区，不是「某个项目的建设计划」。

| 字段 | 类型 | 说明 |
|------|------|------|
| `doc_title` | 文本 | 文件标题 |
| `doc_type` | 枚举 | `单元规划` / `专项规划` / `年度计划` / `其他` |
| `doc_number` | 文本 | 官方文号，无则留空 |
| `issuer` | 文本 | 发布主体 |
| `publish_date` | 日期 | 发布日期 |
| `plan_period` | 文本 | 规划期（如 `2022-2035`） |
| `category` | 枚举 | `学校建设` / `交通` / `旧改动迁` / `商办配套` / `用地性质` / `其他` |
| `summary` | 文本 | 与本项目相关的要点摘录 |
| `status` | 枚举 | `已发布` / `征求意见` / `已废止` |
| `source_url` | 文本 | 原文链接 |
| `source_file` | 文本 | 对应原始 PDF 文件名 |
| `source_page` | 文本 | PDF 页码或图则编号 |

**口径陷阱**：

- **单元规划 ≠ 建设计划**：它规定的是用地性质与开发强度（容积率、高度等），
  不是「某校某年开建」。用它推断学区变化属于过度推断。
- **规划期是区间不是承诺**：`2022-2035` 不代表 2035 年前必然建成。
  做时间序列或溢价推断时必须标注不确定性。
- **图则需按图示解读**：用地性质靠图斑颜色/代码表达，文字摘要容易丢失信息。
  摘录时必须写清是依据文字部分还是图则部分，并记录页码。
- **体量大（数十 MB）**：不要在对话中整份读取；按章节/页码定位后摘录，
  并在 `source_page` 中记录定位。

**口径陷阱**：

- **规划 ≠ 落地**。`status` 为 `征求意见` 的文件不得作为确定事实引用。
- 规划期内的学校建设计划，落地时间常晚于规划时点，做时间序列分析时必须标注不确定性。
- 已废止文件必须标为 `已废止` 并保留——删除会掩盖历史判断依据。

## 新增字段的流程

1. 确认现有字段无法表达该信息（能复用就复用）
2. 在本文件对应主题表中新增一行：字段名 / 类型 / 说明
3. 口径不明确的，写进对应主题目录的 `来源.md` → 「字段口径说明」
4. 更新既有数据文件时**必须同批**补齐该字段或显式留空，不允许部分文件缺列
