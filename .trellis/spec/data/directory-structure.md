# 目录结构与命名规范

---

## 顶层结构

```
Shanghai-XueQuFang/
├── data/                        # 唯一的项目数据目录（按行政区隔离）
│   ├── README.md                # 数据目录总说明
│   ├── 徐汇区/
│   │   ├── 学校/
│   │   ├── 小区/
│   │   └── 规划/
│   └── 普陀区/
│       └── ...
└── .trellis/                    # 工作流、规范、任务（不含业务数据）
```

**硬性规则**：

1. 所有业务数据只能放在 `data/` 下。不要新建 `data_src/`、`raw/`、`output/`、`tmp/` 等平行数据目录。
2. `data/` 的第一层只能是**行政区目录**，使用官方简称：`徐汇区`、`普陀区`、`黄浦区`、`静安区`、`长宁区`、`虹口区`、`杨浦区`、`浦东新区`、`闵行区`、`宝山区`、`嘉定区`、`松江区`、`青浦区`、`金山区`、`奉贤区`、`崇明区`。
   - 不要写 `徐汇` / `xuhui` / `XH`；不要嵌套「区级/市级」中间层。
3. `data/` 的第二层是**主题目录**，目前允许：`学校`、`小区`、`规划`。
   - 新增主题前先在 `.trellis/spec/data/index.md` 登记，并说明为什么现有主题放不下。

## 主题目录的内容边界

| 主题 | 放什么 | 不放什么 |
|------|--------|----------|
| `学校/` | 小学/初中名录、办学性质、对口划片范围、招生计划、地址、办学集团、**中考名额分配到校数据** | 学生个人成绩、非公开评价 |
| `小区/` | 小区名录、地址、建成年代、户型面积、挂牌/成交价格与租金 | 具体房源的房东/中介个人信息 |
| `规划/` | 官方规划文件与摘要（含**单元规划**）、新建/改扩建学校计划、交通与旧改规划、原文文号与发布时间 | 未经证实的传闻、自媒体推测（若保留必须标注为「非官方」） |

`名额到校` 属于 `学校/` 主题：它是初中学校与市重点高中之间的招生计划分配关系，
不是独立主题。字段定义见 `field-conventions.md`。

跨行政区共享的市级文件放到 `data/_全市/`（下划线开头，与行政区目录区分），
并在 `来源.md` 中说明。

## 文件命名

```
<主题>-<范围或口径>-<时点>[.csv|.md]
```

示例：

- `小学名录-公办-2026.csv`
- `对口划片-徐汇区-2026.md`
- `小区挂牌价-2026-09.csv`
- `规划文件摘要-2025-2035.md`

规则：

- 使用中文短横线 `-` 分段，段内不使用空格
- 必须包含**时点**（年份或年月），因为学区房数据强时效
- 同一实体同一时点只允许一个文件；需要保留旧版本时移到该目录下的 `_历史/` 子目录
- **禁止** `最终版`、`最新`、`new`、`副本`、`copy` 这类命名

## 格式约定

- 结构化、多行多列的数据：`CSV`，UTF-8（含 BOM），首行为英文字段名
- 政策原文摘要、口径说明、少量手工整理的资料：`Markdown`
- **原始文件（PDF、公告截图等）直接放在对应主题目录下**，与整理后的文件同级。
  文件数量多时才归入 `原始文件/` 子目录；不要为了整齐把已有的原始文件搬来搬去
  —— 移动会打断既有引用（**重命名不受此限**，见下条）。
- 原始文件**统一命名**为 `【<区>】【<年>】<主题>.<ext>`，例：
  `【徐汇】【2025】名额到校最低分数线.pdf`、`【普陀】【2023】名额到校最低分数线.pdf`。
  - **不得改动文件内容**：重命名前后 MD5 必须一致；
  - 改名必须在同目录 `来源.md` 的「重命名记录」中登记 `原名 → 新名 → MD5`，
    未登记即视为丢失 provenance；
  - **主题词必须与登记口径一致**：口径不同（如「计划名额数」vs「最低录取分数线」）
    必须用不同主题词，禁止同一名字承载两种口径；
  - 来源方原始文件名记入 `来源.md` 的「来源」列，以保留回源线索。

  **本条于 2026-09-30 修订**，取代此前「原始文件沿用来源方原始命名、不要重命名」的规定。
- 不使用 Excel 二进制格式（`.xls`/`.xlsx`）作为长期存储：先另存为 CSV 再入库
- 每个 CSV 首行字段名必须与 `.trellis/spec/data/field-conventions.md` 登记的一致

### 当前实际文件形态（供参考基线）

```
data/徐汇区/学校/【徐汇】【2022】名额到校最低分数线.pdf     (2022–2026，共 5 份)
data/普陀区/学校/【普陀】【2023】名额到校最低分数线.pdf     (2023–2026，共 4 份)
data/嘉定区/学校/【嘉定】【2023】名额到校最低分数线.pdf     (2023–2026，共 4 份)
data/黄浦区/学校/【黄浦】【2023】名额到校最低分数线.pdf     (2023–2026，共 4 份)
data/徐汇区/规划/【徐汇】【2022】上海市徐汇区单元规划.pdf
data/普陀区/规划/【普陀】【2022】普陀单元规划.pdf
```

**命名已统一为 `【区】【年】` 一种风格**（2026-09-30 起）。历史遗留的
`区名-年份-主题`（原徐汇 2026）与 `年份+区名+主题`（原普陀 2023–2025）两种风格
已通过重命名消除，逐份映射见各区 `来源.md` 的「重命名记录」。
新增文件一律用上面这一种，不要引入第二种。

**同一主题下并存多种口径**是已知现状（例如「名额到校**计划**」与「名额到校**最低分数线**」）。
这两类必须**分表存放、分表登记**，且**文件名主题词必须区分**；
年份不对齐时禁止并列展示。

**同一口径跨年也可能变版式**（以「名额到校最低分数线」为例，逐份渲染原文核对）：
2022 无「是否同分优待」列；2023 起有该列；2025 起增加「综合素质评价」列；
2023 称「综合考查成绩」、2024 起改称「综合素质评价成绩」（满分均 50 分）。
整理成 CSV 前必须逐份核对原表头，不得按最早一年的表头套用。

**2022 年「名额分配到校最低分数线」缺口**：市教育考试院官网 2022 年只集中发布了
「名额分配到**区**」线；「到**校**」线当年由各区招考机构分别发布。
目前仅徐汇已从区级来源补齐（见 `data/徐汇区/学校/来源.md`）；
普陀/嘉定/黄浦的 2022 为**已知缺口**，不得当作「无数据」或「无录取」。

## 废弃与隔离

- 判定为错误/失效的数据**不要直接删除**，移到 `data/<行政区>/_废弃/`，
  并在 `来源.md` 与 `_废弃/说明.md` 中写明废弃原因与时间
- 分析结论中发现依赖了已废弃数据 → 必须回到工作流 2.2 / 2.4 重新校验与验证
