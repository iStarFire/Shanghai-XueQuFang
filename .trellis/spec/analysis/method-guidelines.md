# 分析方法规范

> 适用于工作流 2.3。目标不是「算出数」，而是**产出别人能复核的结论**。

---

## 一、分析设计（写进 `design.md`）

每个分析任务在动笔前必须明确：

| 项 | 说明 | 反例 |
|----|------|------|
| 分析问题 | 一句话说明要回答什么 | 「分析一下徐汇学区房」 |
| 对比基准 | 和什么比（同区非学区房 / 同区其他学区 / 全市均值 / 历史同期） | 不与任何基准对比，只说「很贵」 |
| 指标定义 | 每个指标的分子分母、单位、时点 | 「溢价率」没说是相对谁 |
| 样本范围 | 纳入与排除规则（哪些小区/学校算，哪些不算） | 只写「徐汇区的小区」 |
| 预期反证 | 什么结果会推翻预期结论 | 完全没有 |
| 局限声明 | 已知的数据与政策局限 | 留空 |

---

## 二、口径声明

- 每个指标必须写出计算公式与单位
- 涉及价格时必须声明：`price_type`（挂牌/成交）、面积口径（建筑面积/使用面积）、时点
- 涉及划片时必须声明依据的招生年度
- 口径中途变化必须显式记录，不得静默切换

---

## 三、事实与推断分离

输出中必须区分两类陈述：

- **事实描述**：数据直接显示的，可被逐条核对
  > 「2026 学年，A 小学对口范围内的 12 个小区中，有 9 个小区近 6 个月成交单价中位数高于本区非学区小区中位数。」
- **推断判断**：需要额外解释的，必须标注为推断并给出不确定性
  > 「据此推断 A 小学对口因素与该价格差异相关（不能断言因果）。样本量 12，未控制房龄与楼层差异，置信度中等。」

**禁止**把推断写成事实。禁止使用「必然」「一定」「显然」等词描述未经检验的关系。

---

## 四、输出格式

分析与结论草稿写入 `{TASK_DIR}/analysis/`，每条结论采用如下结构：

```markdown
## 结论 N：<一句话结论>

- **类型**：事实描述 / 推断判断
- **支撑数据**：`data/徐汇区/小区/小区挂牌价-2026-09.csv` 字段 `unit_price_cny_per_sqm`
- **样本量**：N = 12 个小区 / 共 143 条价格记录
- **计算方式**：<筛选条件 + 聚合口径 + 公式>
- **反向证据**：<与结论冲突的个案，及如何处理>
- **局限与不确定性**：<数据缺口、口径风险、政策变动风险>
- **置信度**：高 / 中 / 低（并说明理由）
```

缺失「支撑数据」「样本量」「计算方式」的结论视为未完成。

**Markdown 写作约束（`build_html.py` 的解析器口径）**：
- 表格行必须成组：表头行下一行必须是 `|---|---|` 分隔行，否则该 `|` 行不被识别为表格；
- **不要把 `|x|` 之类的绝对值记号写在行首**——行首 `|` 行若不构成表格，
  旧版转换器会死循环（2026-09 A6 节触发过，已加防御按普通段落处理），
  写作时仍应改用「x 的绝对值」等文字表述或把记号移到行中。

## 五、本项目常用的分析框架

1. **学区溢价估算**
   - 对比学区房与非学区房单价中位数（控制行政区、房龄区间）
   - 必查：是否混入商住、是否混用挂牌/成交价、样本是否覆盖高低价段

2. **同类学区横向对比**
   - 同区多个学区之间比；跨区比必须说明区级政策差异
   - 必查：对口范围大小不同会直接影响可比性

3. **时间序列趋势**
   - 至少覆盖 3 个时点；政策变动时点必须标注在图上/文中
   - 必查：指标口径在时间上是否一致（换过口径的序列不可直接连）

4. **规划兑现预期**
   - 区分「已发布」「征求意见」「已废止」
   - 必查：规划落地时间通常晚于规划时点，不得按规划发布日当作兑现日

5. **多时点、小样本的水平与稳定性评估**（如「某学校/小区连续 5 年处于什么位置」）
   - **跨时点不用原始值，用「期内名次」**：原始值（分数、单价）受当年难度/行情影响，
     不可直接连成趋势；名次是序数变量，跨期可比。名次之外可报告分差，但不得跨期连线。
   - **固定基线**：若参与比较的对象集合逐年扩张/收缩，算术均值会被集合变化污染。
     取**各期都在的交集**求均值作为主口径（跨期可比），当期全量做辅口径并做稳健性对照。
   - **共同子集**：跨期汇总只用「各期都有数据」的样本；样本进出会让均值漂移。
     非共同子集样本保留在明细表中，但不参与跨期排序。
   - **三个统计量各回答一个问题**：均值=长期位置；中位数=典型期位置；方差=稳定程度。
     必查：**均值与中位数大幅背离时，优先怀疑单期异常，而不是宣布「不稳定」**。
   - **时点少（如 5 期）时，方差只能分档不能排序**——它本身噪声极大。
   - **时间加权必须并列多方案**（等权/线性/指数），把方案间差异当**不确定性区间**报告，
     而不是挑一个方案当答案。必查：加权会放大**最近一期的噪声**，
     若多所样本的异常期都落在最近一期，须显式指出这一点。
   - **报告加权敏感性时，必须给出「最新一期所占权重比例」并做一个极端对照**：
     例如「只看最新一期」的榜，用它的位移幅度给不确定性定上界。
     若极端对照下变动 ≥3 位的对象超过全部样本的 1/3（或出现「第 20 名→第 2 名」级位移），
     必须写明结论：**加权不等于更准，只是把权重集中到最新一期**——
     「近期考得好应算更好」是**价值判断**（测「当前水平」还是「长期水平」），不是统计改进。
     规范处置：主口径保持等权（长期画像）时，须显式区分「等权 = 长期水平、加权 = 当前水平」；
     若确实需要「当前强弱」，应**显式选窗口**（如近 3 年榜并标注窗口）或**显式建趋势**
     （Sen 斜率 / 收敛残差），而不是用指数加权当主榜。
     （2026-10 实例：普陀指数权重下最新一期独占 51.6%、18/32 所位移 ≥3 位；
     单年榜 24/32 所位移 ≥3 位、最大 18 位。徐汇同法仅 8/24 所 —— 两区敏感度不同，
     数字必须各自独立测算，不得互抄。）
   - **规模/量级分层**：量大与量小的对象，其波动机制不同（量小的单点即可改变结果），
     混在一起排序会把「样本量小」误读为「水平不稳」。
     做法：按规模代理分档，**阈值事前固定**，同时给出档内排名与全样本排名。
     **必查：先实测分档是否真的造成翻转，再谈为什么**——
     不要先验断言「合并排名必然失真」（实测可能完全不失真，这本身是有信息量的结论）。
   - **报告「规模 vs 名次」关联时必须给带符号的 ρ + n（必要时 p），且分两层检验**：
     ① 跨样本（全部对象）；② **控制维度后**（如同一条录取线内 / 同一档内）。
     两层符号若相反，必须并列披露并解释叠加机理，**不得只报绝对值**——
     只报 \|ρ\| 会把「中等强度的反向关联」误写成「无系统关联」
     （2026-10 普陀实例：跨样本 ρ = −0.546（n=31, p≈0.0015，即名额越多位次略好）
     曾被误述为「无系统关联」；同线内 ρ = −0.170 方向相同）。
     同时禁止反向误读：**中等关联 ≠ 强解释力**，档内离散大于档间差异时，
     仍应写成「规模不足以单独决定名次」。
   - **子集/单维度视角（如「只看某一条录取线」）必须并报可比性指标**：
     与主口径的 Spearman + **平均绝对位次漂移**（并给出最大漂移对象），
     以及子集自身的样本量（每条线每校每年可能只有 1–3 个名额）。
     子集视角只用于看趋势与个案，**不得替代主口径做综合排名**。

6. **「统计上稳健」≠「归因上专属」**（做趋势/变化分析时必做的一步）
   - **问题**：多方法一致性（如 Sen + Spearman 同号）、留一法、换窗、换基准
     这一整套**只证明「这个变化不是噪声」，不证明「这个变化属于该对象」**。
     当全体存在系统性位移（收敛 / 发散 / 共同趋势）时，每个对象的位移里
     都含一份**由整体决定的量**。
   - **症状**：排名靠前的一批全在「下降」、靠后的一批全在「上升」——
     这不是 N 个独立故事，可能是一个现象。
   - **做法**：做**扣除整体效应**的诊断。最简形式是对「首末变化量」回归「起始水平」：
     ```
     Δ = a + b × 起始值          b<0 ⇒ 整体收敛；b>0 ⇒ 整体发散
     残差 = 实际变化 − 预测       |残差| ≥ 1σ ⇒ 位移超出整体效应可解释范围
     ```
     同时报告**离散度的时间序列**（IQR 比标准差稳健），看整体是在收敛还是发散。
   - **披露要求**：整体效应的量化结果（b、R²、离散度变化）**必须写进结论**；
     「位移超出整体效应」的对象与「位移被整体效应解释」的对象**分开点名**。
     若该诊断是观察到分布异常后补做的，**必须标注为事后诊断**，
     与事前登记的门槛并列呈现，不得替换原判定。
   - **收敛回归的锚点效应**：首末端点回归以「起点」为锚。若某对象的起点恰是它的谷底/峰值，
     端点检验只约束首末变化，**对近端（最后 2–3 期）从峰/谷的回落/反弹没有约束力**。
     此类对象必须并报近端斜率（如近 3 期 Sen / rel 斜率），把「端点符合收敛」与
     「近端走弱/走强」**同时披露**，不得用前者否定后者——
     「末期比五年前更好」与「最近两年在持续下滑」可以同时为真。
     （2026-09 个案：徐教院附中 rel −10.5→−3.0 端点符合收敛，
     但 2024→2026 为 +8.6→+1.5→−3.0 连续下行、近 3 年 −5.8 分/年。）
   - **不做的后果**：把系统性变化误报成 N 个个案变化，
     且系统性变化的方向会让「表现最好的一批」被描述成「在退步」。

## 六、反模式

- 只给结论不给过程
- 用「数据表明」代替具体数据
- 只挑支持既有观点的样本（挑选性偏差）
- 把相关性表述为因果
- 用百分比掩盖样本量（「上涨 30%」但样本只有 3 个小区）
- 把挂牌价当成交价
- 结论与数据文件脱钩，无法回溯
- **用「最近一期的异常值」当作趋势**：单期跳变在只有 5 个时点时与「结构性变化」
  无法区分。应写成「典型期处于 X、末期出现极端值，成因未明」，不得写成「水平下滑」。
- **用 5 个时点的方差给对象排序**：方差在小样本下噪声极大，
  只能用来分「稳定 / 中等 / 很不稳定」三档。
- **把均值与中位数的背离直接解读为「不稳定」**：先回看逐年数值，
  判断是「单期异常」还是「长期漂移」，两者的结论完全不同。
- **在口径变更的时点上做跨期连线**：参与对象集合变化、纳入口径变化
  （如某年起新对象被纳入）都会造成台阶式跳变。必须标注断点，不得连成趋势线。
