# 结论可靠性验证规范

> 本文是工作流 2.4 的执行标准。核心要求：**主动寻找能推翻结论的证据**，
> 而不是复核结论是否「看起来合理」。

---

## 一、九个验证维度

| # | 维度 | 验证内容 | 不通过判定 |
|---|------|----------|-----------|
| 1 | 计算复核 | 关键指标独立重算（抽样或全量），与草稿比对 | 任一处数值不一致且无法解释 |
| 2 | 口径一致 | 结论使用的口径与 `design.md` 一致，未中途偷换 | 存在未声明的口径变更 |
| 3 | 数据链路 | 每个数字可回溯到已通过 2.2 校验的文件与字段 | 任一数字无法定位来源 |
| 4 | 样本代表性 | 样本量是否足够；是否只覆盖少数小区/学校；时段是否有偏 | 结论依赖的样本明显不足或系统性偏向 |
| 5 | 对比基准 | 溢价/涨幅类结论的基准是否合适（同区域、同房龄、同时点） | 基准不可比或未声明 |
| 6 | 因果警惕 | 相关性是否被表述为因果 | 出现无检验的因果断言 |
| 7 | 反向证据 | 是否存在与结论冲突的数据；是否被忽略 | 存在被忽视的反向证据 |
| 8 | 稳健性 | 换一个合理口径/剔除极端值后，结论方向是否仍成立 | 结论对口径或个别样本高度敏感而未说明 |
| 9 | 局限声明 | 不确定性、数据缺口、政策变动风险是否显式写出 | 缺少局限声明或声明与实际风险不符 |

---

## 二、验证方法（必须真正执行）

1. **独立重算**：不要复用 2.3 的计算过程，用不同路径（换工具/换聚合顺序/手工抽算）得到同一指标。
   **「独立」的最低标准是另写一份实现，且不 import 2.3 的构建脚本**——
   调用 2.3 的函数重算一遍，结果必然相同，那不是验证，是自我确认。
2. **抽样回源**：从结论中的每个数字出发，反向打开数据文件与来源登记表，逐跳核对。
   **必须同时打印 `source_doc` + `source_page` 并确认它能定位到那一格**——
   数值相等与页数指得准是两件事。
3. **敏感性测试**：至少做一次「换口径」或「剔除极端值」的重算，记录结论是否翻转。
   逐年对照主口径与辅口径的 Top/Bottom，**逐条写明哪些年份不一致、不一致是否可归因**。
4. **时间加权敏感性**：换权重方案（等权/线性/指数）重算，报告**偏移量的中位数与最大值**，
   并单独说明偏移最大的样本。若偏移最大的几个样本的异常期都落在**同一期**，
   须指出「加权把该期噪声放大了」。
5. **红队提问**：站在反对者立场问：
   - 「如果我不同意这个结论，我会拿哪条数据反驳？」
   - 「有没有一类样本被系统性排除在外？」
   - 「这个数字如果是错的，最可能错在哪里？」
   - 「同一个数在别的年份/别的口径下会不会不支持我的结论？」
6. **反证注入**：构造一个「语义上应当被判定为不可靠」的结论样例，确认验证流程能标记出问题
   （验证流程本身也需要被验证）。

## 四、反模式（出现即判为未验证）

- 只复核了「结论是否与草稿一致」，没有独立重算
- **伪独立重算**：调用 2.3 的构建脚本/函数重算一遍当作「独立验证」
- **在文档里写「已独立重算，误差 0」，但重算脚本 import 了构建脚本** ——
  这类自述必须能指出**两个实现确实互不依赖**，否则等于没做
- **把「统计上稳健」当成「归因上专属」**：多方法一致 + 留一法 + 换窗 + 换基准
  只能证明变化不是噪声，**不能证明变化属于该对象**。
  若全体存在系统性位移（收敛/发散/共同趋势），必须再做一步扣除整体效应的诊断，
  否则会把系统性变化误报成 N 个个案变化（本项目的收敛现象即此类）
- 验证者引用了 2.3 的中间结果当证据（循环验证）
- 「数据一致、格式正确」当作「结论可靠」——那是 2.2 的范围
- 只验证最主流的结论，忽略次要但对外发布的结论
- 敏感性测试只做了「不会翻转」的那一种口径
- **只比数值不验定位**：抽查时确认了值相同，却没打开 `source_page` 看那一格是否真在那里
- 把「找不到反证」当成「结论成立」（可能只是没去找）
- 验证结论直接写「通过」，没有逐维度证据
- **把「不需要改结论」当成「不需要写验证记录」**——验证的过程本身要留痕，
  尤其是那些「看起来可疑、查完发现没事」的项（如异常值、口径分歧），
  它们是后续复核的锚点

## 五、必须显著标注的情况

以下情况不一定要推翻结论，但**必须**在结论中显著标注：

- 样本量 < 20 个对象
- 覆盖居委/片区 < 全部对口范围的 50%
- 数据时点距当前 > 6 个月
- 存在已确认但未修复的数据缺陷（降级使用）
- 关键依赖来自非官方来源
- 结论对口径高度敏感（换口径即翻转）
- 相关规划尚未落地
- **期间存在口径变更断点**（参与对象集合变化、纳入口径变化等）——
  必须写成「某年起的台阶是口径变更，不是趋势」，并在结论处复述一次
- **存在改名/合并的实体**——必须写明「同一编号的旧名是 X、现名是 Y」，
  否则读者会把同一实体读成两个
- **某样本的极端表现只出现在最后一期**——必须写成「典型期处于 X、末期出现极端值，
  成因未明」，不得写成「水平下滑/提升」
- **某样本的均值与中位数大幅背离**——必须给出两者，并说明背离来自哪一期
- **对「预期会失真」的假设做了实测且实测未复现**——必须如实写出「实测未复现」，
  这本身是有信息量的结论，不得省略或改写成符合原假设的表述
- **样本间存在整体性位移**（收敛 / 发散 / 共同趋势）——必须量化并披露
  （变化量对起始水平的回归系数与 R²、离散度的时间序列），
  且把「位移超出整体效应」与「位移可由整体效应解释」的对象**分开点名**。
  典型误报：整体收敛被写成「排名靠前的一批在退步」
- **同一批对象里「靠前的全在降、靠后的全在升」**——这是整体性位移的典型症状，
  发现该分布时必须先查整体效应，再谈个案
