# Implement：嘉定区名额分配到校初中水平分析（2022–2026）

执行顺序严格按 Phase 2：**2.1 采集 → 2.2 校验 → 2.3 分析 → 2.4 验证 → 2.5 网页化**。
每步「判定标准」不满足即**不得进入下一步**。

## 2.1 数据采集与整理

| 步 | 内容 | 判定标准 |
|---|---|---|
| 2.1.1 | 采集名额到校计划 PDF **4 份**（2023–2026，取附件直链）；**2022 年为图片、待补全表**，登记 URL/发布时间/MD5 | 4 份下载成功且 MD5 登记；每年文本层可抽取（`fitz.get_text()` > 500 字符）。**回滚点**：某年 404 或图片版 → 记缺口，改用转载页并显式标注二手 |
| 2.1.2 | 采集初中名录（校名/代码/公办民办） | 覆盖分数线与计划中出现的全部初中；缺项逐一登记 |
| 2.1.3 | 分数线 PDF → `名额到校最低分数线-嘉定区-2022-2026.csv`（复用普陀的表头定位 + 块边界抽取法；2022 已入库） | 5 年全部非空对抽出；每行带 `source_doc`+`source_page`；逐年表头措辞差异登记不静默归一 |
| 2.1.4 | 计划 PDF → `名额到校计划-嘉定区-2023-2026.csv`；2022 若补全则另存 `-2022-图片转录.csv` 并标注二手 | 每年行内求和自洽；有名额无分数的对须标注；2022 无法补全则该年不做名额加权 |
| 2.1.5 | 校名归一 + 别名表 | 同一 `code` 唯一规范名；`code` 冲突即阻断 |

## 2.2 数据正确性校验（**门禁**）

| # | 维度 | 判定标准 |
|---|---|---|
| 1 | 逐格回源 | 分数线与计划**全量**回源 PDF（表头定位列 + 块边界 + 多重集三重比对），不一致数 = 0 |
| 2 | 计划行内自洽 | 每年分列求和 = 总计，不等数 = 0 |
| 3 | 分数-名额交叉 | 无「有分数无名额」对；**「有名额无分数」对逐条登记**（2022 已知：多校在交大附中嘉定分校有名额但无分数线 → 须以计划表与分数线交叉确认，并判断是「无人达线」还是数据缺失） |
| 4 | 取值域 | 600 ≤ min_score ≤ 750，越界数 = 0 |
| 5 | 名额占比离散 | 同线占比极差 < 0.25；超阈值的线单独说明 |
| 6 | 年份结构 | 逐年校数/线数/名额总数与公告一致 |
| 7 | 校名归一 | code↔规范名一对一 |

不通过则回 2.1 修正，**禁止**在 2.3 用填补值绕过。产物：`validation/data-validation.md`。

## 2.3 分析与结论产出

| 步 | 内容 | 判定标准 |
|---|---|---|
| 2.3.1 | 建宽表（design §2.3 全部指标列 + `years_included`） | 列齐全，逐年列数 = 5 |
| 2.3.2 | 按 design §2.4 落实主口径：**当年全部区属市重点线的名额加权均分**（2022 1 条 / 2023–2024 2 条 / 2025–2026 3 条），委属线排除 | 逐年线清单与线数登记；口径扩容年（2023、2025）标为结构断点 |
| 2.3.3 | 头/尾分组：**仅 2025–2026 做**（3 条区属线，取最高 1 + 最低 1） | 2022–2024 须显式标注「线数不足，分组不可用」，不得沿用普陀分组结论 |
| 2.3.4 | 主表（n≥3 过滤）+ 敏感性（单指标 × 时间权重） | 主表年数标注齐全 |
| 2.3.5 | 结构分析：规模分档、规模与位次（跨样本 + 同线内两层检验）、单线视角、结构断点 | 规模相关须报带符号 ρ + n |
| 2.3.6 | 趋势与收敛：逐年 IQR、收敛回归、残差 z 名单、SEN | 单线口径下 IQR/收敛解读须谨慎（见 design 偏差表） |
| 2.3.7 | **指标有效边界**：名额占比校际离散 → 切点深度（标注估算）→ 待补数据清单 | 切点深度必须给出无外部假设口径 |
| 2.3.8 | **与普陀结论的异同表**（3 条结论逐条给复现结果 + 原因） | 复现与否都要落盘 |
| 2.3.9 | 报告 `分析报告.md` + `index.html` + 排序表图片 | 结构对齐普陀；局限声明含缺失年份与切点深度 |

## 2.4 结论可靠性验证（**门禁**）

- 从原始 PDF/CSV **独立重建**关键指标（**不 import 2.3 脚本**），逐项容差比对。
- 九维度逐条记录（格式参照普陀 `conclusion-review.md`），其中**反向证据**与**稳健性**两栏必须有实质内容。
- 至少 1 项**跨区结论的独立复算**（普陀结论在嘉定的方向）。
- 产物：`validation/conclusion-review.md`。不通过则回 2.3，**不得先出网页**。
