### 2.3 派生指标口径

设某校某年可取到分数的区属线集合为 \(H_c\)，名额为 \(q_{c,h}\)。

| 指标 | 定义 | 角色 |
|---|---|---|
| `mean_score_wq_{y}` | \(\sum_{h\in H_c} q_{c,h}\cdot s_{c,h,y}\ /\ \sum_{h\in H_c} q_{c,h}\) | **主口径** |
| `mean_score_eq_{y}` | \(\sum s / \lvert H_c\rvert\) | 对照 |
| `rel_y` | `mean_score_wq_y` − 当年全池中位 | 跨年可比（去年度难度） |
| `P_wq_{y}` | 加权均分在当年全池中的分位 \(1-(r-1)/(n-1)\) | **排名主指标** |
| `Z_wq` / `ZR_wq` | 标准化 / 稳健标准化 | 辅 |
| `P_comb` | \((P_{全身}+P_{头部}+P_{尾部})/3\) | **主排序** |
| 头部 / 尾部组 | 当年按**线难度**（该线全区名额加权均分）排序取最高 2 / 最低 2 条区属线 | 分组口径 |
| `SEN` | `rel` 对年份的 Sen 斜率 | 趋势 |
| `years_included` | 有分数的年份数 | **排名过滤依据（入榜 n≥4）** |

## 2.4 排名口径（**按用户确认的口径：区属市重点全部纳入**）

实测的线结构（`design.md` §2.1 口径，逐年登记）：

| 年 | 区属市重点线 | 委属线（排除出排名口径） |
|---|---|---|
| 2022 | 嘉定一中 | 上海中学、华师大二附中、复旦附中、上师大附中、交大附中本部（各 1–3 所初中） |
| 2023 | 嘉定一中、**交大附中嘉定分校** | 同上 |
| 2024 | 嘉定一中、交大附中嘉定分校 | 同上 |
| 2025 | 嘉定一中、交大附中嘉定分校、**上师大附中嘉定新城分校** | 同上 |
| 2026 | 嘉定一中、交大附中嘉定分校、上师大附中嘉定新城分校 | 同上 |

**主口径（用户确认）**：

- `mean_score_wq_y` = **当年全部区属市重点线**的名额加权平均
  （2022 = 嘉定一中单线；2023–2024 = 2 条；2025–2026 = 3 条）
- 委属线**排除**出排名口径：每年仅 1–4 所初中有名额、每格常仅 1 个名额，
  参与次数与学校规模强相关（普陀实证 ρ=+0.67），进排名会变成「规模优势」而非水平。
- 头/尾分组：**仅 2025–2026 可做**（3 条区属线，取最高 1 + 最低 1）；
  2022–2024 因线数不足，只报「全身」单一口径，**分组结论须标注不可用**。

**必须随年报出的口径说明**（防止误读为「同一批线」）：

1. 区属线**逐年增加**，因此「区属加权均分」的含义逐年变化（1 条 → 2 条 → 3 条）；
2. 因此**跨年比较只使用 `rel`（相对当年中位的分差）与分位**，不得直接比较加权均分原值；
3. 名额按规模比例分配 → 新增线会使各校切点变浅，**新增线本身是结构断点**，
   2023 与 2025 各有一次口径扩容，须在趋势分析中断点标注。

## 3. 对比基准

- **跨校**：同年内全区池内分位（消除年度难度与池变化）。
- **跨年**：`rel` 与分位，**禁止直接比较原始分数线**（名额到校线含综合考查且逐年难度不同）。
- **跨区**：与普陀**只做方向性对照**，不比数值；差异登记于「与普陀结论的异同表」。

## 4. 偏差来源（预判 + 应对）

| 偏差 | 应对 |
|---|---|
| ~~2022 起点缺失~~ **已解决** | 2022 分数线已由区级来源补齐，窗口与普陀对齐 |
| **1 条区属线** → 无法做分组口径 | 见 §2.4；主口径降为单线，委属线只作个案观察 |
| 单线噪声（每校每年 1 个名额） | 单线排名须与 5 年聚合、分位并列；披露单年极差 |
| 5 年样本 → 「全勤」样本量有限 | 主表按 n≥4 过滤并标注年数；结构断点逐年披露 |
| 名额按「符合资格的报名人数」比例分配 | 用嘉定各线名额占比的**校际离散度**实证「切点分位是否恒定」；离散大的线标注机械效应风险 |
| 郊区导入人口 → 规模年际波动 | 规模与位次关系**必须分层检验**（跨样本 + 同线内），报带符号 ρ + n |
| 最低分是小样本极值（每线每校每年可能仅 1–2 个名额） | 单线视角只用于个例与趋势；主排序用跨线聚合 |
| 招生学校名单逐年变动（新校/撤并） | 逐年登记并披露；线难度排序随之变动 |
| 校名更名 / 一校多名 | 别名表 + 代码双重校验，代码不一致即阻断 |
| **委属本部 vs 区属分校同名族**：分数线中「上海交通大学附属中学」（本部，委属）与「…嘉定分校」（区属）、「上海师范大学附属中学」（本部）与「…嘉定新城分校」（区属）并存，且**单元格跨行拆分**（`…嘉定分` + `校`） | 2.1.3 抽取必须用坐标法做**跨行拼接**后再判定归属；别名表须带「本部/分校」标记与代码；数量对不上即阻断 |
| **2022 计划为图片 + 二手来源 + 截断** | 不得当作官方一手数据；若无法补全，2022 年**只用分数线做单线分析**，名额类指标标「2022 计划缺失」 |
| 委属线名额极少（普陀为 1 个/格） | 委属线不参与排名口径，仅作个案观察；不得用于「谁最好」的证据 |
| 池含民办初中 | 排名池是否含民办须在报告中明示（普陀含民办，民办因 n<4 未入榜但参与分位池） |

## 5. 验证设计

**2.2 数据正确性校验（七维度）**

1. 逐格回源：分数线与计划**全量**（非抽样）回到 PDF，用「表头定位列 + 块边界（不出现其他初中校名）+ 多重集校验」三重比对（普陀已验证可行，脚本可复用改造）。
2. 计划表行内求和 = PDF「总计」列。
3. 分数线与计划**交叉校验**：有分数的对必须有名额；有名额无分数的对须为 0 名额或「无人达线」。
4. 分数取值域：600 ≤ `min_score` ≤ 750。
5. 名额占比校际离散：同区属线占比的极差应 < 0.25（普陀实测 0.10–0.17），超阈值须人工核查分配政策。
6. 年份结构：逐年学校数、线数、名额总数须与公告一致。
7. 校名归一：同一 `code` 在 4 年内对应唯一规范名。

**2.4 结论可靠性验证（九维度）**

- **计算复核**：从原始 PDF 独立重建全部关键指标，容差内全一致（不 import 2.3 脚本）。
- **口径一致**：`design.md` ↔ `prd.md` ↔ 报告三方对照。
- **数据链路**：每个报告数字可回溯到文件 + 字段。
- **样本代表性**：4 年窗口与全勤样本量的检验力评估；郊区规模波动的影响。
- **对比基准**：跨区只做方向性对照。
- **因果警惕**：不把名额规模与位次的关联表述为因果。
- **反向证据**：主动搜索与主结论冲突的学校/年份（如规模最大校是否位次靠后）。
- **稳健性**：至少 3 组敏感性（时间权重 × 单指标口径 × 样本过滤）。
- **局限声明**：含缺失年份、切点深度、缺统招数据、委属线不可用等。

**必做的跨区对照（无论结果如何都要落盘）**：普陀的 3 条关键结论在嘉定的复现结果 ——
① 名额越多位次略好（负相关）；② 切点落在全校前 2%–5%；③ 存在系统性收敛。
**复现或不复现都要写入报告的「与普陀结论的异同表」**，并给出原因分析。

## 6. 局限声明（草稿，进报告）

1. 窗口 5 年（2022–2026），与普陀对齐；**2022 年为区级发布、仅存附件直链**（原公示页 404），引用须注明。
2. **区属线逐年增加（1→2→3 条）**，与普陀「4 条稳定并行」不同：跨年只有 `rel` 与分位可比，加权均分原值不可跨年比较；头/尾分组仅 2025–2026 可用。
3. 委属线每年仅 1–4 所初中有名额、每格常仅 1 个名额，**排除出排名口径**，不可用于校际比较。
4. 指标只覆盖名额到校通道，**只测到每校最前面约 2%–5% 的学生**（量化值以嘉定数据为准），不足以判断学校整体好坏。
5. 名额按符合资格的报名人数比例分配 → 切点分位大体恒定，但**各线占比的校际离散度**决定机械效应强弱，需实证。
7. 名额到校是**志愿填报制**，各校名额批次的实际构成为未知量，「切点深度」只能估算。
8. 初中名录的公办/民办归属为初判，待公开名录核实。
9. 郊区导入人口导致规模年际波动，跨年比较须同时披露规模变化。
10. **委属线校名跨年不一致**（交大附中本部 / 嘉定分校），须在别名表区分；2022 计划为二手图片来源，2022 与 2023–2026 的名额口径不完全可比。
