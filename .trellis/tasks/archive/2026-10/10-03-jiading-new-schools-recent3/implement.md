## 3. 2.2 数据正确性校验（门禁）

按 `.trellis/spec/quality/data-validation.md` 七维度执行，写 `validation/data-validation.md`：

| 检查 | 方法 | 判定标准 |
|---|---|---|
| C1 来源可回溯 | 4 所新校每行反查源 CSV 行号 | 全部可追 |
| C2 **逐格回源抽查** | 4 校 × 有成绩年份 × 各线，首/中/尾各抽 3 格回源 PDF/HTML 原文；**另抽 3 组归并校各 3 格** | **命中率 100%**，否则门禁不通过 |
| C3 数量守恒 | 逐年有分数学校数 27/28/35/38/39、分数线格数、名额格数 | 与改动前一致；全区校数 43 → 40 |
| C4 内部一致 | 复算 `quota3_y` 与 `mean_score_base3_wq_y` | 逐格相等 |
| C5 空值语义 | `row_type≠ranked` 行聚合列为空字符串 | 无 0 / NaN |
| C6 **无静默改数** | 除德富、嘉二实验两行的多年聚合列外，其余与基线逐格 diff | **零差异** |
| C7 归并判定有据 | 3 组别名的证据级别如实记录 | 可复现 |
| C8 **池子不变** | 各年参与分位计算的校数未变 | 27/28/35/38/39 |
| C9 **固定样本可复现** | Q2 的 27 所清单与逐年 `rel` 可独立复算 | 清单可导出 |
| C10 **分类规则可复现** | 阈值 1.10、判定优先级、28 所分类结果可由 CSV 独立算出 | 独立脚本复算一致 |
| C11 **唯一性：归并后无重复实体** | 同一实体跨年只占一行；`former_names` 中的旧名**不得**同时作为独立行存在 | 旧名 3 个均无独立行 |
| C12 **误合并断言（陷阱 8）** | 「上海外国语大学嘉定外国语学校」与「上海嘉定区世外学校」**必须各自独立存在**，行数、分数、名额均不交叉 | 两者均在宽表且数据无交集 |
| C13 **ownership 无空值** | 归并后 40 所的 `ownership` 全部命中枚举 {公办, 民办, 待核实} | 无空字符串（名录未同步的典型症状） |
| C14 **名录与宽表校数一致** | 归并后名录所数 = 宽表行数 | 差 0 或差异已书面解释 |
| C15 **可追溯性真做** | 抽查 5 条，`source_doc` + `source_page` 打开该页确认目标行真在那里 | 页码 ≤ 实际页数且行存在 |

**门禁**：C1–C15 全过才可进入 2.3。
