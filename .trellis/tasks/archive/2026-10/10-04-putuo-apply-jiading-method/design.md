# Design：普陀区按嘉定方法重做

> 方法参考嘉定，**数据与结论完全独立**；报告内不做跨区比较。

## 一、同一性判定：普陀用编号，嘉定用证据链

普陀宽表 44 行的 `junior_high_school_code` **全部非空**，这是与嘉定最大的方法差异 ——
嘉定该列整列为空，只能靠「官方名录页 + 名额结构比对 + 名称互证」三重证据链；
普陀**可以直接按编号核对**。

### 1.1 归并 A 组（代码级铁证）

```
071048  上海市曹杨第二中学附属实验中学   2023;2024;2025;2026
071048  上海市兴陇中学                 2022
```

**判定**：同一所学校改名（兴陇 → 曹二实验），**必须归并**。

**依据强度**：编号相同 = 代码级铁证，**不依赖名称相似度、不依赖外部搜索结果**。
外部信息（2023-09「普陀：兴陇中学更名为曹二实验」）只作**辅证**。

**实现位置**：`build_wide_pt.py` 的**读取阶段**做名称映射，使 2022 年数据挂到规范名上。
**禁止**在输出阶段合并 —— 否则 `score_*/quota_*_2022` 仍会挂在不存在的旧名行上。

**归并后**：规范名 = `上海市曹杨第二中学附属实验中学`（最新年份写法），
`former_names` = `上海市兴陇中学`，年份 2022–2026（**五年全勤**，`years_included` 4 → 5）。

**对池子的影响**：归并只改名字、不增删学校 ⇒ **各年参与分位计算的池子大小不变**（必须断言）。

### 1.2 别名表的错误要修正

`初中校名别名表-普陀区.csv` 现记：
`上海市兴陇中学 → 停办/退出待核实，去向待核实，不得猜测映射`

**该判断错误**：编号相同已是铁证，不属于猜测。改为：
`status=已归并`，`canonical_name=071048 曹杨第二中学附属实验中学`，
`remark` 写明依据为**学校编号一致**。

保留原表作为历史记录，新增一列 `evidence`（`code` / `name` / `external`）区分依据强度。

### 1.3 光新学校：退出，撤并状态**无依据**

- code `075044`，2022–2024 有数据，2025–2026 消失
- 编号 `075044` 在宽表中**只出现在这一行**，无重名 ⇒ **不是改名，是退出**
- ⚠️ **「已撤并」无依据**：别名表 `status = 停办/退出待核实`，
  `来源.md` 亦记为「3 所停办/退出待核实（光新、兴陇、武宁）——**去向不得猜测映射**」。
  仓库 `data/` 下**查无**任何政府文件提及光新撤并或其设备调拨。
  ⇒ 只能写「**退出，原因待核实**」，**不得写「已撤并」**

处理：`row_type = 'exited'`，**不参与任何排名口径**（它只有 3 年数据，本就 `ranked=0`），
在报告中作为「**退出（原因待核实）**」披露，与「民办排除」「短样本」分开陈述，
并明确标注「撤并/停招/转制均未核实」。

### 1.4 西校：有名额无分数，去向**完全无记录**（阻塞项）

code `075083`，**别名表与 2026 名录均无记录**，`来源.md` 亦未提。

| 项 | 事实 |
|---|---|
| 2022 名额 | 区属 48 个（华二普陀 4 / 二中 15 / 晋元 14 / 宜川 15） |
| 2022 分数线 | **0 条** |
| 2023–2026 | 完全不出现 |

`build_v3.py:243` 的 `COV(c) >= 1` 已将其正确排除在宽表外（44 行而非 45 行），
但**那 48 个名额从未进入任何分析**。须查清是「撤并」「改名」还是「分数线数据缺失」；
查不到则标 `ownership=待核实` 并在报告声明，**不得猜测**。

### 1.5 武宁中学：待查（阻塞项）

code `071042`，仅 2022 一年，2023–2026 无名额到校记录，但学校仍在
（2024 年有异地改扩建工程竣工报道）。

**必须先查清**是「停招初中」「转制九年一贯制」还是「退出名额到校」，
因为它决定 `ownership` 与 `row_type`，且**不能猜**。查清前该行 `ownership` 保持空并标注待核实。

## 二、字段设计

### 2.1 新增列

| 字段 | 位置 | 取值 |
|---|---|---|
| `row_type` | 宽表、总表 | `ranked`（入榜）/ `short_sample`（数据不足但仍在读）/ `exited`（退出，**原因待核实**）/ `excluded_private`（民办） |
| `junior_high_school_former_names` | 宽表、总表 | 归并前的旧名，`;` 分隔；显示名取最新年份写法 |
| `ownership` | 宽表、总表 | `公办` / `民办` / `待核实`（**不得留空**，空值会静默影响排名池） |

> 普陀特有：嘉定只有 `ranked` / `new_school` / `excluded_private` 三类，
> 普陀因有**退出校**与**多年短样本**两类，需四类，否则「消失」与「数据少」会混为一谈。

### 2.2 逐年派生列（普陀宽表当前缺失，需新建）

嘉定宽表有、普陀没有的：

| 列 | 含义 |
|---|---|
| `mean_score_base3_eq_{y}` / `_wq_{y}` | 该年两条链（等权 / 名额加权）的均分 |
| `rank_base3_eq_{y}` / `_wq_{y}` | 该年位次（**平均秩**，并列同名次、后续跳号） |
| `P_eq_{y}` / `P_wq_{y}` | 名额加权分位（主排序用） |
| `Z_*` / `ZR_*` | 标准分 / 稳健标准化分 |
| `rel_{y}` | 均分 − 当年公办池中位（跨年可比） |

**位次口径**：逐年位次用**平均秩**（`b + (e+1)/2`），
与嘉定 `build_v3_jd.py:170-175` 一致；**名次列**（多年聚合）也统一为平均秩，
避免嘉定那边「逐年用平均秩、名次用顺序秩」的双实现问题（该问题已记入 `spearman-tie-bug.md`）。

## 三、四个研究问题的算法

### 3.1 主排序（问题 1）

- 排名池 = **当年有数据的公办初中**
- `P_wq` = 名额加权均分在当年公办池内的分位，多年取**等权平均**
- 排除：民办（5 所）、退出校（光新 / 武宁 / 西校）、`years_included < 4`（短样本，理由见 3.3）
- 口径：`quota4_avg` = **区属 4 所基线线**名额之和（普陀与嘉定不同，见下方「与嘉定的口径差异」）；
  `rel` = 减当年公办池中位

> **⚠ 与嘉定的口径差异（不可照搬字段名）**
>
> | 项 | 嘉定 | 普陀 |
> |---|---|---|
> | 区属基线线 | **3** 所（嘉定一中 / 交大嘉定 / 上师嘉新） | **4** 所（华二普陀 / 曹杨二中 / 晋元 / 宜川） |
> | 名额字段 | `quota3_avg` | `quota4_avg` |
> | 委属线 | 5 所（不参与排名） | 5 所（上中 / 上师大 / 交附 / 华二 / 复附，不参与排名） |
>
> 普陀宽表**无 `quota3_*` 字段**（整列不存在），照搬嘉定脚本会静默取到空值。共 9 条线，
> 每条 2026 年覆盖 41 所；仅区属 4 条进排名口径。

### 3.2 差距是否缩小（问题 2）

**不能直接用全池离散度** —— 普陀公办池 31→36，新增学校若偏强会机械压低 σ（构成效应）。
方法与嘉定一致：

1. 固定样本 = **五年全勤**的公办校（归并后曹二实验进入该集合）
2. 6 个归一化指标逐年值：σ / CV / IQR / Gini / P90−P10 / 极差
3. 每年对 6 个指标做趋势检验，输出斜率、95% CI、p
4. **CI 跨 0 即判「无法判定」**，不得写成「没有缩小」
5. Q-Q 回归（2022 分位 → 2026 分位）：β<1 为向中心收缩，检验 H0:β=1
6. 量化构成效应：逐年输出「固定样本外学校的分位均值」

### 3.3 谁在上升谁在下降（问题 3）

- 斜率用**最小二乘**（与普陀现有 `SEN` 一致），阈值**预注册**
- **样本边界必须显式声明，且理由不止「年份少」**：

  | 障碍 | 事实 | 后果 |
  |---|---|---|
  | ① 斜率自由度不足 | 公办短样本 **4 所**：3 年 2 所（金鼎、上音安师）、2 年 2 所（梅陇实验、甘泉外国语），**无 1 年制** | Mann-Kendall 在 n=2 时 p 最小 0.5、n=3 时 0.28，连趋势存在性都无法检验 |
  | ② **名额基数过小（最致命）** | 这 4 所在区属 4 条基线线上名额**几乎全为 1**；对照江宁学校为 1–8 | 名额=1 时「名额加权均分」**退化成单条线的分数**，任何单线随机波动都被算成趋势（上音安师宜川线 2024=710→2025=686 即是） |
  | ③ 有额无线，跨年不同质 | 甘泉外国语 2025/2026 晋元、宜川**有额无分**；金鼎 2023 年 4 条线全部有额无线 | 该校某些年份的加权均分只由部分线贡献，**与其它年份不是同一个量** |

- **处置**：分类、收敛、显著性检验**一律只用 `years_included ≥ 4` 的 32 所**；
  4 所短样本校**单列披露**（只给逐年事实与名额基数，不给斜率、不进分类、不做显著性检验）
- 显著性：Mann-Kendall + Bonferroni 校正；**若仍 0 所显著，必须写明是检验力天花板**
  （n=5 时最小 p ≈ 0.028 > 校正后 α），不得省略
- 附「五年方向 vs 近三年方向相反」对照

### 3.4 代表性个案（问题 4）

选人标准**分析前预注册**：头部 = 主口径前 5；明显上升 = 阈值以上且 Δrel 最大 3；
明显下降 = 阈值以下且斜率最负 3。
每所含逐年表 + **事实与推断分离** + **至少一条反向证据**。
预印断言：入选名单变化时脚本必须**显式失败**，防止文案与数据错配。

> ⚠️ **执行中口径决定（D1–D7）见 `validation/caliber-decisions.md`**，与本节冲突时以该文件为准。
> 关键偏离：`recent3` 扩池至 34（D1）、`recent2` 存在并列（D2）、`rel` 基准池排除
> `exited` 校并统一趋势链口径（D3）、名额按 `merged_into` 排除（D4）。

## 四、口径结论的证据级别（普陀的弱点，必须如实标注）

已核普陀 **5 个年度**的名额到校计划文件，**全部是纯数据表**（标题为「…分配结果公示」），
**没有**「以…为测算依据」的规则说明文字。

嘉定有（2023/2024/2026 三年），普陀无。

因此普陀报告写「名额是学校规模的代理」时：

| 要素 | 普陀可写的表述 |
|---|---|
| 依据 | 上海市统一政策《上海市高中阶段学校招生录取改革实施办法》（沪教委规〔2021〕2 号） |
| 旁证 | 其他区公开计划文件中有同规则明文（须注明**非普陀本地原文**） |
| 数据旁证 | 各校名额占本线总额比例的**跨年稳定性**（普陀自行计算） |
| **禁止** | 不得写成「普陀区名额按…分配」（无本地原文） |

同时用普陀自己的数据做检验：若各校名额占比跨年稳定、跨校差异大，则与「按人数占比分配」一致。

## 五、三层校验脚本

| 层 | 覆盖 | 判定 |
|---|---|---|
| 1 逐格 | 宽表/总表每个数值 vs 源 CSV | 逐格一致 |
| 2 分节 | 报告各章数字 vs CSV | 一致 |
| 3 反向穷举 | 报告里每个小数须能追溯到 CSV 或已登记派生量 | 白名单外 0 |

**必须与生成脚本共用同一套秩实现**（平均秩）——
嘉定已因两套实现导致门禁「自洽地通过」却与标准不符（见 `spearman-tie-bug.md`），此处从一开始就统一。

## 六、风险

| 风险 | 处置 |
|---|---|
| 归并改变曹二实验的历史长度，进而影响排名与趋势 | 归并前后**各跑一次**，差异必须逐格可解释；池子大小须不变 |
| 短样本校（公办 **4 所** n≤3）混入统计 | 分类与收敛均只用 `years_included ≥ 4` 的 32 所；其余单列（理由见 3.3，含「名额=1 导致加权均分退化」） |
| 照搬嘉定字段名 `quota3` | 普陀为区属 **4** 线、字段 `quota4_avg`；`quota3_*` 整列不存在，取值为空且不报错 |
| 名额口径结论证据级别被夸大 | 报告显式写「非普陀本地原文」，并给数据旁证 |
|  tempted 引入与嘉定的比较 | 报告全文检索区名，出现即门禁失败 |
| 名录 41 所 ownership 全为「依校名初判」 | 排名池依赖它，须在局限声明中写明该证据强度 |
