## 4. 高中分层（区属 / 委属）

**判定依据**（两条并用，任一条单独不足）：

1. 计划表表头备注：「区属市实验性示范性高中的名额分配到校原则上以……**比例为测算依据**；
   **委属**市实验性示范性高中的名额分配到校具体分配方案以**均衡、随机为原则抽签确定**」
2. 名额分布形态：随初中规模变化 → 区属；普遍 1–3 且大量初中整列空白 → 委属（抽签特征）

**分层结果**（2026-09-30 核对）：

| 分层 | 高中 |
|------|------|
| **委属（排除，仅登记）** | 上海中学 `042032`、交大附中 `102056`、复旦附中 `102057`、华二附中 `152003`、上师附中 `152006` |
| **区属（纳入）** | 2022：市二中学 `042001`、南洋模范 `042008`、位育中学 `042035`、南洋中学 `043015`（4）<br>2023–2025：上述 4 所 + 复附徐汇 `042036`（5）<br>2026：上述 5 所 + 市二梅陇 `042002`（6） |

**固定基线 `BASE4`** = {市二中学 `042001`, 南洋模范 `042008`, 位育中学 `042035`, 南洋中学 `043015`}
—— 5 年全部存在，用于**跨年可比**。

## 5. 指标定义与计算方式

记 `P(c,h,y)` = 年 y 初中 c 在高中 h 的计划名额数；
`S(c,h,y)` = 年 y 初中 c 在高中 h 的最低分。

### 5.1 有效集合

```
ZONE(y)   = 年 y 的区属市重集合（见 §4）
E(c,y)    = { h ∈ ZONE(y) : S(c,h,y) 存在 }
E4(c,y)   = { h ∈ BASE4   : S(c,h,y) 存在 }
```

### 5.2 主指标一：区属均分（跨年可比，固定 4 校基线）

```
mean_score_base4(c,y) = Σ_{h∈E4(c,y)} S(c,h,y) / |E4(c,y)|
```
- **分母是有效对数**，不是名额数（避免缺分名额稀释）
- `|E4(c,y)| = 0` 时该格留空，不参与任何汇总

### 5.3 辅指标一′：区属均分（当年全量，仅当年内参考）

```
mean_score_all(c,y) = Σ_{h∈E(c,y)} S(c,h,y) / |E(c,y)|
```

### 5.4 主指标二：南模线（头部学生水平代理）

```
nanmo_score(c,y) = S(c, 南洋模范 042008, y)
```

### 5.5 排名

**平均名次法**（处理并列）：

```
rank(c,y) = 1 + #{ c' ∈ 公办初中, c'≠c : mean_score_base4(c',y) > mean_score_base4(c,y) }
            + ( #{ c' : mean_score_base4(c',y) == mean_score_base4(c,y) } - 1 ) / 2
```
- 名次**越小越好**；样本为「当年全部有效公办初中」
- `nanmo_rank` 同法，用 `nanmo_score`
- `mean_rank_all` 同法，用 `mean_score_all`

### 5.6 跨年汇总（只用共同子集）

**共同子集 `CORE`** = 2022–2026 **5 年都被收录且 5 年都有 `mean_score_base4` 的公办初中**。

对 `c ∈ CORE`：

```
rank_avg(c)    = mean{ rank(c,y) : y ∈ 2022..2026 }
rank_median(c) = median{ rank(c,y) }
rank_var(c)    = var{ rank(c,y) }          # 总体方差（除以 n）
```
`nanmo_rank_*` 同法。`quota_zone_avg(c)` = 5 年区属市重总计划数的算术平均。

### 5.7 时间加权

三种权重方案都算，用于敏感性：

| 方案 | 权重 `w_y` |
|------|-----------|
| 等权 | `1` |
| 线性 | `y - 2021`（2022→1 … 2026→5） |
| 指数 | `0.7^(2026-y)`（2026→1，2025→0.7 …） |

```
rank_w(c) = Σ_y w_y · rank(c,y) / Σ_y w_y      # 只对该校有数据的年份求和
```
样本仍限定 `CORE`。敏感性 = 三方案下排名的最大变动幅度。

### 5.8 规模分档

- 规模代理：`quota_zone_avg(c)`（**区属**市重总计划数）——
  不用委属名额，因为委属是抽签噪声；不用「全部高中合计」，
  因为区属名额本身按报名人数比例分配，是规模的线性代理
- 分档：对 `CORE` 按 `quota_zone_avg` 升序，取 1/3、2/3 分位数切三档（小 / 中 / 大）；
  阈值在产物中固定写出，事后不得调整
- 若任一档 < 5 所，改为两档（中位数切分）并在报告中说明

## 7. 偏差来源与局限声明（必须写进结论）

1. **分数线受当年试卷难度影响** ⇒ 跨年只用名次，不用原始分（D3）
2. **「最低分」是末位录取分**，受志愿填报博弈影响，存在「大小年」波动
3. **委属抽签已排除** ⇒ 顶尖学生去向信息不完整；南模线只是**代理**，不等于「头部水平」
4. **公办/民办划分来自 2026 年公示** ⇒ 2022–2023 的性质判定属跨年外推
5. **区属高中集合逐年变化**（2023 +复附徐汇、2026 +市二梅陇）⇒ 主口径固定 `BASE4`
6. **样本逐年进出** ⇒ 跨年汇总只用 `CORE` 共同子集
7. **计划数 ≠ 实际录取数**（官方未公布实际录取数）
8. **2022 无「是否同分优待」列、2025 起才有「综合素质评价」列** ⇒ 相应字段留空
9. 分析只覆盖**徐汇区**，结论不得外推到其他区

## 9. 趋势分析（追加，2026-09-30）

> 本节为 R5 的口径与算法，追加于原设计之后，编号接续，不改动 §1–§8。

### 9.1 趋势度量口径（强制七段式的「口径契约」）

**为什么不用「当年内名次」**：名次是相对当年全体的序数，一所学校里外挪一名会牵动全表。
实测（23 所 CORE）：**去掉最新一年后，名次口径下 20/22 所方向翻转**，
分差口径下仅 5/22。名次口径的趋势结论不可用。

**主口径**：

```
rel(c,y) = mean_score_base4(c,y) − median_{c' ∈ CORE}( mean_score_base4(c',y) )
```

- **单位「分」**，正 = 高于当年 CORE 中位
- **基准用固定集合 `CORE`**（五年全勤的 23 所公办）而非「当年全部有效公办」，
  以消除样本进出带来的基准漂移
- 逐年实测 CORE 中位：`728.62 / 725.25 / 726.50 / 728.12 / 739.12`
  ⇒ 2026 比 2022 高 **10.5 分**，再次印证原始分不可跨年直接比较
- **保留原始分的量级信息**，因此「分差变化 1-2 分」这类信息不会被名次的整数化吃掉

**已知局限**：假定「当年难度差异对全体学校是近似平移的」。若难度变化对高分段与
低分段影响不同（天花板效应），减中位不能完全消除。⇒ 必须与名次口径**并列互校**，
两者方向不一致的学校不得列入结论。

### 9.2 三个趋势统计量

| 量 | 定义 | 作用 |
|---|---|---|
| `sen` | Theil–Sen 斜率：全部 10 个点对斜率的**中位数** | 主趋势方向与幅度（分/年）；对单期异常稳健 |
| `spearman` | 年份与 `rel` 的 Spearman 秩相关 | 单调性；与 `sen` 同号才认为方向可信 |
| `sen_drop26` | 仅用 2022–2025 的 Theil–Sen 斜率 | 去尾敏感性 |

### 9.3 严格三重判定（R5.3）

**三条全过才判「有趋势」**：

1. **方向一致**：`sign(sen) == sign(spearman)` 且 `|sen| ≥ 幅度阈值`
2. **去尾不翻转**：`sign(sen_drop26) == sign(sen)`
3. **非单年驱动**：**留一法**——分别删去 2022…2026 各一年后重算 Sen，
   5 个结果的符号**全部**与 `sen` 一致

> 条件 ② 被条件 ③ 蕴含（删去 2026 即留一法之一）。保留 ② 是因为它单独可读，
> 且是「最新一年是否主导结论」的直答；但**判定以 ③ 为实质门槛**。

**幅度阈值**：`|sen| ≥ 1.0 分/年`（5 年窗内累计约 4 分）。
取值理由：该校均分的排名尺度上，1 分已足以改变名次；低于 1 分/年的变化
在 5 个时点下无法与噪声区分。**阈值在计算前写定，事后不得调整**。

**未通过者必须列出并写明卡在哪一条**（R5.4）——
否则读者无法判断是「真的没趋势」还是「门槛太苛刻」。

### 9.4 与既有结论的对照（R5.6）

每所 CORE 初中输出四元组：`(历史平均排名, 趋势方向, sen, 是否通过判定)`，
重点点出两类组合：

- **历史排名靠前但趋势向下**（如某校均名第 2 却在相对下滑）
- **历史排名靠后但趋势向上**（如某校均名第 21 却持续改善）

### 9.5 中止 / 降级条件（追加）

| 触发 | 处置 |
|---|---|
| 分差口径与名次口径方向不一致的学校 > 1/3 | **降级**：不出「有趋势」清单，只出逐年相对分差明细，结论改写为「5 个时点不足以判定趋势」 |
| 通过严格三重判定的学校 < 3 所 | 报告写「本窗口内未检出可靠趋势」，不得为凑数放宽阈值 |
| 某校 `rel` 序列出现无法解释的跳变（如同一校相邻年差 > 20 分） | 该样本单独标注，先回查原始数据再纳入 |
