# 设计：普陀报告重构

## 三组口径与综合口径

| 组 | 基线高中 | 逐年指标 | 跨年聚合 |
|----|----------|----------|----------|
| 全身 `all` | 华二普陀/曹杨二中/晋元/宜川（4 所） | 可得线均分 → 当年池内名次 → 分位 `P_it` | 等权均值（= 既有主口径 P） |
| 头部 `head` | 华二普陀/曹杨二中（2 所） | 同上 | 同上 |
| 尾部 `tail` | 晋元/宜川（2 所） | 同上 | 同上 |
| **综合** `comb` | — | — | `P_comb = (P_all + P_head + P_tail)/3` |

- 排名池：当年有该组数据的**全部初中**（含民办），与既有 base4 口径一致。
- 逐年样本量：all 34/33/40/41/41；head 34/33/40/41/41；tail 34/33/39/40/40（2025–26 宜川少 2 所）。
- **每校每年每组的名额只有 1–5 个 → 头部/尾部组是极小样本极值**，这一点必须写进表下注与局限。

## 合成规则的定位（价值判断登记）

`等权三组 P` 是用户选定的方案，含义是：**尖子层（顶线）与中后段（低线）同等重要**。
报告必须显式写明这是**分析者的价值判断**，并给出替代方案的对照：

- 头部加权（如 35/40/25）下梅陇更高、晋元附校略降；
- 组内名次平均（名次平均而非 P 平均）会抹平「偏科」信息（梅陇头部第 2 / 尾部第 10）。
- 按规范：**主排序用综合口径，但三个分组名次必须并列披露**，差异即「口径不确定性」。

## 实施方式

1. **计算**：`工具/multi_metric_pt.py` → `rank-多口径总表-普陀区-2022-2026.csv`
   - 三组 P 从原始分数线重算；`P_all` 自校验 vs `rank-标准化-普陀区-2022-2026.csv`
   - 单指标/加权列从既有 CSV **读取而非重算**（避免口径漂移）
2. **重排报告**：用 Python 汇编脚本
   - 从旧报告按标题锚点**抽取原样保留的块**（A5、A7、A2、A9.1–A9.4、A3/A3.1、A8、0、局限）
   - 新写的块（核心结论、1 章增补、2 章、3 章引言与合并、附录框架）单独成文件后拼接
   - 旧文件保留在 git 历史中，可随时比对
3. **图片**：`/tmp/build_rank_pt.py` 改为读多口径总表
4. **验证**：`validation/verify_multi_metric.py`

## 风险

- 汇编脚本按锚点抽取，**锚点若重复/缺失会静默丢内容** → 抽完必须打印各块长度并人工核对章节完整性；
- 旧报告中的交叉引用（「见 A5」「见 A9.5」）在重构后必须全部改为新章节号（AC7）；
- `build_html_pt.py` 的行首 `|` 死循环坑：新表必须带 `|---|` 分隔行。
