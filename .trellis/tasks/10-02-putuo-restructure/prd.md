# PRD：普陀报告重构（多口径总表 + 结论综合）

## 背景与用户决策

用户指出普陀报告「太乱」，并给出三条要求。经确认的决策：

| 决策点 | 选定方案 |
|--------|----------|
| 综合口径合成规则 | **等权三组 P**：`P综合 = (P全身 + P头部 + P尾部)/3` |
| 目录结构 | **6 章重构**，且**结论置顶** |
| 范围 | **只改普陀**（徐汇后续按同一范式再改） |

三组定义：**全身** = 4 所区属；**头部** = 华二普陀 + 曹杨二中；**尾部** = 晋元 + 宜川。

## 现状问题（核对后）

1. **口径内容分散五处**：A1（P/主表）、A2（规模）、A3/A3.1（加权）、A6（口径敏感性）、A9（单线/规模效应）。
2. **个案重复三处**：A4（全口径与梅陇现象）、A7（逐校个案）、A9.5（梅陇三分）。
3. **结论重复两份**：文首「核心结论」与文末「结论」内容同源。
4. **单一口径主导结论**：主表仅 base4 等权 P，导致梅陇（顶线全区第 1）显示为中游第 8，与常识/预期冲突。

## 目标

### 需求 1：多口径总表（核心交付）

新增 CSV `rank-多口径总表-普陀区-2022-2026.csv`，每校一行，含**得分与排名**：

- 结构组：`P_all / P_head / P_tail` + 各自名次
- 综合：`P_comb = (P_all+P_head+P_tail)/3` + `rank_comb`
- 单指标：`P / Z / ZR / 均名` + 各自名次（均从既有 CSV 取，不重算）
- 时间权重：`P_lin / P_exp / P_recent3` + 各自名次
- 元数据：`n_years`

报告第 2 章给两张表：
- **表 2-1 综合排名总表**：综合名次 | 初中 | P综合 | P全身(名次) | P头部(名次) | P尾部(名次) | 覆盖
- **表 2-2 单指标得分与名次对照**：初中 | P(名) | Z(名) | ZR(名) | 均名(名) | P线性(名) | P指数(名) | P近3年(名)

### 需求 2：报告重构为 6 章（结论置顶）

```
核心结论（唯一结论位置，基于综合口径）
局限声明
快速导航
1 数据与口径        ← 旧 0 + A1 口径定义 + Z/ZR/权重/三组的直白解释
2 排名总表          ← 新表 2-1 / 2-2 + 旧 A1 事实段 + 旧 A6 一致性结论
3 结构与异质性      ← 旧 A2（规模）+ 旧 A4（全口径）+ 旧 A9（单线视角与规模效应）
4 趋势与收敛        ← 旧 A5（原文保留）
5 逐校个案          ← 旧 A7（原文保留）+ 旧 A9.5 梅陇
附录 A 口径敏感性与稳健性 ← 旧 A3 + A3.1（加权）
附录 B 与徐汇结论的关系   ← 旧 A8
附录 C 验证记录           ← 指向任务验证文件
```

- **结论只保留一处**（文首），文末不再重复；「结论详解」并入核心结论的分组条目。
- 旧 A9.1–A9.4 归入第 3 章；A9.5 归入第 5 章个案。

### 需求 3：结论基于综合多口径

- 主排序表述改为**综合口径**（P综合），并**并列给出全身/头部/尾部三个名次**，说明分歧来源。
- 梅陇中学等「顶线强、底线弱」的学校，结论须反映其综合位置（预期由第 8 升至约第 7），
  并明确写出「综合口径把尖子层与尾部等权，是分析者的价值判断，已登记」。
- 原「第 8」类表述全部改为带口径的写法（如「综合第 7 / 全身第 8 / 头部第 2 / 尾部第 10」）。
