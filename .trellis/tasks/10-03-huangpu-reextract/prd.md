# PRD：黄浦名额到校分数线重抽（修复 PDF 版面漏行）

## 背景

用户核查 2023 年 PDF 后指出「不是 14 个初中」。复核确认：**2023 年 PDF 实为 18 所初中、168 条记录，
现有 CSV 只有 14 所 / 88 条，漏掉整整一半**。此前基于该数据产出的所有下游结论不可信。

## 要回答的问题

1. 黄浦区 2022–2026 年名额到校最低分数线，**官方 PDF 到底有多少条记录、多少所初中**？
2. 现有 CSV 漏了哪些、漏了多少？漏掉的是整所学校还是零散记录？
3. 漏抽的根因是什么，能否构造一个对 5 年都成立的**可判定**抽取器？

## 根因（已定位）

旧抽取器要求「初中名 + 招生学校 + 5 个分数」落在**同一个 y 行桶**（按 `round(y/3)` 分桶）。
但 PDF 中**名称垂直居中、分数贴基线**，两者 y 相差约 3px：

```
桶33 (y≈99) : x38:上海市格致初级中学 | x152:上海市格致中学 | x306:734 | x402:否 | x436:407 ...  ← 抓到
桶49 (y≈147): x303:735.5 | x402:否 | x433:403.5 ...                                        ← 名字在桶50，被丢
桶50 (y≈150): x38:上海市格致初级中学 | x152:上海市大同中学
```

名称较短时偶然同桶（抓到），较长或换行时落到相邻桶（丢弃）。**丢失是随机分布的**——
这比系统性漏掉某几所更危险，因为 CSV 看起来「有数据」。

## 数据范围

- 区：上海市黄浦区
- 年：2022–2026（5 年）
- 文件：`data/黄浦区/学校/【黄浦】【{年}】名额到校最低分数线.pdf`（5 个）
- 字段：`year / district / junior_high_school / senior_high_school / min_score / is_tie_preferred / s综合评价 / yw_sx / yw_math / yw_chinese / yw_comprehensive / source_doc / source_page / note`

## 口径要求

1. **列边界逐年探测，不得硬编码**。从每年表头行（`初中学校` / `招生学校` / `语数外` / `数学` / `语文` / `综合测试` /
   `录取最低分` / `是否同分优待`）的 x 位置推导列区间。
2. **记录 = 5 个分数列全部有值的行**。缺列的年份（如 2022 无同分优待）不因此丢记录。
3. **名称配对按同页最近 y（容差 ±8px）**，不要求同行桶。
4. **初中名用名录做最长匹配**，跨行换行由拼接流处理；水印/标题/表头/注 计入已知样板文字白名单。
5. **旧 CSV 只做对账，不做数据源**。新 CSV 全面重建。

## 验收标准

| # | 标准 | 判定 |
|---|---|---|
| 1 | 每年记录数 = 该年 PDF 中「5 个分数列齐全」的行数 | 独立重数两遍一致 |
| 2 | 每年初中标签数 = 记录数（100% 配上，无 `None`） | 断言相等 |
| 3 | 每年招生学校 100% 配上，y 偏移 ≤ 8px | 断言最大偏移 ≤ 8 |
| 4 | 初中列未匹配字符仅含白名单（标题/水印/表头/注），无未知校名残留 | 断言残留集合 ⊆ 白名单 |
| 5 | 新抽取 ⊇ 旧抽取，且**差异全部是新增行**，不得有「同 (初中,招生学校,年) 但分数不同」 | 逐格对账 |
| 6 | 计划表 ↔ 分数线交叉：计划中名额 >0 的 (初中, 招生学校, 年) 组合，分数线应存在 | 列出缺口并解释 |
| 7 | 门禁脚本覆盖以上 6 条，逐年独立断言（不假设 5 年同版式） | 全过 |
