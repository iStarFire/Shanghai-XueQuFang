## 步骤 4：数据正确性校验（2.2）

- 产出：`validation/verify_reextract.py`
- 命令：`python3 .trellis/tasks/10-03-huangpu-reextract/validation/verify_reextract.py`
- 逐年独立断言（不假设 5 年同版式）：

| 段 | 检查 |
|---|---|
| [1] 版面 | 5 年分数列聚类数 == 5；列锚点与 design.md §1 表一致 |
| [2] 记录完整性 | 每年记录数 == 独立重数（第二实现 `get_text("blocks")`）的行数 |
| [3] 配对 | 初中标签数 == 记录数；招生学校 100% 配上；Δy ≤ 8 |
| [4] 残留 | 初中列未匹配字符 ⊆ 白名单；水印词不在初中名中 |
| [5] 逐格对账 | 新 ⊇ 旧；同键 `min_score` 差异 == 0；新增数 == 漏记录数 |
| [6] 计划交叉 | 计划中名额>0 的 (初中, 招生学校, 年) 在分数线中存在；缺口须逐条列明 |
| [7] 字段规范 | `min_score` ∈ [0, 800]；`yw_*` ∈ [0, 150]；无重复键；`source_page` ∈ [1, 页数] |
| [8] 回归 | 旧 `analysis/` 目录中引用该 CSV 的产物已标记为需重跑 |

## 步骤 6：规范沉淀（3.3）

- 在 `.trellis/spec/data/` 追加两条：
  1. **PDF 表格抽取禁止「同行桶」假设**——名称垂直居中与数字基线可差数 px，
     必须按列锚点 + 最近 y 配对；且必须逐年探测版面，5 年 PDF 不可共用坐标。
  2. **抽取完整性必须用「记录数」而非「有无数据」判定**——黄浦 2023 丢 80/168 条，
     CSV 仍显示 14 所学校「有数据」，随机漏行会被误判为完整。
- 同时在质量校验规范补一条：**丢失必须是整行/整校，禁止随机漏行**。

## 风险与预案

| 风险 | 预案 |
|---|---|
| 2024/2025/2026 招生学校名落入初中列 | 用表头锚点定界；若仍重叠，改为「先按数值列锁记录行，再按 y 就近取名」，名不参与列判定 |
| 民办校名（明珠/立达/康德/永昌/震旦）在分数线表中缺席 | 断言「计划表校名 ⊇ 分数线表校名」，缺席只记录不报错 |
| 某年官方表本身不全（如 2023 曾疑 14 所） | 已证伪为抽取问题；若仍发现缺口，落到 `note` 并列入局限声明 |
| 新抽取与旧 CSV 出现同键分数不一致 | 视为严重缺陷，必须查明是旧抽取错还是新抽取错，不得直接采用新值 |
