## 2. 为什么不能沿用旧抽取器

旧抽取器的两个隐含假设都不成立：

1. **同行桶假设**：「初中名 + 招生学校 + 5 个分数在同一 y 桶」——名称垂直居中，与分数基线差 3px，假设不成立。
2. **固定列边界假设**：用 `x<110 / 110–290 / >290` 划分三列——仅对 2023 成立；2024 起招生学校名落入 `x<110`，
   且水印「上海市教育考试院」也在该区域。

## 3. 抽取流程

### 3.1 逐年版面探测（`probe_layout`）

从每年**第 1 页表头行**取列锚点，而不是写死坐标：

| 锚点文字 | 用途 |
|---|---|
| `初中学校` | 初中列左边界 |
| `招生学校` | 招生学校列左边界 |
| `录取最低分` | 分数列区起点 |
| `语数外` `数学` `语文` `综合测试` | 4 个科目列中心 → 数值列边界 |
| `是否同` / `分优待` | 同分优待列（**2022 缺失，须容忍**） |

推导规则：
- 数值单元格 = x 落在任一分数列锚点 ±14px 内、且匹配 `^\d+(\.\d+)?$` 的词。
- 列区间 = 相邻锚点中点。锚点缺失时用**当年全部数值 x 的聚类中位数**兜底，
  并要求聚类数 = 5（4 科目 + 录取最低分）——不满足则该年判定为「版面未识别」，**直接失败，不猜**。

### 3.2 行聚类

`round(y / 3)` 分桶保留（用于聚合同一物理行的词），但**桶只用于「收集这一行的所有词」，
不用于判断「是否同一记录」**。

### 3.3 记录识别

一条记录 = 一个桶内**命中 ≥5 个数值列**（录取最低分 + 4 科目）。
按 `(页码, y)` 升序编号 `i = 0..N-1`。

### 3.4 名称配对（关键修正）

对每条记录，在**同页**所有桶中找「含非数字文本且 x 在招生学校列区间」的桶，
取 **y 距离最小**且 **|Δy| ≤ 8** 者。同理配对初中列。

预期与实际一致：2023 年实测 Δy 分布仅 `{0, 3}`，可作为配对正确的自证。

### 3.5 初中名识别

1. 取每年初中列（左边界 = `初中学校` 锚点 x，右边界 = `招生学校` 锚点 x）的所有非数字文本，
   按 y 升序**拼接成字符串流**，同时记录每个字符的 `(页码, y)`。
2. **水印剔除**：位于页面边缘（`x < 40` 或 `x > 页宽 - 60`）且文本 ∈
   `{上海市教育考试院, 市教育考试院, 考试院, 育考试院, 教育考试院}` 的词，不进流。
   2025/2026 实测存在多种被切碎的写法，故按**子串包含**判定而非精确相等。
3. **最长匹配贪心**：校名池按长度降序，在流上逐位尝试命中；命中则记录 `(校名, 首字 y, 页码)` 并跳过。
4. 命中数必须 **等于** 记录数（验收标准 2）；不等即失败。
5. 残留字符必须 ⊆ 样板白名单（标题、`注：…`、表头词、`初中学校`），否则失败。

校名池取自计划表 CSV 的 24 个规范名 + 曾用名（`大同初级中学（原黄浦学校）`、`上海市兴业中学`），
按长度降序。**不使用前缀/子串模糊匹配**——模糊匹配正是普陀/黄浦此前出错的来源。

### 3.6 字段落位

| CSV 列 | 来源 | 缺失处理 |
|---|---|---|
| `min_score` | 录取最低分列 | 必填 |
| `yw_sx` / `yw_math` / `yw_chinese` / `yw_comprehensive` | 语数外 / 数学 / 语文 / 综合测试 | 必填 |
| `is_tie_preferred` | 同分优待列 | **2022 官方无此列 → 留空**，并在校验中按年断言 |
| `s综合评价` | 综合评价列 | 2022/2024 官方注明均 50 分 → **填 50**（不是留空），2023 无此列 → 留空 |
| `source_page` | 记录所在页码（1 起） | 必填 |
| `note` | 该年缺失列的说明 | 如「2022 官方表无同分优待列」 |

### 3.7 与旧 CSV 对账

不把旧 CSV 当数据源，只做**差异报告**：

- 键 = `(year, junior_high_school, senior_high_school)`
- 分类：① 新增（旧无新有）② 缺失（新无旧有，应为 0）③ 同键但 `min_score` 不同（应为 0）
- 验收：②③ 必须为 0；① 的数量应等于「漏记录数」

## 4. 对比基准

不与外区对比。基准是**同一 PDF 的结构事实**（记录行数、列锚点、名称出现次数），
可用完全独立的第二实现（`PyMuPDF get_text("blocks")` 而非 `words`）复算交叉验证。

## 5. 偏差来源与局限

| 来源 | 影响 | 处置 |
|---|---|---|
| y 配对容差 ±8px | 若某年版面行距 <16px 可能错配 | 断言「Δy 分布只有 0 和 3」；若出现更大值须人工核 |
| 水印剔除按 x 边缘 | 若水印出现在正文区则剔不掉 | 断言水印词不出现在残留集合 |
| 校名池来自计划表 | 若分数线表出现计划表没有的新校名则无法匹配 | 断言残留 ⊆ 白名单；发现新名则先更新池再重跑 |
| 2022 无同分优待列 | 该年无法判断同分优待 | 字段留空 + 报告局限声明 |
| 2022/2024 无综合素质评价 | 官方注明均 50 分 | 填 50 并在 `note` 注明依据 |

## 6. 局限声明（须写入报告与 README）

1. 2022 年官方表**无「是否同分优待」列**，该年无法判断是否存在同分优待。
2. 2022 / 2024 年官方表**无「综合素质评价」列**，官方注明均为 50 分，已按 50 填入。
3. 抽取依赖 PyMuPDF 的文字坐标，**若官方后续重新排版 PDF，坐标假设失效**——
   故门禁必须逐年重新探测版面，不得复用历史坐标。
4. 分数线表只反映**末位录取考生**成绩，不等于学校整体水平。
