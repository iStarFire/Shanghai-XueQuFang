# Design：名额是规模代理的论证 + 近 2 年同池排名

## 一、Q1：名额是不是学校规模的代理

### 1.1 报告错在哪（三处独立错误）

| # | 报告的表述 | 错因 |
|---|---|---|
| 1 | 「嘉定名额按**志愿填报**分配」 | **误读原文**。原文是「符合填报…资格的中招**报名人数**」/「符合…资格**学生人数**」——「符合资格」是定语，「人数」才是被分配的依据；不是「按志愿填报意愿分配」 |
| 2 | 「占比极差 0.048–0.092 ⇒ **不是**规模代理」 | **检验方向反了**。各校占比不同，正是各校**规模不同**的直接体现。若各校规模相同，占比才会相同 |
| 3 | 「名额是**志愿热度/生源强度**的代理」 | **推论无依据**，且与「份额跨年稳定」相悖（热度会波动） |

另有一处**报告内部矛盾**：L236 写「**是招生规模**」，6.3 写「**不是学校规模**」。

### 1.2 正确的论证链

1. **规则层**：官方连续年份写明分配依据是「符合资格学生人数 / 中招报名人数」占全区的**比例**，
   「均衡、随机」是其原则。符合资格者 = 不选择生源初中在籍在读满 3 年的初三学生（2025 年原文）。
   ⇒ 名额在**定义上**就是「该校有资格学生数」的单调函数，即**学校规模的代理**。
2. **数据层**（本轮新算的旁证）：
   - 各校占比**跨年** CV 中位数 **0.135**（28 所中仅 3 所 > 0.25）⇒ 份额由**稳定因素**决定
   - 各校占比**同年跨校** 0.0290 ~ 0.0757（**2.6 倍**）⇒ 校际**规模**差异显著
   两者都与「按人数比例分配」一致，与「按志愿热度分配」不一致。
3. **推论层**（这是修正的要点）：
   - 既然名额是规模的代理，则**不能**用名额推断办学水平 —— 名额多只说明**学生多**
   - `Spearman(名额, P) = +0.534` 的解读相应改变：应是「**规模较大的学校，其名额到校通道的位次更靠前**」，
     可能来自绝对人数多带来的尖子更多（**容量效应**），**不是**「填报意愿强的学校生源更强」
   - 报告原先把「名额多」解读为「生源强/志愿热」，方向正好相反

### 1.3 必须避免的过度断言

- 本区**没有**各校初三学生数，因此**不能**直接验证「名额占比 = 人数占比」。
  只能说：**按官方规则**它由人数决定（定义层面成立），且现有份额数据（跨年稳定、跨校差 2.6 倍）
  **与该规则一致**。这属于「规则 + 一致性旁证」，不是「实测回归验证」。
- 「均衡、随机」原则意味着实际名额与严格比例可能有小幅调整，
  这可以解释部分份额波动（如 3 所 CV > 0.25 的学校），但不改变方向性结论。
- 不得反向断言「名额完全等于规模」——只能说它是规模的**代理**（单调相关，非等值）。

### 1.4 需要修改的位置（全文一致性）

| 位置 | 现状 | 修改方向 |
|---|---|---|
| 摘要 B 第 6 条 | 「不是规模代理 / 是志愿热度代理」 | 改为「**是**规模代理 ⇒ 不能用它推断水平」 |
| 3.1 解读段 | 同上 | 同步，并给出 +0.534 的新解读 |
| 6.3 节标题与正文 | 「名额占比不能当规模用」 | 改为「名额**是**规模代理，故不能当水平用」 |
| L236 指标说明 | 「是招生规模」——本就正确 | 保留，并确认与 6.3 不再矛盾 |
| 第 7 章证据表相关行 | 反向证据写「生源与填报意愿无法分离」 | 按新结论重写正/反向证据 |
| 摘要首行（L25 一带） | 「名额规模在此区是志愿热度而非学校规模的代理」 | 同步修正 |

## 二、Q2：近 2 年同池排名

### 2.1 口径定义（沿用既有）

`recent2 = {2025: 1, 2026: 1}`，即各校 2025、2026 两年 `P_wq` 的**等权平均**
（`P_wq` = 名额加权均分在**当年公办池**内的分位）。

### 2.2 池的变更（28 → 31）

- 现状：`ranks_of()` 只对 `TABLE`（28 所 = 27 所五年全勤 + 1 所四年校）排名
- 变更：`recent2` 一列的池改为「**有 2025 与 2026 两年 `P_wq` 的公办校**」= TABLE + 3 所新开办校 = **31 所**
- **代价（已实测）**：原 28 所中 **25 所**名次变动；须在报告中列出变动清单供核对
- **实现**：`ranks_of` 增加「按口径取池」参数，`recent2` 用扩池，其余口径维持 TABLE
  （避免顺带改动 lin/exp/recent3 的既有名次）

### 2.3 为什么不给新校补「近 3 年」

对这 3 所（只有 2025–2026）：`W_TIME['recent3']` 中 2024 权重为 1 但**无数据**，
按既有实现 `den` 只累加有数据的年份 ⇒ 其 `P_recent3` **恒等于** `P_recent2`。
若两列都填，读者会误以为它们有 3 年数据。因此**只补 recent2**，`recent3` 留空并在表注说明原因。

嘉一实验（仅 2026 一年）**两列都留空** —— 单年数据算不出"近 2 年的变化"。

### 2.4 输出层的清空规则调整

现状（`build_v3_jd.py`）：所有 `row_type != 'ranked'` 的行，`AGG_COLS` 一律清空。
变更：对该 3 所新校，**保留** `P_recent2` 与 `rank_P_recent2`，其余聚合列仍清空。
民办（`excluded_private`）**全部清空**，不适用。

### 2.5 表注必须写清

- 「近 2 年」列为 **31 所池**（含 3 所新开办校），与主排序的 **28 所池不同**，两者名次不可直接比
- 3 所新校只有 2 年成绩，其「近 2 年」值即其全部历史；嘉一实验仅 1 年，不参与

## 三、偏差来源与局限

| 项 | 说明 |
|---|---|
| 无各校学生数 | 无法直接验证「名额占比 = 人数占比」，只能依规则 + 一致性旁证（1.3） |
| 2022 年规则缺失 | 该年仅微信截图，OCR 不可用；引用官方原文时只用 2023/2024/2026 三年 |
| 名额数含「均衡、随机」调整 | 份额非严格比例，故称「代理」而非「等值」 |
| 池变更带来 25 所名次变动 | 属**预期结果**，不是错误；须列出变动清单并说明原因 |
| 小规模学校份额波动 | 3 所 CV > 0.25，源于名额基数小（个位数）导致的量化噪声 |

## 四、风险

| 风险 | 处置 |
|---|---|
| 改「规模代理」后，+0.534 的解读失控（如被读成「大校更强」） | 明确写成「容量效应的**可能**解释」，并保留「大校是否因规模而位次靠前，本数据无法分离容量与生源」 |
| recent2 扩池后有人误以为主排序也变了 | 表注 + 验收 A10 断言主排序逐格不变 |
| 改 `ranks_of` 时误改其他口径 | 验收须逐口径比对 lin/exp/recent3 名次**不变** |
| 3 所新校 recent2 名次高（第 4、第 7），被当作"新校很强" | 报告须同时给出「只有 2 年、名额少、单年波动大」的限制声明 |
