# PRD：按嘉定方法重做普陀区名额到校分析

## 硬约束（用户明确要求）

> **只参考嘉定的分析过程、方法与课题，不与嘉定做任何数据对比。**

因此报告中**不得出现**「普陀 X 比嘉定 Y 高/低」「两区差距」等跨区比较。
可复用：口径定义、四个研究问题的结构、指标算法、校验方法、脚本组织方式。
不可复用：任何数值、任何「嘉定的结论是…」的表述。

## 背景

普陀现有分析（2026-10-02）结构为「1 数据与口径 / 2 排名总表 / 3 结构与异质性 / 4 趋势与收敛 / 5 逐校个案」，
与嘉定当前的「四个研究问题」结构不一致，且数据层缺若干字段。本任务按嘉定方法重做。

## 已完成的事实核查（非待办）

- 排名池**已**仅公办（32 所入榜全为公办，5 所民办 2024 起出现并已排除）
- 已有 `初中校名别名表-普陀区.csv`
- 源数据完整：分数线 809 行、计划 1719 行，2022–2026 五年齐全
- **有 `junior_high_school_code`，宽表 44 行全部非空** —— 这是普陀相对嘉定的**关键优势**，
  可按编号核对同一性（嘉定该列整列为空，只能靠三重证据链）

## 要回答的问题（= 嘉定的四个研究问题，结构一致）

1. **总排名**：普陀公办初中的名额加权主口径排名
2. **差距是否随时间缩小**：固定样本 + 6 个归一化指标 + 置信区间 + Q-Q 回归
3. **谁在上升、谁在下降**：预注册阈值分类 + 显著性检验 + 五年 vs 近三年
4. **代表性个案**：头部 / 明显上升 / 明显下降

## 范围

**范围内**

1. 归并 A 组（同代码 071048），并修正别名表的错误判断
2. 查清武宁中学去向，据实填 `ownership`
3. 新增 `row_type`（入榜/新开办或短样本/民办排除/退出待核实）与 `junior_high_school_former_names`
4. 补建逐年位次与分位列（普陀宽表当前**没有** `mean_score_base3_wq_{y}` / `rank_base3_wq_{y}` / `P_wq_{y}`）
5. 按时间权重扩多口径（lin / exp / 近 3 年 / 近 2 年），并按口径取池
6. 报告重写为四个研究问题结构
7. 新建收敛指标表、趋势分类表
8. 三层数字校验脚本（逐格比对 / 分节核对 / 反向穷举）
9. 名额口径结论：**普陀本地 PDF 无规则说明文字**（已核 5 个年度文件，均为纯数据表），
   只能引上海市统一政策名称 + 其他区公开文件作旁证，并**如实标注这是旁证而非普陀原文**

**范围外**

- 不与嘉定做任何数据对比
- 不做房价、小区分析
- 不新增数据采集（除武宁去向外）

## 关键差异（普陀 ≠ 嘉定，方法要调整）

| 项 | 普陀 | 嘉定 | 处理 |
|---|---|---|---|
| 各年公办池 | 31/32/34/36/36 | 27/28/28/31/32 | 固定样本选法需按普陀实际年数分布定 |
| 民办出现 | 2024 起 5 所 | 2024 起 7 所 | 同口径排除 |
| 短样本校（**公办口径**） | **4 所**：3 年制 2（金鼎、上音安师）、2 年制 2（梅陇实验、甘泉外国语），**无 1 年制** | 0（入榜 28 所全为 4–5 年） | **趋势章的样本边界必须重新界定**；且这 4 所在区属 4 线上名额几乎全为 1，加权均分退化，见 `design.md` 3.3 |
| 区属基线线数 | **4 所**（华二普陀 / 曹杨二中 / 晋元 / 宜川），字段 `quota4_avg` | 3 所，字段 `quota3_avg` | 不可照搬字段名；普陀无 `quota3_*` 列 |
| 退出校 | 3（光新 2022–2024 / 兴陇 2022 / 武宁 2022）+ 1（西校 2022，有名额无分数） | 0 | 新增 `row_type = exited`。四校**均只标「退出」**，`来源.md` 明令「去向不得猜测映射」；**光新的「已撤并」说法已删除**（无出处，见上表注） |
| school_code | 有（`junior_high_school_code`，如光新 `075044`） | 无 | 同一性用编号核对，不靠名称 |
| `row_type` 列 | **当前宽表没有此列**（只有 `ranked`） | 有 | 需新增；光新的退出目前只能靠「有 P 的年份」推断，无权威来源字段 |

## 验收标准

**数据层**

- A1 归并后 071048 只有一行，`former_names` 含「上海市兴陇中学」，年份为 2022–2026（5 年）

- A3 44 行宽表中 `ownership` 无空值

- A5 逐年位次/分位列可由源 CSV 独立复算
- A6 主排序在各口径下的名次可独立复算

**结论层**

- A7 报告按四个研究问题组织，每章结论都能回溯到 CSV

- A9 趋势章的样本边界（多少所、多少年）显式说明
- A10 **全文无任何与嘉定的数据比较**
