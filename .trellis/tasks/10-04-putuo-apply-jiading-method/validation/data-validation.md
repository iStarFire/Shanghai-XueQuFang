## 1. 6.1 的核心发现：原校验是「假门禁」

`implement.md` 6.1 要求「与生成脚本**共用平均秩实现**」。实测发现**两边各写一套**：

- `build_v3.py` 有**两处**内联实现 —— L143（`year_stats`，算 P/Z/ZR）与 L174（`YEAR_RANK`，算位次）
- `verify_derived_pt.py` 又自带一份 `_rank_avg_tie`

**风险**：两套实现可能同错而互相「验证通过」，校验失去独立性 —— 这正是
嘉定 `Spearman` 并列问题的同类风险。

**处置**：抽出 `工具/pt_common.py`（`midrank` / `p_from_rank` / `weighted_mean`），
生成侧与校验侧全部 `import`。重构后**宽表逐字节未变**，证明纯提取、无行为改动。

新增门禁 `verify_shared_impl_pt.py` 用 **AST** 检测内联（正则会因 tokenize 拼接的空格失准 ——
我第一版正则因此对真实内联**完全失效**，注入测试才暴露出来）。

## 3. 5.2 证据级别：design 判据只满足一半（否定结论）

design 要求「各校名额占比**跨年稳定且**跨校差异大 ⇒ 与『按人数占比分配』一致」。
用普陀自有数据**分别**检验（`工具/quota_proxy_evidence_pt.py`）：

| 条件 | 实测 | 判定 |
|---|---|---|
| 跨校差异大 | 4 条区属线上某校占比 **0.51% ~ 9.83%**，相差 **19.2 倍** | ✅ 满足 |
| 占比跨年稳定 | 132 条校线观测 CV 中位 **18.6%**；只看规模校（4 线年均 ≥3 名额）仍 **15.7%** | ❌ **不满足** |

**结论**：「名额 ≈ 学校规模代理」只能作**弱旁证**。可说「名额的**校际分布**与规模高度相关」；
**不可**说「名额**就是**规模」（CV 已排除该强说法）；**不可**写区级分配规则的断言（本地无规则原文）。

132 条校线观测中 **20 条**的 4 线年均名额 <1.5（多为 1 个），CV 中位 **23.9%** ——
一个名额的增减就让占比接近翻倍，与 3.3「名额基数过小」是同一问题的两副面孔。

## 4. 趋势分类的检验力天花板（精确推导）

```
n=5 ⇒ |S| ≤ n(n−1)/2 = 10，Var(S) = n(n−1)(2n+5)/18 = 16.667
     ⇒ |z| = 9/√16.667 = 2.205（上界）⇒ p ≥ 0.0275
Bonferroni 按入榜校数 32 项 ⇒ α = 0.05/32 = 0.0015625，需 |z| > 3.163
2.205 < 3.163 ⇒ 0 所显著是数学必然，与数据无关
```

实测最小 `mk_p` = 0.0275，**恰落在理论下界**上 ⇒ MK 实现无误。
已固化为 `build_tables_pt.py` 的三条断言。

⚠️ **口径修正**：原 `N_MK_TESTS = 14`（照搬嘉定**注释**「7 指标 + 7 方向检验」）。
嘉定代码 `build_q2q3_jd.py:265` 实为 `m = len(RANKED)` = 28 ——
**嘉定自己的注释与代码就不一致**。普陀 MK 是每校一次，已改为 `MK_M = len(FIXED)` = 32。
结论未变（仍 0 所显著），但 `mk_p_bonferroni` 列值原先是错的。
