## 二、结论是否越过了证据能支撑的边界

### 2.1 已明确标注「无法判定」而非「无趋势」

「Bonferroni 校正后 0 所显著」**不是**「没有学校在变」。报告 4.4 给出精确推导：

```
n=5 ⇒ |S| ≤ 10、Var(S) = 16.667 ⇒ |z| ≤ 2.205 ⇒ p ≥ 0.0275
校正后 α = 0.05/32 = 0.0015625，需 |z| > 3.163
2.205 < 3.163 ⇒ 0 所显著是数学必然
```

结论表述为「**按预注册阈值可分三类**」，而非「三类之间有统计显著差异」。
已固化为断言：若 `|z|max ≥ 3.163`、或有学校通过校正、或实测 p 低于理论下界，脚本直接失败。

### 2.2 名额口径的因果强度已下调

design 判据（「占比跨年稳定**且**跨校差异大」）**只满足一半**：

- ✅ 跨校差异 **19.2 倍**（0.51% ~ 9.83%）
- ❌ 跨年 CV 中位 **18.6%**（规模校 15.7%）

故报告中 3 处「名额按在籍人数比例分配」式断言已全部改为「事实 / 推断（证据强度）」分离，
证据级别降为**弱旁证**。可写「校际分布与规模高度相关」，不可写「名额就是规模」，
更不可写区级分配规则（普陀本地无规则原文）。

### 2.3 样本边界与四类排除已显式披露

- 趋势 / 收敛 / 显著性**只覆盖 `years_included ≥ 4` 的 32 所**
- 4 所短样本**不进分类**（三障碍：自由度不足 / **名额基数过小** / 有额无线跨年不同质）
- 2 所退出校、5 所民办**单列披露**（1.4.1–1.4.4）

### 2.4 CI 跨 0 的指标写作「无法判定」

收敛趋势检验中 `range_norm` 的 p = 0.1129（CI 跨 0），报告写「无法判定」而非「没有缩小」。

## 三、是否给出了反向证据

`design.md` 3.4 要求每个个案**至少一条反向证据**。已落实，例：

- **梅陇中学**（上升组）：区属 4 线名额 2026 年 21 个为五年最高（2022 年 18 个），
  同期名额增加 3 个 —— 名额与规模的关联仅为弱旁证，不能排除规模变化驱动了部分升幅。
- **规模相关性反直觉**：名额越多的校位次反而**略好**（ρ = −0.469，p < 0.001），
  与「名额多→切得深→线更低」的机械直觉**相反**，报告已作为「机理推断」标注证据强度。
- **华二普陀线离散异常**：切点深度跨校极差 0.171，是 3 条低线（~0.10）的近 2 倍，
  报告未将其与低线合并表述。
