## 步骤 3：结论可靠性验证（2.4）

- 产出：`validation/verify_analysis.py`
- 命令：`python3 .trellis/tasks/10-03-huangpu-analysis/validation/verify_analysis.py`
- 断言：

| 段 | 检查 |
|---|---|
| [1] 池正确性 | 逐年池 = 18/18/18/17/17；民办 0 行；五年池 = 17；三年池 = 18 |
| [2] 宽表自洽 | `wq_y` = Σ(q×s)/Σq（从原始 CSV 独立重算，最大偏差 < 1e-9）；`P_y` 在 0–1；名次 1..n 连续无重 |
| [3] **SEN 独立复算** | 用独立实现（`statistics` 手写 OLS vs `numpy.polyfit`）对比，最大偏差 < 1e-6；**断言不等于 n 倍** |
| [4] 逐年排名可复算 | 从原始 CSV 独立重算 5 个年度的分位 P，与宽表逐格一致 |
| [5] 离散度双口径 | IQR/σ/CV/极差/头尾差 逐年 × 双口径全部算出；主辅同向性可判定 |
| [6] 趋势分类 | `z` 与分类一致；残差 \|z\|≥1 的学校数与报告一致 |
| [7] 报告↔宽表 | 报告主表 17 行 × N 列逐格一致；三个目标的结论数字均可回溯 |
| [8] 报告独立性 | 0 处跨区引用（禁词含 10 区名 + 其他区/异地） |
| [9] 局限声明 | 报告含全部 8 条局限，尤其「名额未用满」「大同 2024 断点」「2025 异常趋同」 |
| [10] 排除项声明 | 报告显式列出被排除的 5 所民办 + 黄浦学校及原因 |

- **门禁**：全过（0 不通过）才允许生成网页
