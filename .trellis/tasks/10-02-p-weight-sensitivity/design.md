# 设计：主口径 P 的时间加权变体

## 逐年 P 的取数路径（两区不同，必须分开处理）

| 区 | 逐年 P 的来源 | 说明 |
|----|--------------|------|
| **普陀** | **从原始分数线 CSV 重算**：`mean_score_base4_{y}` → 当年池内名次（平均名次法）→ `P_it = 1 − (rank_it − 1)/(n_t − 1)` | 普陀宽表**只有聚合列**（`mean_rank_base4_avg` 等），没有逐年列；基线 = 4 所区属（华二普陀/曹杨二中/晋元/宜川），排名池 = 当年有数据的全部初中（含民办，与既有口径一致） |
| **徐汇** | **直接读宽表逐年列** `mean_rank_base4_{2022..2026}` | 徐汇宽表已含逐年名次列（口径内建）；`n_t` = 该列非空学校数；**不重算原始分数线**（避免与 base5/公办过滤口径打架） |

> 普陀脚本内的 `P_eq` 与既有 `rank-标准化-普陀区-2022-2026.csv` 的 `P` 必须逐值一致——
> 这既是需求，也是本轮最有力的自校验（见需求 5.1）。

## 权重定义

```
w_eq     = {2022:1, 2023:1, 2024:1, 2025:1, 2026:1}
w_lin    = {2022:1, 2023:2, 2024:3, 2025:4, 2026:5}
w_exp    = {2022:1, 2023:2, 2024:4, 2025:8, 2026:16}
w_recent = {2022:0, 2023:0, 2024:1, 2025:1, 2026:1}     # 窗口 = 2024–2026
P_w(school) = Σ_t w_t · P_it / Σ_t w_t        # 只对有数据的年份求和，自动归一化
```

- 4 年校（普陀 曹杨二中附属实验中学、徐汇 徐汇中学南校）缺失年份直接跳过，权重按剩余年份归一化；
  其加权名次的精度天然低一年，引用须标注。
- 权重设计上**不做时点归一化到「每年等重要性」的反向操作**：指数权重本就是「近期更重要」的显式主张。

## 结论口径（防止把加权榜当更准的榜）

1. **主口径保持等权**（长期画像）：不重排 A1/A8。
2. 三列加权 P **并列披露**，并给出与等权榜的 Spearman、最大位次变动、变动 ≥3 位的学校清单
   ——按规范，这些差异是**不确定性区间**，不是「哪个更对」。
3. 必须写出的反直觉结论：**加权不是"更准确"，而是把权重集中到最新一期**。
   指数权重下 2026 独占 16/31 = 51.6%；「只看 2026」时 24/31 所学校位次变动 ≥3 位、最大 18 位
   （上理工附属普陀实验 20→2）。故：若目标是「当前强弱」，应显式使用**近 3 年窗口榜**
   或**趋势斜率**（A5 已有），而不是把指数加权当主榜。
4. 抽样点名（普陀）：真北中学（逐年 P 1.00/0.97/0.59/0.71/0.66，高开低走：等权第 4 → 指数第 8）、
   曹杨中学附属学校（0.67/0.84/0.97/0.45/0.26，大起大落：12 → 17）、
   梅陇中学（0.79/0.72/0.62/0.78/0.76，稳定：8 → 5）。
