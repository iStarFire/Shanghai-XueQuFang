# 设计：计划表校名归一

## 1. 归一依据（三条独立来源，互相印证）

| 依据 | 内容 | 作用 |
|---|---|---|
| A. 数据自带标记 | `is_placeholder_code = 1`（13 行，全在 2024） | 圈定待归一行 |
| B. 官方代码 | 同一 `senior_high_school_code` 下 2024 简称、其余年份全称 | 简称 → 全称的映射 |
| C. 2024 PDF 头部对照表 | 「学校代码名称」列出 `格致(012001)`、`格致奉贤(012002)`…`华二附中(152003)` | **独立验证 B 的结果** |

C 是关键：它让「按代码推断」与「官方文档明示」两条独立路径必须一致，不一致即失败。

## 2. 归一规则

### 2.1 高中简称（13 行）

```
canonical(code) = 该代码下「出现年数最多」的名称
              （并列时取字符数最多者）
2024 行若 senior_high_school ≠ canonical(code) → 替换为 canonical(code)
同时 is_placeholder_code: 1 → 0，note 追加「原为简称『X』，按官方代码 012001 归一」
```

代码 `012011 同济大学科技中学`（2026 新增）与 `152006 上海师范大学附属中学`（2022–2023）
本身只有唯一名称，规则不触发，**不会被误改**。

### 2.2 初中临时代码（13 行）

```
017777 大同初级中学（原黄浦学校） → 015002 上海市黄浦学校
```

依据：分数线侧 2024 官方写法已确证「上海市黄浦学校」在 2024 以
「上海市大同初级中学（原黄浦学校）」形式出现，且 reextract 任务已将其
归一为独立序列 `上海市黄浦学校`。**双源必须指向同一实体**。

同时 `junior_high_school_code`: 017777 → 015002。

## 3. 为什么不按名字匹配

「光明」是「上海市光明中学」的子串，也是「上海市光明初级中学」的子串；
若用子串/前缀匹配，2024 的高中「光明」会被误并入初中「上海市光明初级中学」。
**必须用代码，不能用名字。** 这与普陀/黄此前的初中名模糊匹配教训一致。

## 5. 局限与风险

| 风险 | 处置 |
|---|---|
| 代码复用（两个不同学校共用一个代码） | 已核实：**一码一名**，无复用；若门禁检出复用即失败 |
| 归一后与分数线 join 出现新缺口 | 归一只会**减少**缺口（简称被替换成全称）；若缺口数上升说明映射方向错了 |
| `017777` 若并非黄浦学校而是新设校 | 已用名额规模（20 vs 24/26）与分数线 PDF 原文双重印证；若被推翻需回滚该条 |
| 归一后旧分析产物失效 | 已确认 `analysis/黄浦区公办初中名额分配到校分析/` 下**无宽表/报告**，仅工具脚本，故无失效产物 |
