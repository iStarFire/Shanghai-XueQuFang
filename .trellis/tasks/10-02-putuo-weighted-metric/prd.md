# PRD：普陀口径变更 v3（名额加权均分）+ 宽表扩容

## 用户决策（已确认）

1. **主口径的「当年到校均分」改为计划名额加权平均**；**等权版保留为对照列**（主表按加权排序）。
2. **宽表扩容**：写入逐年 × 逐线的全部原始数据（分数、名额）与全部中间计算，本轮一起做。

## 变更定义

```
等权（对照）： mean_score_base4_{y}    = 当年可得区属线最低分的算术平均
加权（新主口径）：mean_score_base4_wq_{y} = Σ(score_h × quota_h) / Σ(quota_h)   （h 取当年该校有分数的线）
```

- 某条线有名额但无分数（无人达线）时**不计入**（与等权口径一致，避免把缺失当 0 分）。
- 权重来自名额，**按在籍人数比例分配**，因此权重差异反映「招生规模结构」而非学校水平——
  这一语义局限必须在报告中披露（规范要求）。

## 受影响的下游（全部重算）

逐年名次 → P / Z / ZR → 三组结构口径（全身 / 头部 / 尾部）→ 综合口径（三组等权）→
时间权重口径（线性 / 指数 / 近 3 年）→ 均名 / 中位 / 方差 → 趋势与收敛（rel、Sen、收敛回归、IQR、σ、
超收敛个案、趋势方向）→ 规模相关性（ρ(名额, 名次)）→ 表 2-1 / 2-2 / 附录 A 各表 → 核心结论 18 条 →
第 3–5 章数字 → 排序表图片。

**不受影响**：单线视角（逐线名次，与跨线汇总无关）、名额深度效应的组内检验（线级）、枚名近名校检查。

## 目标

### 需求 1：计算管线（单一事实源）

- 新脚本 `工具/build_v3.py` 从原始分数线 / 计划表出发，计算**两套链**（等权对照 + 加权主口径），
  一次性产出：扩容宽表、趋势分析、rank-标准化、rank-多口径总表、rank-加权敏感性。
- 命名：加权为主口径，列名带 `_wq`；等权为对照，列名带 `_eq`（旧列名 `P`、`rank_P` 等将被
  `P_wq`/`rank_P_wq` 取代，避免"哪个是主口径"的歧义）。

### 需求 2：宽表扩容（核心交付）

`宽表-初中水平-普陀区-2022-2026.csv` 写入：

| 列组 | 内容 |
|------|------|
| 元数据 | 校名、**校代码**、ownership、years_included、years_list |
| 逐年 × 逐线 **原始分数** | `score_{高中代码}_{年}`（9 所高中 × 5 年） |
| 逐年 × 逐线 **计划名额** | `quota_{高中代码}_{年}`（同上） |
| 逐年派生 | `mean_score_base4_eq/wq_{年}`、`valid_pairs_{年}`、`quota4_{年}` |
| 逐年标准化 | `rank_base4_eq/wq_{年}`、`P_eq/wq_{年}`、`Z_eq/wq_{年}`、`ZR_eq/wq_{年}` |
| 汇总 | quota4_avg、均名/中位/方差（主口径）、三组 P_wq、P/Z/ZR/P_comb 与名次、时间权重口径 |

- 目标规模 ≈ **170 列**；每格可回溯到原始 CSV。
- **硬约束**：扩容后与原宽表**共有的列逐值 0 变化**（尤其 raw 与等权列）。
