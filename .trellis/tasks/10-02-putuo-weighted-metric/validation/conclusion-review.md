- 变更性质：**主口径变更**（等权 → 名额加权），等权链完整保留为对照列

## 验证方法说明

1. **独立重算（不 import 2.3 脚本）**：`validation/verify_v3.py` 从原始分数线/计划表重建；
   2.3 用逐值比较法，验证脚本用**排序分组法**。
2. **回归校验（本轮特有，最关键）**：把 v3 宽表与 git 中的旧宽表按**口径无关列**逐值比对——
   `years_included` / `years_list` / `quota4_avg` **132 项 0 差异**。
3. **等权链连续性**：旧 `P/Z/ZR/rank_P` 与 v3 的 `P_eq/Z_eq/ZR_eq/rank_P_eq`
   32 所**逐值 0 差异**——证明本次变更对等权口径无副作用，旧报告数字可无损映射到对照列。
4. **原始列回源**：新宽表的 `score_{高中}_{年}` / `quota_{高中}_{年}` 抽样 60 格与原始 CSV 一致。
5. **报告表核对**：表 2-1 / 2-2 / A.3-1 共 **96 项**字符串级核对 0 未匹配。
