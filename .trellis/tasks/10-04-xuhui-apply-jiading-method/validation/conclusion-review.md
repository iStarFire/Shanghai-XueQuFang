## 二、结论是否越过了证据能支撑的边界

### 2.1 「差距在缩小」被降级为「3 显著 + 4 无法判定」

- **Gini、(P90−P10)/中位、MAD/中位** CI 不跨 0 ⇒ 显著收窄
- **σ、CV、IQR/中位、极差/中位** CI 跨 0 ⇒ **无法判定**（p 0.0998 ~ 0.5115）

⇒ 报告明确写「**不得**写成『徐汇公办初中差距在缩小』」。

### 2.2 「0 所显著」被定性为**检验力天花板**，而非「没有学校在变」

```
n=5 ⇒ |S| ≤ 10、Var(S) = 16.667 ⇒ |z| ≤ 2.205 ⇒ p ≥ 0.0275
Bonferroni 校正项数 = 23（= 参与 MK 的学校数，⛔ 不是 14）⇒ α = 0.002174
需 |z| > 3.065
2.205 < 3.065 ⇒ 0 所显著是数学上的必然，与数据无关
实测最小 mk_p = 0.0864，远高于理论下界
且徐汇连未经校正的都没有一所显著（0/23）
```

### 2.3 名额口径的因果强度已标注

- **一级依据**：2022–2024 计划 PDF 正文原文「以符合填报『名额分配到校』志愿资格的
  中招报名人数占我区该类学校中招报名总人数的**比例为测算依据**」
- 2025/2026 为纯数据表 ⇒ 引用须注明年份，**不得笼统称「徐汇计划文件规定」**
- 委属线排除也有原文（「以均衡、随机为原则**抽签**确定」）
- 名额与位次的 ρ = **−0.465** 写成**相关**，明写「**不是因果识别**」

### 2.4 样本边界与四类排除已显式披露

- 趋势与收敛**只覆盖 23 所五年全勤**
- 短样本 1 / 退出 3 / 民办 6 / 四年制 1 各给排除原因（报告 5.1）
