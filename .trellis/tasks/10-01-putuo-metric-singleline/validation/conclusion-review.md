## 验证方法说明

1. **独立重算（不 import 2.3 脚本）**：`{TASK_DIR}/validation/verify_singleline.py`
   与 `工具/singleline_pt.py` 无 import / 函数复用关系。
2. **实现路径不同**：
   - 2.3 用「逐值比较法」算平均名次；验证脚本用**排序后按位次区间取中点**（并列取 `(i+j)/2+1`）；
   - 2.3 的 Spearman 用列表推导式求秩；验证脚本用**索引排序 + 并列取平均名次**的独立实现；
   - 两条路径都从**原始分数线 / 计划表**出发，不经过宽表中间值（宽表仅用于跨样本 ρ 的输入比对）。
3. **比对覆盖**：单线视角 CSV 全表 1620 项逐值比对（均名 / 均分 / 名额合计 / 年数，容差 5e-3）；
   P/Z/ZR/旧均名全表 176 项比对；报告 A1 表按正则抽样 9 行核对。
4. **回源抽样**：3 个 (校, 线, 年) 单元格回原始 CSV，打印 `source_doc` + `source_page`。
5. **修正记录（本轮发现的既有错误）**：
   - A2 / 核心结论 3 原称「规模与竞争强度**无系统关联**（Spearman = 0.546）」——
     实测带符号值为 **−0.546**（与 P 口径 +0.553），n=31 时 p≈0.0015，属**中等强度、方向明确**的关联。
     旧表述误读了符号与显著性，已更正（A2、核心结论 3、A4、A7.4）。
   - 核心结论 4 原称「曹杨第二中学附属**实验中学**…其**均名第 5**」——
     两个数字与校名均错：「均名第 5」属五年全勤的曹杨第二中学附属**学校**（均名 9.50）；
     4 年制的附属实验中学旧均名为 **25.375（第 23）**。已更正并补 P 口径下的入榜说明。
